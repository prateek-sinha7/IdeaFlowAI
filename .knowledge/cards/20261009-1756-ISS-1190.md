# ISS-1190

**Register source:** found while re-running the regression sweep for [FIX-781](20261009-1735-FIX-781.md) (`QA-KB-120`,
2026-10-09). Not its own bug row. [ISS-1179](20261009-1659-ISS-1179.md) named the shared `FakeSandbox` in
`test_finalizer_v2.py` and the files that import it. These two are separate copies, not imports, so neither that card nor
FIX-781 covered them.

**Confidence.** CONFIRMED by reading (quotes below) and by running both files after FIX-781 (green). INFERRED: that any test
in either file depends on the per-path behaviour. Nothing was traced beyond the two `def stage_exact` bodies.

## Condition

The production primitive is one call (`backend/app/agents/runtime/local.py:1426-1434`):

```python
    def stage_exact(self, paths: list[str]) -> None:
        ...
        if not paths:
            return
        self._git("add", "--force", "--", *paths)
```

The two doubles loop instead:

- `backend/tests/agents/test_cancel_paths_v3.py:250-253`:
  `for p in paths: _run_git("add", "--force", "--", p, cwd=self.root)`
- `backend/tests/agents/test_phase3_wip_commit.py:169-172`: the same loop.

Both files drive the real `finalize_terminal_run` (`test_cancel_paths_v3.py:481`, `:539`, `:625`;
`test_phase3_wip_commit.py:290`), which reaches `build_flat_payload` and its `stage_exact` call.

## Effect

The effect is the one [ISS-1179](20261009-1659-ISS-1179.md) describes. When one path is absent, git stages nothing, but the
double stages every path that came before the absent one in the frozenset's iteration order, so the result depends on
`PYTHONHASHSEED`. After FIX-781, `build_flat_payload` no longer passes a missing output. A missing `logs.jsonl` or
`summary.md` ([ISS-1178](20261009-1659-ISS-1178.md)) still would, so the divergence is latent, not gone. Both files pass
today: `test_cancel_paths_v3.py` 4 passed, `test_phase3_wip_commit.py` 12 passed.

## Fix direction (test-only, not applied)

Make both bodies one `_run_git("add", "--force", "--", *paths, cwd=self.root)` behind `if paths:`, as FIX-781 did for
`FakeSandbox` (`test_finalizer_v2.py:181-184`). Then run each file on its own.

## Evidence

`evidence/qa-kb-120/fix-04-redispatch-test-runs.txt`. Its last section quotes both `def stage_exact` bodies by line, and its
sweep section has both files' results.
