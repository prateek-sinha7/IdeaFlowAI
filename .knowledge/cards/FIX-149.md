## Description

Prototype dropdown title shows "Prototype · Prototype" and clicking still navigates to User Stories run

## Root cause

Bug 1: odProtoNotifCreated effect used hardcoded "Prototype"/"Presentation" as title; submittedBrief available but ignored. Bug 2: onViewResults for running notifications called onSelectWorkflowRun (a history-reopen fn that calls resetPipeline(), getWorkflow() fetch, resetReplayState()) — completely wrong for a live run. Fix: (1) use submittedBrief as notification title; (2) add onSwitchToLiveRun prop + handleSwitchToLiveRun in page.tsx that only attaches SSE + updates trackedRunIdRef/activelyBuildingRunIdRef/contentSource without resetting state; (3) onViewResults now calls onSwitchToLiveRun for running notifications.
