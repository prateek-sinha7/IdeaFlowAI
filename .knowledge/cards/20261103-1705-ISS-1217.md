## What is unchecked
The approval for gap 3 (`.agents/tasks/workflow-gaps/decisions.md`) asked for a query of `workflows.manifest_json` for saved
or inline manifests declaring `degrade` before shipping. The backend step ran it against the local development database
through `SessionLocal`: 0 rows containing `chain_policy` or `degrade` in `workflows.manifest_json` and 0 in
`workflow_runs.manifest_json`. Shared environments (staging, production) were not queried. The Composer never writes the field, so the expected hit count is 0, but that is an expectation and not a
measurement.
## Who should act
Whoever deploys [FIX-789](20261103-1705-FIX-789.md). The query is a read-only `SELECT` over both `manifest_json` columns
for the strings `chain_policy` and `degrade`.
