# ISS-139

## Title

page.tsx's case "pipeline_cancelled": case "pipeline_failed": switch arm is UNREACHABLE dead code (~:1527-1562). Both types are members of pipelineTypes, and that branch returns before the switch is ever entered — so the arm's runStore.update(termSrcRunId, {reviewGateData:null, questionnaireData:null}), its setLastCancelledRunId, its detachRunRef release and its setActivePipelineRunId(null) never run. A fix applied there would silently do nothing. Verified by reading the control flow, and now pinned by a test in terminalReopenReconcile.source.test.ts that asserts the ISS-126 fix is NOT inside it. Deleting it needs care: setLastCancelledRunId and the detachRunRef release may be genuinely wanted on the LIVE terminal path, in which case they belong in the reachable block, not this one.

## Source / evidence

Verified during the ISS-126 investigation; the trap is that the arm reads exactly like the right place to fix ISS-126.
