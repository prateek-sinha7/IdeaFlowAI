## What was wrong

`_atomic_write_context_dir` staged three payload files in a temp directory
(`mkdtemp`), then called `shutil.rmtree(dest_dir)` on `.context/` itself before
renaming the staging dir over it.  The staging dir contained only the three flat
payload files, so after the rename every pre-existing file under `.context/` was
gone — specifically `.context/design/` and `.context/selections.json` written by
the `opendesign` context provider at sandbox open (`engine.py:4130`).

The bug was latent until BUG-125 (B23) is fixed, because no chainable manifest
currently declares `chain_context` in its `context_providers:` list.  It would
become live the instant the manifest edits from BUG-125 land.

Root cause card: [BUG-126](20260915-1302-BUG-126.md).

## What changed

**`backend/agents/capabilities/context_providers/chain_context.py`**

Replaced the body of `_atomic_write_context_dir`.  Old strategy: `mkdtemp` →
write all files → `rmtree(dest_dir)` → `rename(staging, dest_dir)`.  New
strategy: for each file, `mkstemp(dir=dest_dir)` → write bytes → `Path.replace(dest_file)`.

Key properties:
- Each write is atomic: the temp is in the same directory as the destination,
  so `os.replace` is guaranteed to be on the same mount.
- Pre-existing files (`.context/design/`, `.context/selections.json`) are
  never touched.
- A failure mid-loop leaves previously written payload files in place and
  removes only the failed file's temp via `unlink(missing_ok=True)`.
- The `shutil` import is gone — no deferred import needed.

**`backend/tests/agents/test_context_determinism.py`**

Completed `test_atomic_write_context_dir_preserves_sibling_files` in
`TestChainInstallDoesNotTouchDesignFiles`.  The test previously captured
`sel_before` / `design_before` but had no final assertions — the comment
said "if the implementation was changed to preserve siblings, this assertion
would confirm that."  Four assertions added:
- `selections.json` exists after the call
- `selections.json` bytes are unchanged
- `design/design-system.md` exists after the call
- `design/design-system.md` bytes are unchanged

**`backend/tests/agents/test_chain_context_v3.py`**

Added `test_atomic_write_merges_not_replaces` — a standalone regression guard
that pre-populates `.context/design/tokens.json` and `.context/selections.json`,
calls `_atomic_write_context_dir` with three payload files, then asserts all
five files are present and byte-identical to what was set up.
