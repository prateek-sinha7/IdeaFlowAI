A launch panel built from this endpoint showed five rows called `custom-agent:emoji`,
`custom-agent:language`… all with `order: 0`, in arbitrary order.

## Root cause

```python
spec  = spec_by_id.get(step.agent_id)     # AGENT.md lookup
name  = spec.name  if spec else step.agent_id
role  = spec.role  if spec else ""
order = spec.order if spec else 0
```

A composed step is an instance of the `custom-agent` template and has no `AGENT.md`, so
`spec` is `None` and all three fields collapse. The manifest's own label was sitting
unused on the compiled step as `display_name` — the same field the engine already overlays
onto the runtime spec.

## Fix

`name` prefers `step.display_name`, falling back to the `AGENT.md` spec then the raw id.
`order` is now the position in `compiled.steps` for EVERY step, via `enumerate(..., 1)` —
one ordering system rather than AGENT.md order for declared agents and 0 for composed
ones, and closer to the truth since the compiled sequence is what runs.

Verified: `ex_A2_branch` returns `Emoji Picker`, `Pick Language`, `Say Hello`, `Say Hola`,
`Say Hallo` at orders 1-5.
