## Description

The ISS-065 artifact-version picker only moved the raw output — the prominent artifact CARD kept rendering the LATEST version, so the owner selected v1, saw v3's page grid, and reported "while changing the version there, i couldnt see the older version's content". AgentDetailPanel computed shownOutput = viewed?.content ?? agent.output and passed it to OutputPreviewSection (:869) — correct — but handed the RAW agent to SettledArtifactCards (:840), which re-derived everything from agent.output: parseSpecSections (:611), parseSpecOverview (:612) and <AnalysisPreview content={agent.output}/> (:687). The card TYPE was picked the same way (discriminateArtifact(agent.output), :130), so a mid-re-run agent — agent.output cleared by FIX-039 — rendered NO card at all even with v1 selected.

## Root cause

One screen, two answers to *"what am I looking at"*. The version selection lived in a local shownOutput that only one of four consumers read; every other consumer went back to the agent for the same information. Not a missing feature — a missing single source (INV-12), the same shape as FIX-225's "two accumulators, one truth". The card derivation additionally treated the artifact's TYPE as a property of the AGENT when it is a property of the ARTIFACT.
