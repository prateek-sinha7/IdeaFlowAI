## Description

useRunStream "Maximum update depth exceeded" — setCursor and setLastMessage called on every SSE frame causing re-render storm with concurrent runs

## Root cause

cursor and lastMessage were useState — each SSE frame called setCursor(seq) and setLastMessage(msg), triggering a React re-render cascade. With N concurrent runs each emitting frames continuously, React exceeded its update depth limit. Neither value is used in production code (only in tests). Fix: convert both to useRef (cursorStateRef, lastMessageRef). cursor React state removed; lastMessage React state removed. Return values still expose cursorStateRef.current and lastMessageRef.current for API compatibility. Also added stoppedRef.current guard before setState calls in dispatchBlock for strict-mode safety. lastError (set only on reconnect/auth failure) remains useState — not a per-frame update.
