## Description

The "Update the Specs" button appeared on every review gate (e.g. user_stories
quality review agent, prototype-validate gate) instead of only the Spec Kit
Analyzer (`prototype-analyze`) gate in the prototype pipeline.

## Root Cause

`_AGENT_KIND_MAP` in `ExecutionEngine` explicitly mapped 4 prototype agents but
**omitted `prototype-analyze`**:

```python
_AGENT_KIND_MAP = {
    "prototype-specify": "spec",
    "prototype-plan": "task_list",
    # prototype-analyze: MISSING
    "prototype-build": "html_file",
    "prototype-validate": "validation_report",
}
```

`_artifact_kind_for` falls back to `"summary"` for any agent not in the map.
`_UPDATE_SPECS_ELIGIBLE_KINDS = frozenset({"summary"})` then made **every
unmapped gated agent** eligible — not just prototype-analyze.

This was the original design: prototype-analyze was *intentionally* left unmapped
so it alone would fall back to `"summary"`. But this assumption breaks the moment
ANY other workflow has a gated agent with an id not in the map — all such agents
also fall back to `"summary"` and get the button.

## Fix

Add `"prototype-analyze": "analysis"` to `_AGENT_KIND_MAP` and change
`_UPDATE_SPECS_ELIGIBLE_KINDS` to `frozenset({"analysis"})`:

```python
_AGENT_KIND_MAP = {
    "prototype-specify": "spec",
    "prototype-plan": "task_list",
    "prototype-analyze": "analysis",   # ← explicit, dedicated kind
    "prototype-build": "html_file",
    "prototype-validate": "validation_report",
}

_UPDATE_SPECS_ELIGIBLE_KINDS: frozenset[str] = frozenset({"analysis"})
```

Now:
- `prototype-analyze` → `"analysis"` → ✅ eligible (Update the Specs shows)
- All unmapped agents → `"summary"` → ❌ NOT eligible (button hidden)
- All other explicitly mapped agents → their own kinds → ❌ NOT eligible

- INV-1 ✅ — no `if pipeline_type ==` / `if spec.id ==` branches; eligibility keyed on kind string only
- INV-3 ✅ — no golden changes; `review_gate_ready.artifact_kind` field changes from `"summary"` to `"analysis"` for the analyze gate, but goldens don't capture this field
