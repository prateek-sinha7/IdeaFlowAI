# ISS-011

## Title

env/credential (NOT product): the 3 Phase-8 HITL live-tail tests + the self-check traced to ONE cause — the default-profile SSO token expired mid-sweep. RECURRING-MODE FIX (Part 2, the real deliverable): test_phase8_live.py now re-checks live_skip_reason() per live test (autouse on TestLiveHITL) → pytest.skip()s with the re-run-after-aws sso login reason on mid-sweep expiry instead of failing the 0-token assertion; the self-check no longer asserts strict _LIVE_SKIP == live_skip_reason() equality (tolerates the collection-valid → runtime-expired drift, asserts gate correctness per point-in-time). Proven OFFLINE: an expired-creds simulation (monkeypatched live_harness.live_skip_reason) shows the guard SKIPS (not FAILS) + a no-op complement; TestOfflineHITL green. The transient-error classification (model_policy.py:185-211) was deliberately left UNCHANGED (widening it to retry expired SSO would mask real AccessDenied/ValidationException — INV-3). DEFERRED (not blocking, needs fresh creds): Part 1 — re-run the 3 HITL cases after aws sso login (sub-$0.05, ~minutes) on the next Bedrock pass to confirm the live-green path.
