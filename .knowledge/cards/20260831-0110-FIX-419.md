## What changed

**Five pins bumped, each with its cause recorded** in the docstring the file
already used for exactly that — *"Went 23 -> 24 with spec 017's ppt_v2"* now
continues *"Went 24 -> 25 with spec 018's playwright_smoke_test"*. The identity
of the addition was established before each bump (the 30th manifest, the 9th
model, the 186th skill), because a pin bumped to green is a pin deleted.

**S-16-12 subtracts the page's existing tokens.** A `_token_runs()` helper is
called once before the key is created and again after, and only tokens that
arrived WITH the creation can be this key's plaintext:

```python
before_tokens = set(_token_runs(page.evaluate("() => document.body.innerText")))
...
secrets = [s for s in _token_runs(shown) if name not in s and s not in before_tokens]
assert secrets, "no newly-shown token was captured, so the reload below proves nothing"
```

That `assert secrets` is the important half. Without it, a create step that
stopped showing the plaintext at all would leave the loop empty and the test
would pass having checked nothing — the failure mode this test exists to catch.
The narrower alternative (anchoring on the `flowin_` prefix) was rejected: it
goes stale the day the prefix changes.

**S-15-16** targets `"Share this run"`. **`not-found.tsx`** escapes four
apostrophes, taking eslint from 24 errors to 20; the remaining 20 are
structural React-correctness rules in the app's largest files and were left
alone deliberately.
