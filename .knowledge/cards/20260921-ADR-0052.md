## The decision

Figma export extracts on the **server**, with headless Playwright, and ships a
versioned absolute-positioned intermediate representation. The previous
client-side DOM walk is kept only as a fallback when the endpoint is
unreachable.

## Why

A DOM walk running inside the user's page can only see what that page has
already rendered, in the viewport it happens to be at, with whatever fonts and
charts have finished loading. It cannot navigate to a second screen, cannot wait
for a JS-rendered chart, and cannot produce a screenshot to check its own work
against.

## What that buys

- **Fidelity.** `getComputedStyle` + `getBoundingClientRect` for every element,
  CSS variables and classes resolved, SVG captured as `outerHTML`, form
  controls, pseudo-elements, and canvas/video frames serialized as data-URIs.
  `device_scale_factor=2`, a 1.5s settle and a `networkidle` wait, so
  JS-rendered charts are actually present.
- **Multi-screen.** Nav and sidebar links are discovered and clicked; each
  screen gets a PNG screenshot and its own `SCRAPE_FN` pass. The screenshot's
  MD5 is the dedup key, and its nav label names the Figma frame so layers are
  readable.
- **A visual backstop.** In the v3 mapper the screenshot becomes the frame's
  background fill, with editable layers — text, frames, SVG, images, gradients,
  shadows — placed on top. Pixel-perfect even where a mapping is imperfect.

## The contract

`{ version: 3, screens: IRNode[], viewport, tokens, _screenshot }`.

The plugin handles v1 (legacy auto-layout) and v3 (IRNode absolute-position);
`ui.html` validates v1/v2/v3. Fonts: Inter plus any family found in the IR, with
the "Semi Bold" alias handled. Linear/radial gradients and box-shadows are
parsed by the plugin, not pre-flattened by the server.

## Operational constraints worth keeping

- The endpoint runs the browser in a `ThreadPoolExecutor` to bypass the Windows
  `SelectorEventLoop`.
- `json.dumps` cannot serialize NaN/Infinity, which computed-style arithmetic
  readily produces; `_sanitize_floats` runs over every payload.
- Two-layer IDOR protection on the run id.
