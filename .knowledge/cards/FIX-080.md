## Description

Fix Save button flash + double appearance on Reset — remove loading early-return from ConfigLeversFlat

## Root cause

Reset increments resetKey which remounts ConfigLeversFlat. On remount, useAgentCapabilities starts loading=true and the early-return <p>Loading…</p> caused a height change (tiny→4 big rows) that shifted the button row, creating the double-button flash. Removed the loading early-return (renders rows with empty options = same height always). Also added setSaved(false) to Reset and removed transition-all from Save button.
