## Three defects, one symptom

All three read to the user as "the version you pinned is not the version on
screen".

### The generic deliverable never followed the pin — [ISS-300](20260828-1726-ISS-300.md)

`content` only reaches the first-party renderers (`user_stories`, `ppt`,
`prototype`). A custom or unknown `renderType` routes through the **generic**
channel, which read the un-pinned `genericDeliverable` prop. Pinned to v2, the
Files tab showed v2's agent outputs beside the ROOT's "Final output" — two runs
in one view. Every read now routes through `effGenericDeliverable`; the Preview
tab was equally wrong and is fixed with it.

### The renderer did not follow the pin either

`workflowType` is the SHELL's type, and a pinned deep link mounts the family
ROOT in the shell. A `prototype_revision` pinned under a `custom` root was
therefore typed `custom`, fell into the generic channel, and presented
differently from its own `/runs/{id}` page. The pinned run's own type now wins.

### The header's token total — [ISS-304](20260828-1600-ISS-304.md)

A reopened run rebuilds its totals by replaying durable events, and the
`agent_complete` case sums the per-agent figures. Work not attributed to a
top-level agent row — wave workers, sub-agents — never enters that sum.

Measured on run `26a7e162`: the header read **13.6M** against a persisted
`token_usage.total_tokens` of **19.7M**, a 6.1M shortfall on the one number a
user would check a bill against. The server's persisted usage is authoritative
for a settled run and now wins, in the same after-the-replay reconciliation
that already restores the persisted status.

## Also: deliverable naming

A run may declare `output` with mimetype `application/zip`, and that reached the
UI verbatim — an extensionless name with a Download button that saved a file the
OS could not open. The extension is now filled from the mimetype when the
declared name lacks one, never rewriting one that is there. Every format label
names its extension too; `zip` and the binary fallback omitted theirs while
html/markdown/json carried them.
