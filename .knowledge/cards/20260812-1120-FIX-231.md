## Description

The live harness's review-gate wrapper could not accept the gate's own arguments — every gated harness drive raised TypeError and then reported the run COMPLETE without gating. Fixed by forwarding the engine's kwargs through the wrapper, plus a static signature-drift guard over every _run_review_gate stub so the family ends.

## Root cause

tests/agents/live_harness.py:672 pinned the four-parameter shape of 2026-06-11 and installed itself over engine._run_review_gate at :683 unconditionally; the engine grew to TEN parameters and all FOUR call sites pass them by keyword (engine.py:3397/:3504/:4440 + kernel_services.py:1116, the declared-gate delegate the ISS-074 row missed). The wrapper also forwarded only the same four positionally, so widening the def alone would silently DROP them. Broke at f18de868 (2026-06-30, redoable). Invisible for 43 days because .planning/TEST-REGISTER.md:85 excluded offline suites by FILENAME ("anything *_live*") and both affected files are offline-safe — coverage selection, not the credential gate the row claimed.
