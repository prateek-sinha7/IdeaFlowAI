# ISS-995

## What happened

Sibling of [ISS-662](20260917-1307-ISS-662.md) (register bug **QA-KB-063**): the same old literal,
in a spec file that neither ISS-662 nor the QA-KB-063 triage names. **Marked INFERRED.** Nothing
fails today, so this is documentation drift found by grep, not a reproduced defect.

## Why the root cause implies this

ISS-662's root cause is that the specs froze the narrator's pre-[FIX-517](20260917-1307-FIX-517.md)
wording. FIX-517 changed two strings (`chat_narrator.py:167-175`): the "answered" card became
`Clarifications round N answered` and the ask became `Round N: Before I build, I need to lock a few
things down.`. A repo-wide grep for the old text finds more Gherkin than the three artifacts
ISS-662 lists:

- `tests/integration/screens/22-handoff-and-gates.feature.md:362`, scenario S-22-24 (chips, then
  `chat-clarify-submit`): `And the lane records "Clarifications answered"`.
- `tests/integration/screens/22-handoff-and-gates.feature.md:352-353`, scenario S-22-23:
  `And the lane message reads "Before I build, I need to lock a few things down."`. The post-fix
  card reads `Round 1: Before I build, I need to lock a few things down.`. S-18-07's Gherkin
  (`18-chat-lane.feature.md:206`) says "contains", which still holds.
- Narrative mentions of the old text that describe past captures, not requirements:
  `22-handoff-and-gates.feature.md:60` and `07-run-detail.feature.md:31-33` ("Transcript
  milestones seen: ... "Clarifications answered" ..."). Leave them unless the vocabulary table in
  `18-chat-lane.feature.md:54-64` is rewritten and they are meant to agree with it.

No test asserts any of it: `tests/integration/e2e/suites/22_handoff_and_gates/test_handoff_and_gates.py:386-401`
implements S-22-23 and S-22-24 with `SOURCE.assert_declared("chat-clarify-actions",
"chat-clarify-submit")` and `SOURCE.assert_declared("chat-clarify-chip", "chat-clarify-submit")`
only, so the stale text is not caught. The first live test written from these steps would be born
red, which is the QA-KB-063 failure again.

## Expected vs actual

- **Expected:** the Gherkin quotes what the narrator emits now: numbered
  (`Clarifications round N answered`, `Round N: ...`) for rows written after FIX-517, round-less
  only for rows persisted before it (FIX-517 locked constraint: "An event with no `round` ... keeps
  the pre-fix text byte-for-byte").
- **Actual (INFERRED):** S-22-24 and S-22-23 quote the round-less wording only.

## Suggested fix

Update `:362` and `:352-353` in the same pass as the ISS-662 edits to
`18-chat-lane.feature.md`, using the same vocabulary the shared e2e locator will carry. No code and
no test change is needed.
