## Bug

A run was priced at one run-level model, so a mixed Sonnet/Haiku run was priced
entirely as Haiku.

## Fix

- `agents/capabilities/token_usage.py`: one home for input, output, cache read,
  cache write and their per-model rates. Each agent is priced at its own model.
- Run rows, analytics and terminal output columns carry total / input (uncached +
  cache write) / output. Cache reads are shown only in analytics.
- Characterization goldens strip the new `usage_version` key.
