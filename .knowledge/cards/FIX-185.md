# FIX-185

**Phase / trigger:** Phase 14 (CR-02 guard), Phase 29 (chat router), ISS-050

## Description

Typing a revision request in the chat lane after a completed `prototype` or
`user_stories` run immediately fails with `revision_validation_error`.

## Root Cause

`engine._handle_revision` (engine.py:5906) contains the CR-02 guard:

```python
if compile_for_run(revision_pipeline_type).planner != "skip":
    raise ValueError(f"... not revision-dispatchable ...")
```

Both `prototype_revision` and `user_stories_revision` declared `planner: run`.
CR-02 was added in Phase 14 (2026-06-12) when only PPT revisions reached
`_handle_revision`. 26 days later (Phase 29, 2026-07-08) the generic
chat-lane revision channel (`chat_router.py`) widened the guard's blast
radius to include these two pipelines without any re-audit.

`user_stories_revision` has an additional hazard: `clarify.mode: auto` would
unconditionally force `gate_verdict = CLARIFY_REQUIRED` (engine.py:1809-1812)
if `planner: skip` alone were set, guaranteeing the indefinite `event.wait()`
hang CR-02 was designed to prevent. Both fields must flip atomically.

## Fix

**`prototype_revision/workflow.yaml`** — one line:
```diff
-planner: run
+planner: skip
```

**`user_stories_revision/workflow.yaml`** — two lines (ATOMIC):
```diff
-planner: run
+planner: skip
 clarify:
-  mode: auto
+  mode: skip
```

**`test_manifest_parity.py`** — `_RUN_REVISION_DISPATCHED` frozenset expanded
to include `prototype_revision` and `user_stories_revision`; section comment
updated.

**`test_id_alias_resolver.py`** — same frozenset addition (lockstep per its
own comment).

**`test_revision_intelligence.py`** — two changes:
1. `test_planner_run_target_rejected_before_dispatch` retargeted from
   `prototype_output` → `app_builder_output` (app_builder_revision still
   has `planner: run`, correctly rejected)
2. New `test_prototype_revision_now_dispatches_successfully` — fail-before /
   pass-after pin proving the fix end-to-end via real `_handle_revision`
   dispatch with scripted models

## Test Results

- `test_planner_run_target_rejected_before_dispatch` PASSED (app_builder_output)
