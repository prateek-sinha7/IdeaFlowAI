## Related

## The gap

`single_file` reads the built deliverable back so it can be surfaced. That
readback then stands in for EVERY later agent's output, so any step running
after the build — a reviewer, a validator, a reporting agent — has its own
result overwritten by the deliverable.

Commit `127b20a3d` recorded this alongside the conditional-gate JSON parse
defect; the latter was fixed as FIX-526, this one was left.
