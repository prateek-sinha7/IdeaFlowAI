## Description

The agents.capabilities must not import the execution kernel or the web layer import-linter contract had been BROKEN since 2026-07-20, so Ports & Adapters was at 3 kept / 1 broken against a documented intended state of 4/0. A single line — agents/capabilities/strategies/task_loop.py:562, from agents.execution_engine.od_context import get_example_html (the KAN-103 template.html revision seed) — broke the contract on BOTH forbidden roots at once, because od_context.py:26 itself does from app.services import od_loader. A sweep confirmed it was the only violation in the entire capability tree.

## Root cause

Introduced by 26bcaacb (KAN-102/103) as a one-off bypass of a seam that already existed: KernelServices.template_example() (kernel_services.py:1163) → engine._load_template_example() (engine.py:9040) → the same get_example_html, same EXAMPLE_MAX_CHARS cap, same swallow-and-return-None policy — and the sibling capability context_providers/opendesign.py:128-135 was already consuming it correctly. It survived ~3 weeks because the contract lived ONLY in lint-imports, a separate binary that must be invoked from backend/ (from the repo root it prints "Could not read any configuration" and exits, which reads as a pass).
