## What was wrong

Four tests were pinned with `@pytest.mark.xfail(reason="… unfixed", strict=True)` against issues that had already been resolved in the application code. With `strict=True`, a test that passes when it is expected to fail causes pytest to report `XPASS` — a hard suite failure. The underlying issues (ISS-592, ISS-593, ISS-594, ISS-320) were fixed but their markers were never cleaned up, so every run broke the suite.

The fifth problem was in `test_overlays.py` S-15-01: the test carried `@pytest.mark.defect` and had an *inverse* defect guard — `assert dialogs(page) > 0` (asserting the dialog was still open after Escape) with the message "Escape now closes the inspect dialog — the spec's S-15-01 can be asserted in full". That message was the defect-is-gone signal, and the assertion was failing because Escape now correctly closes the dialog.

## Root cause

Stale test markers. The application defects were fixed (ISS-592/593/594 in the library filter-preservation work; ISS-320 via the constitution-clear confirmation dialog added in FIX-385/FIX-386; S-15-01 Escape handling fixed in the catalog inspect dialog). The test markers were not updated at the time the defects were closed.

## What changed and why there

### 1. `test_iss592_agent_detail_close_preserves_filter.py` (line 28)
Removed `@pytest.mark.xfail(reason="ISS-592 unfixed", strict=True)`. Retained `@pytest.mark.issue("ISS-592")`.

### 2. `test_iss593_skill_detail_close_preserves_filter.py` (line 26)
Removed `@pytest.mark.xfail(reason="ISS-593 unfixed", strict=True)`. Retained `@pytest.mark.issue("ISS-593")`.

### 3. `test_iss594_hook_detail_back_button_loses_search.py` (line 28)
Removed `@pytest.mark.xfail(reason="ISS-594 unfixed", strict=True)`. Retained `@pytest.mark.issue("ISS-594")`.

### 4. `test_settings.py` (line ~454)
Removed `@pytest.mark.xfail(reason="ISS-320 unfixed", strict=True)`. Retained `@pytest.mark.issue("ISS-320")` and `@pytest.mark.destructive`.

### 5. `test_overlays.py` S-15-01 (`test_inspecting_a_catalog_workflow_describes_it_without_launching`)
- Removed `@pytest.mark.defect` from the test decorator.
- Renamed the shot from `"inspect-escape-ignored"` to `"inspect-escape-closes"`.
- Replaced the inverse defect guard `assert dialogs(page) > 0` with the positive assertion `assert dialogs(page) == 0` confirming Escape closes the inspect dialog.
