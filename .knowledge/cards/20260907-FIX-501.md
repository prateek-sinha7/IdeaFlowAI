## Symptom

Every Bedrock call failed with `ValidationException` from the Converse API
once `effort` was passed inside `additional_model_request_fields`.

## Cause

`effort` is a direct Anthropic API field. Bedrock's adaptive thinking accepts
`{type: adaptive}` and no additional sub-fields; anything extra is rejected
outright rather than ignored.

## Fix

Reverted on both paths — the Bedrock path and the Anthropic path — rather than
branching on provider, since the parameter bought nothing on either.
