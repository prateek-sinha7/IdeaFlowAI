## Description

Config lever dropdown clicks do nothing — fix by hoisting CustomSelect/LeverRow to module scope

## Root cause

CustomSelect and LeverRow were defined inside ConfigLeversFlat body. React treats inline component definitions as new types on every render, causing remount instead of update when an option is clicked — breaking the selection. Hoisted to module-level ConfigLeverRow + ConfigLeverSelect with all state passed as props.
