# ISS-675

## Status: found by the 5-fixer, not fixed, not reproduced live

[FIX-521](20260917-1447-FIX-521.md) fixes [ISS-673](20260917-1420-ISS-673.md) for every run this
tab is streaming. It cannot help a run that this tab never streams, and this card records that
gap so it is not rediscovered as "QA-PS-002 came back".

## Mechanism (read in code, line numbers as of FIX-521)

1. `AppHeader.tsx:204` shows `runAgentsCompletedMap?.[r.id] ?? 0` for every live run in
   `recentRuns` that is not the viewed one. `recentRuns` is `GET /api/runs`, so it lists the
   user's live runs from every tab.
2. `page.tsx:3912-3918` fills that map only for runs that have a `runStore` entry.
3. A run gets an entry only through `runStore.handleFrame`, which page.tsx calls only for frames
   that are not foreign (`page.tsx:1370`, `launchedRunIdsRef` = runs this tab launched).
4. `RunConnectionProvider.tsx:298-313` (KAN-125) attaches a stream only for runs in this tab's
   `sessionStorage.tab_launched_run_ids`. A new tab starts with that set empty.

So a run started in a different tab, or in a tab that has since been closed, is listed as live but
has no store entry, and this tab shows "0 of N agents" / 0% for it however far it has progressed.
[ISS-658](20260917-1302-ISS-658.md) first noted this; its "Likely cause" section names the attach
scope.

## Why it was not fixed with FIX-521

Both ways out need a decision that is not a fixer's to make. They are the options already listed
in [ESCALATIONS.md#qa-ps-002](../../ESCALATIONS.md#qa-ps-002):

- **Server count:** add a completed-agent count to `GET /api/runs` (`WorkflowRun` has only
  `agentCount` today, `lib/api.ts:754`) and use it as AppHeader's fallback. This changes an API
  contract.
- **Attach every live run:** stream all of the user's live runs in every tab. This reverses the
  KAN-125 multi-tab isolation.

## What would confirm this

Launch a run in tab A. Open a fresh tab B on `/dashboard`, wait for tab A's run to finish two or
more agents, then open the bell panel in tab B. It should read "0 of N agents" while tab A's
`/runs/<id>` page shows the real count.

## Traceability

Found while fixing **QA-PS-002** (`BUGS.md` / `LEDGER.md`). Not reported by QA. The QA repro
launched its runs from one tab, which FIX-521 covers.
