## Description

Make all custom-composer runs consistent — always pipeline_type="custom"

## Root cause

User story agents were routed to pipeline_type="user_stories" making history/logs inconsistent with prototype runs (which stayed "custom"). Fix: removed the user_stories routing branch from resolveDispatchType; added user story agents to AGENT_DELIVERABLE_MAP with {strategy:"streamed_text", name:"user_stories.md", mimetype:"text/markdown"}. Engine _apply_selections already handles the override + forces clarify.mode=skip. Output renders via GenericDeliverablePreview → MarkdownPreview. All custom-composer runs now consistently show type=custom in logs and history.
