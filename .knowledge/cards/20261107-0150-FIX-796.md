The classifier was added next to `_sanitize_agent_error` and walks the same needles. The code is emitted on the
`agent_error` event, `_log_event`, `RunLog.write` and the server WARNING (`raw=... | client=... | code=...`). The frontend
stores it as `AgentRunState.errorCode` and `AgentDetailPanel` shows `code: X · step: Y` when present.
