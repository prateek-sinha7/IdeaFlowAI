Opening Advanced on any `ex_*` fixture showed an empty panel — no agent rows, no canvas,
nothing to configure.

## Root cause

```js
LIBRARY_AGENTS.filter((a) => a.pipeline_type === effectiveType)
```

`LIBRARY_AGENTS` is sourced from `AGENT.md` files. A composed workflow's steps are
instances of the `custom-agent` template and have no `AGENT.md`, so there is no agent
anywhere in the library whose `pipeline_type` is `ex_A2_branch`. The filter returned `[]`.

## Fix

Fall back to the compiled manifest's steps (already fetched for the capabilities strip)
when the library has nothing for this type. The condition is STRUCTURAL — "the library has
no agents for this pipeline_type" — not a `custom`-name branch: only composed workflows
have no `AGENT.md`-backed agents, so it selects exactly that set without hardcoding a name
(SC-001).

Depends on [FIX-280](20260824-1617-FIX-280.md) and
[FIX-281](20260824-1617-FIX-281.md) — before those the fallback data was unusable
(raw ids, order 0, no prompts).
