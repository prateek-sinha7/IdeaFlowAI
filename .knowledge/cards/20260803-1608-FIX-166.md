## Description

Build Agent task list shows all tasks upfront — store total_tasks from task_loop_progress

## Root cause

Frontend task_loop_progress handler read task_number but discarded total_tasks (present in backend payload since task_loop.py Phase 7). AgentThinkingTab derived totalTasks from wave universe/completed count (both 0 at build start). Fix: add protoTotalTasks to PipelineRunState, store it in task_loop_progress handler, prefer it in AgentThinkingTab totalTasks derivation
