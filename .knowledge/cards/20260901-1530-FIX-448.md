## What was confirmed

Both [ISS-388](20260828-2234-ISS-388.md) (the `/preview/full` still-building run
silently landing on Steps) and [ISS-389](20260828-2234-ISS-389.md) (a failed run
with zero `hook_runs` rendering "No audit records yet" instead of the no-deliverable
affordance) were documented as INFERRED in their cards — confirmed by reading the
source, not by independent browser reproduction.

[FIX-358](20260829-0011-FIX-358.md) explicitly notes both in its **Notes for the
next session** block:

> *ISS-388 and ISS-389 are cured by this same change on the code path, but both are
> still `status: open` and were NOT re-driven in a browser here — they are INFERRED
> cards with `verification.type: manual` and no test file.*

## Evidence this domain verified

Domain 5 (Batch 2) confirmed FIX-358 is fully landed:

1. **Code inspection**: `PreviewPanel.tsx` at the Preview tab render branch carries
   `showFailureAffordance || showDivertedAffordance` (not just `showCancelledAffordance
   || showDivertedAffordance` as before FIX-358). With a deep-link nonce for
   `"preview"` set by the now-existing `run-preview-full` case in `reopenTabFor`,
   `activeTab` is forced to `"preview"` for terminal-failed runs — `AuditTab` is
   never mounted in its place, so the zero-record "No audit records yet" string
   cannot surface (ISS-389). The same deep link for a building run sets
   `activeTab = "preview"` before the generic state ternary runs — Preview shows its
   own "Building your deliverable…" branch (ISS-388).

2. **Regression suite**: `PreviewPanel.degraded.test.tsx` — 11/11 passed
   (observed 2026-09-01, DEGRADED_EXIT=0). This suite includes:
   - "reopen+failed → drops the Preview tab, defaults to Audit": proves the plain
     run screen (no deep link) still defaults to Audit on failure — the base
     behaviour FIX-358 was careful not to change.
   - "reopen+cancelled → shows the cancelled-specific copy": the affordance copy
     branch that ISS-388's fix path also threads through.

## No new code

No production source changed for ISS-388 or ISS-389. Cards are closed on the
