# ADR-0007

## Decision

In the context of custom-agent artifact filenames formatted `<instance_id>.<topic>.md`,
facing a small local model reading the dot as a path separator and writing
`/joke/mountain.md` so the downstream step read a sentence about the file instead of the
file, we decided the separator is a hyphen, to achieve a name that cannot be mistaken
for a directory, accepting a one-time rename of an artifact convention that no released
workflow depends on.

**Area:** agents, artifacts, workflow
