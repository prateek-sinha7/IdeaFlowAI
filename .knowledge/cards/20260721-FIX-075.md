## Description

Config lever option clicks close dropdown without selecting — add onMouseDown stopPropagation to listbox div

## Root cause

The document mousedown listener (used for outside-click dismiss) fired when user clicked an option button, calling setOpenLever(null) and unmounting the dropdown before the click event registered. Fixed by adding onMouseDown stopPropagation to the listbox div so options receive their click events.
