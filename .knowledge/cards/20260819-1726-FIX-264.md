## Persist per-agent resolved model into agent_outputs and the summary allow-list

Fixes [ISS-165](20260819-1726-ISS-165.md) — see that card for the root cause. Closes the persistence half
[BUG-CWF-002-custom-workflow](20260803-BUG-CWF-002-custom-workflow.md) left open (that fix covered live emission only).

**Changes:**
- `backend/app/api/run_commands.py` — `_apply_terminal_output_columns`'s
  `agent_complete` accumulator branch now sets
  `current_agent["model_id"] = data.get("model_id")`, alongside the existing
  token/duration fields. This is the sole writer of `WorkflowRun.agent_outputs` for all
  4 completion paths (launch, both resume entry points, revision), so one change
  covers all of them.
- `backend/app/api/runs.py` — added `"model_id"` to `_SUMMARY_SAFE_AGENT_KEYS`, so
  `GET /api/runs/{id}/summary` actually returns the persisted value instead of
  filtering it out.

`WorkflowRun.model_id` (the single run-level column, sourced from
`user.preferred_model`) is intentionally left unchanged — redefining its semantics is
a separate design question, not this bug. Additive-only change; no existing consumer
reads a fixed-shape `agent_outputs` schema.
