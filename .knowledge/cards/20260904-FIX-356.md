## Related

## What was wrong

Workspace was minted after ingest, so if ingest failed mid-stream, no 
durable mirror would be created and uploaded files would be orphaned.

## The fix (commit 1e329e47b)

- Mint workspace BEFORE ingest starts.
- Durable mirror is guaranteed to exist, even if ingest fails.
- If ingest fails, the workspace and mirror persist for recovery.
- No orphaned files: the workspace structure is complete.

Pinned by test_run_files_upload.py verifying that workspace is created 
before ingest and persists on failure.
