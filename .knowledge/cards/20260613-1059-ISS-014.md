# ISS-014

## Title

The **agent-level** custom composer IS live and well-built — the "Compose a custom workflow" tile → IdeaInputPage → Advanced → "Workflow configuration" modal (Agents / Skills & Hooks tabs, drag-to-reorder, "+ Add agent (8 left)") → a searchable "Add agent" library (category sidebar + agent cards with descriptions + "+ Add"). What's dead is only the **capability-level** `CapabilityPalette.tsx`/`WorkflowComposer.tsx` (the `/api/capabilities` allow-listed-palette composer) — mounted by no live route. So users CAN compose custom agent workflows; they CANNOT compose from the capability palette.
