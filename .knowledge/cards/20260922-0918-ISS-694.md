## What happened

On `/create/prototype`, the "Configure your prototype" step's template grid
shows a first card, pre-selected by default, labeled **"No template"** with
subtitle "Blank canvas". Since this card is the pre-selected default among 48
named templates (not an absence of any selection), the label reads as
"nothing applied" rather than "this is the default starting point". Expected
label: **"Default Template"**.

Reported as QA-PS-012 (register: `LEDGER.md`, detail: `BUGS.md#qa-ps-012`).
Severity: Low — copy-only, no functional break.

## Root cause

`frontend/src/components/workflow/prototype/TemplateGallery.tsx:328-364`,
component `NoTemplateCard` (added under ticket KAN-87, see the comment at
line 328):

```tsx
function NoTemplateCard({ selected, onSelect }: { selected: boolean; onSelect: () => void }) {
  ...
      <div className="px-2 py-1.5">
        <span className="block truncate text-[11px] font-medium text-ink-800 leading-tight">
          No template
        </span>
        <span className="text-[9px] uppercase tracking-wide text-ink-400">
          Blank canvas
        </span>
      </div>
  ...
}
```

The card's label text is hardcoded to `"No template"` — a literal string, not
derived from a data source. This card is rendered first in the grid and is
selected by default (see the comment at line 215: "No template / blank canvas
card — shown first in All tab"), so it is functioning as the wizard's default
option while its copy describes it as the absence of one.

## Reproduction — CONFIRMED 3/3, cold start each cycle

1. **Cycle 1:** fresh login as `qa-admin@flowinqa.com` → direct navigation to
   `/create/prototype` → first template-grid card reads "No template" /
   "Blank canvas". Evidence: `evidence/create-prototype/qa-ps-012-cycle1.png`
2. **Cycle 2:** full-reload navigation to `/create/prototype` with the
   session already established → identical label.
3. **Cycle 3:** `localStorage.clear()`, fresh re-login, fresh navigation to
   `/create/prototype` → identical label. Evidence:
   `evidence/create-prototype/qa-ps-012-cycle3.png`

No axis variation was needed to trigger it — it reproduces unconditionally on
every visit as `qa-admin`; the string is static, not conditional on tier,
theme, viewport, or run/session state.

## Expected vs actual

- **Expected:** first card labeled "Default Template" (subtitle "Blank
  canvas"), signalling it is the pre-selected default starting point.
- **Actual:** labeled "No template", implying no template will be applied at
  all.
