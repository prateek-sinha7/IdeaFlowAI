## Why the lifecycle is the hard part, not the tools

The nine tools are thin. What the spec actually had to get right is that a
browser is *stateful across tool calls* — `playwright_click` only means anything
on the page `playwright_navigate` left behind. That rules out the obvious
Python idiom: `async with` around the browser tears it down at the end of every
call, which is precisely the regression FIX-307 recorded.

So the session outlives individual calls, and something else has to end it.
`ExecutionEngine.execute()` had no `finally:` at all, which meant a cancelled or
abandoned run left Chromium running. The release now sits in a `finally:` that
covers `GeneratorExit` as well, because a streaming engine is a generator and
cancellation reaches it that way rather than as an exception on the happy path.

## The URL-policy bug, and why it survived review

`BROWSER_URL_POLICY` defaults to `file,localhost`. The first implementation
branched on "does this string have a scheme" — and a `file://` URI does, so it
fell into the http(s)-only branch and was refused even with `file` in the
policy. Only a bare path ever reached the sandbox-resolution branch. It read
correctly and was wrong; it took live validation to surface, which is the
argument for validating a policy against both spellings of the same input.

## Temporary, and deliberately so

`backend/agents/workflows/playwright_smoke_test/` is a single-step pipeline that
exists to exercise all nine tools without waiting on a full ppt_v2 run. It is
entitled on the enterprise tier in BOTH `entitlements.py` and its frontend
mirror `entitlements.ts` — the two drifted on the first pass, the same gap the
`ex_A*` fixtures hit. **Delete it when spec 018 closes.**
