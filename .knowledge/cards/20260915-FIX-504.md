## What happened

Multiple gaps in the sandbox git-versioning implementation (spec-019) were
identified in `GIT_VERSIONING_BUGS.md` across P0, P1, and P2 priority tiers.

## Fixes applied

### P0
- **B17** — `_ReservedPathGuardMiddleware._normalise` lacked `posixpath.normpath`,
  so embedded `../` sequences (e.g. `sub/../.chain/x`) bypassed the
  reserved-prefix check. Fixed by normalising before the check; matching fix
  in `TestReservedPathGuardLogicWithoutDependencies`.
- **B3** — Saved-workflow chain launch was broken: `WorkflowHistory` did not
  accept `savedWorkflows` prop or pass `userWorkflowId` through
  `onChainPipeline`. Fixed in `WorkflowHistory.tsx` and `DashboardLayout.tsx`.
- **B4** — ppt strategy branch in `build_flat_payload` did not materialise the
  deck from `ectx.last_streamed`; completed ppt runs now publish `completed`
  and mint `vN` tags via a four-step carousel-sanitize pipeline.

### P1
- **B5** — `source_payload_missing` always raises HTTP 422 (degrade path blocked).
- **B8** — `custom-revision-planner` and `custom-revision-builder` registered
  for `custom_revision` pipeline; `handleReviseCustom` wired in
  `DashboardLayout`.
- **B9** — `SandboxTab.test.tsx` `toHaveBeenCalledWith` calls updated with
  `ref` argument.

### P2
- **B18** — 10 vacuous source-inspection assertions in
  `test_phase6_sandbox_versioning` replaced with 5 real behavioural tests
  (resume, rebuild, restore, policy).
- **B19** — `test_prompt_ledger_v2.py` rows rewritten as full-composer
  behavioural tests via `_EngineHarness`/`_drive_agent` (54 tests).
- **B20** — Module-level `test_deepagents_package_is_installed` canary added
  to `test_reserved_path_registry.py` (`pytest.fail` not `skip` when absent).

## Integration tests added
- `backend/tests/integration/test_git_versioning_e2e.py` — 9 offline tests
  covering commit message, commits, agent files on disk, revision ordinal,
  chained-run `.context/` presence, cancel wip-commit + no-tag, post_run hook,
  restore forward-commit contract, and uploaded-files path.
- `frontend/src/components/preview/VersionSwitch.integration.test.tsx` — 10
  tests for version-switch flow (menu positioning, ref= API calls, read-only
  banner, back-to-latest, usable-while-running, no restore control).
