# ISS-860

Found while writing [FIX-641](20260923-0229-FIX-641.md). Not fixed there. It is a
test-fixture defect in a CLOSED bug's file (QA-PS-027), and QA-PS-021 did not ask
for it.

## What is wrong

`test_native_prototype_pipeline_placeholder_output_not_marked_completed`
([ISS-761](20260922-1424-ISS-761.md)) says its build agent "only streams placeholder
text, then reports the task complete". The harness does not do that:

- `_prototype_placeholder_scripts` gives `prototype-build` exactly ONE
  `_ScriptedTurn`, and that turn carries a `report_task_complete` tool call.
- `ScriptedFakeChatModel._next_turn` (`tests/agents/_scripted_model.py`) returns
  `turns[idx] if idx < len(turns) else turns[-1]`. Once the script runs out, the model
  replays that tool-call turn forever.
- The graph never reaches a stop condition. The captured log of the test shows
  `deep_agent_runner.py:1298 DeepAgentRunner.astream_events failed: Recursion limit of
  1000 reached`, followed by `engine.py:9586 Agent prototype-build: runner surfaced an
  error event — marking failed (no completion)`.

So the scenario being tested is "the build agent errored", not "the build agent
cleanly reported completion without writing". Each run also spends about 10 s on the
1000-step loop.

## Why it is low severity

The test still proves what it exists to prove. With FIX-612's gate neutralised
(`agents.capabilities.deliverables._placeholder.placeholder_narration_reason =
lambda *a, **k: None`), the test fails at its `published_status` assertion. That was
observed during FIX-641. The failed build agent does not publish a degraded status
in this harness, because the test stubs `finalize_terminal_run` with a clean record.
The placeholder gate is the only thing that degrades the run.

## Fix direction (not applied)

Give `prototype-build` a second, text-only `_ScriptedTurn` after the tool-call turn,
so the graph stops cleanly. Then re-check the test's `final_output` precondition.
Branch 3 reads `ctx.last_streamed`, so the expected value may shift with the change.
