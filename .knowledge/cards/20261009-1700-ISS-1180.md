# ISS-1180

**Found during:** [FIX-779](20261009-1659-FIX-779.md) (`QA-KB-109`, 5-fixer, 2026-10-09), while type-checking that change. Not caused by
it: none of the seven files is in its diff, and `admin/page.tsx` exports nothing they import.

**Confidence:** CONFIRMED that the command fails at HEAD; INFERRED why each line fails (read from the compiler messages only, no file
was opened to trace it).

## Condition

`tsc --noEmit -p .` from `frontend/`, on a clean export of HEAD `9cd0d6c5a` (`git archive HEAD frontend`, `node_modules` linked):
13 errors, all in test files, all committed and unmodified in the working tree. Per file: `AnalyticsPage.test.tsx` 1,
`DashboardLayout.chain.test.tsx` 2, `WorkflowHistory.modelChip.test.tsx` 3, `PreviewPanel.liveVersion.test.tsx` 1,
`AgentDetailPanel.waveWorkerStatus.test.tsx` 4, `useWorkflow.imagePayload.test.ts` 1, `RunConnectionProvider.test.tsx` 1.

That is the exact command of CI's `frontend-static` job: `ci/frontend-static-checks.json` runs `npm --prefix ../frontend run
typecheck` (`package.json:17` `"typecheck": "tsc --noEmit"`) with `"mandatory": true`, and the job fails if any mandatory check fails
(`.github/workflows/ci.yml` "Run frontend static checks (all, then fail if any failed)").

## Expected vs actual

Expected: `npm run typecheck` exits 0, as a mandatory CI gate. Actual: 13 errors. The tests themselves pass, because vitest
transpiles without type-checking, so nothing local turns red.

## Mechanism (INFERRED from the messages)

Each error is a test fixture or mock that no longer matches the type it stands in for: a `WorkflowRun` literal missing `createdAt` and
`agentCount` (`DashboardLayout.chain.test.tsx:145`), a call with two arguments to a zero-argument signature (`:43`), a `string`
assigned where `AgentThinkingEntry[]` is now expected (`WorkflowHistory.modelChip.test.tsx:194,223,244`), a `vi.fn()` mock not
assignable to a `(runId, tab) => void` prop (`PreviewPanel.liveVersion.test.tsx:94`), an object literal not assignable to
`RunConnectionContextValue` (`useWorkflow.imagePayload.test.ts:32`), values typed `never` (`AnalyticsPage.test.tsx:363`,
`AgentDetailPanel.waveWorkerStatus.test.tsx:370,387`, where the same lines also report "not callable"), and an index into an empty
tuple type (`RunConnectionProvider.test.tsx:630`). The full compiler output is the evidence file below.

## Disposition

Open, unscheduled. Fix direction (INFERRED): bring each fixture up to its current type, test files only, one file at a time,
`npm run typecheck` as the check. No application change is implied.
