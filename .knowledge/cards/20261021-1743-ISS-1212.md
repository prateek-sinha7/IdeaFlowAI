## What fails

Found while verifying [ADR-0056](20261021-1743-ADR-0056.md); unrelated to it. All
four fail identically at `82132faf9` in a clean detached worktree, so they
predate that change.

| Test file | Error |
|---|---|
| `src/app/[...view]/initialWorkflowType.bug023.source.test.ts` | `ReferenceError: initialWorkflowTypeFor is not defined` |
| `src/components/layout/DashboardLayout.iss1154.test.tsx` | `ReferenceError: initialMainViewFor is not defined` |
| `src/components/workflow/WorkflowView.attachmentMarkerNames.test.tsx` | `Error: stripAttachmentMarker not found in WorkflowView.tsx` |
| `src/app/[...view]/bgTerminalClarify.qaKb035.source.test.ts` | 4 tests: `expected -1 to be greater than 109527` and `SyntaxError: Unexpected token 'switch'` |

Each reads a production file as text and extracts a function or block by
pattern. The pattern no longer matches the current source, most likely because
the function moved or was reshaped. Not diagnosed.

## Disposition

Open. Each test needs either its extraction updated to the code's current shape
or a rewrite against the exported function. `npm run test` exits 1 until then.
