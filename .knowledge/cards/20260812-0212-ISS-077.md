# ISS-077

## Title

**`ArtifactNode`'s TypeScript declaration disagrees with the wire shape on three fields.** `frontend/src/lib/api.ts:602-604` declares `derived_from: string[]` and `children: string[]`, but the backend returns `derived_from: string \| null` (`runs.py:920`) and `children: ArtifactNode[]` (`runs.py:921`); `task_id` is declared `string` but is `null` on every row observed. Nothing reads those three fields today — `WorkflowHistory.tsx:303` and the new `ArtifactVersionPicker` both use only `kind` / `version` / `content_hash` / `producer_agent` / `id` / `content` — so nothing is broken, but the first consumer of the lineage tree will be type-checked against a lie and will write `.map()` over a nullable string. The same file's docstring also cites `runs.py:590-608` for the node shape, which has drifted; the real `_node` is `runs.py:907-925`.
