## Why the extension, not the workflow

`ppt_v2` declares `presentation.html` deliberately (see ADR-0029) but the file a
user sends is the PowerPoint. Keying the preference on the declared extension
gets that without a workflow-name check, and repairs plain `ppt` in passing: it
declares `presentation.pptx` while nothing in it emits PptxGenJS, so that file is
never on disk and the button used to be dead.
