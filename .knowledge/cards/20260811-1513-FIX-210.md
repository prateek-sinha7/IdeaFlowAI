## Description

Concierge proposal chips not appearing; revision confirm posting wrong run; revision UI not switching to new run

## Root cause

(1) Concierge called propose_chain but chain_hints had no target_id exposed — only labels. (2) Confirm POST hit wrong run_id after view switched to child run. (3) handleRevisionLaunched missing attachRun + switchViewTo. (4) sendCommand wrapper discarded return value. (5) concierge_proposal inline SSE frames had no event_id (dedup broken). (6) _dispose_concierge_proposal returned no params in held dict.
