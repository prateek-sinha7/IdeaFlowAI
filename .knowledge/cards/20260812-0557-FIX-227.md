# FIX-227

**Phase / trigger:** quick-260812-7sk

> No detail section exists in the register for this entry — only the
> summary-table row below. Nothing has been invented to fill the gap.

## Description

There was NO way for anyone — user or operator — to stop a running build once it had crossed a backend restart, and every un-stoppable od_prototype build costs 5–21M Bedrock tokens of the owner's money. The whole escalation ladder was broken: UI Stop no-op; POST /api/runs/{id}/cancel → HTTP 200 {"cancelled":true} with the run still generating; SIGTERM ignored (local uvicorn has no --timeout-graceful-shutdown, and SHUTDOWN_STOP_RUNS is False anyway); and kill -9 finished the run, because restore_non_terminal_runs re-adopts every non-terminal row on the next boot. Measured on run d5dbc9f2: 16,530,718 tokens total, of which 7,510,082 (45%) were billed AFTER the API answered cancelled: true, with zero pipeline_cancelled events on the run — the entire dev DB contains exactly one such event ever, and its payload shows it came from a destructive task.cancel(), never a cooperative Stop.

## Root cause

Two defects, one upstream of every loop. (1) ExecutionEngine._drive_resumed_stream (engine.py:8310-8332) — the ONE funnel all four resume drivers reach the kernel through — passed _execute_impl no cancel_event kwarg at all, so it bound its None default (engine.py:1096) and all twelve cooperative guards, each written if cancel_event and cancel_event.is_set(), short-circuited. The guards were never wrong; the value was. Structural since 83cfff4c (2026-06-11). (2) run_engine._register_resume_task minted an orphan asyncio.Event into _CANCEL_EVENTS for exactly those runs, on a premise its own comment asserted and that was false the day it was written — so cancel_run found one, set it, and reported registry mutation as cancellation. 849e536d/KAN-88 (2026-06-30) had simultaneously deleted the working destructive fallback, and Phase 44's REST port dropped it entirely: after that there was no path, cooperative or destructive, by which a user could stop a resumed run.
