## Root cause
On Windows, `asyncio.create_subprocess_exec` raises `NotImplementedError` under a SelectorEventLoop. `render_pdf` failed,
`export_backlog` caught it and skipped `Backlog.pdf`. `workflow.yaml` declares `Backlog.pdf` as the deliverable, so
`finalize_terminal_run` found it unmaterializable, fell back to a metadata-only snapshot and published `degraded` with
`payload_chainable=False`, even when all 21 agents completed.

## Evidence level
Mechanism from the commit message; the guard and wrapper were read at `backlog_export.py:756-778`. No Windows run was
observed for this card. The win32 branch has no direct test per the commit message.
