# ISS-1052

This card holds the product half of [ISS-981](20261002-0409-ISS-981.md) part B. [FIX-720](20261007-1756-FIX-720.md)
resolved ISS-981's defect half: the orphan `pending` audit row, and the false, duplicated `stripped` rows. ISS-981 itself
called the rest "INFERRED until the owner says ... Settle it before changing behaviour". This card keeps that question
open, so it does not close along with ISS-981. It is not a defect until the owner decides it is.

## What happens

- **By code reading of the tree at `afdeefa03`.** `_launch_run_core` replaces the content only when text comes before the
  marker: `if _stripped_content:` (`backend/app/api/run_commands.py:2989`). A message that is only the block keeps its
  content, and since FIX-720 nothing is recorded for it.
- **Observed before FIX-720.** The analyzer's probe E3 (`evidence/qa-kb-057/04-analyze-probe-output.txt`, section 3)
  saw HTTP 200 with `chain_v2_accepted: true`, and the persisted `WorkflowRun.input` was the whole
  `=== CONTEXT FROM PREVIOUS PIPELINE ===` block. So both the v2 `.context/` payload and the legacy block reach the run.
  FIX-720 kept the content outcome on purpose: before and after, the original content stays.

## Why it is a question

- **For keeping it.** The removed endpoint-level copy of the guard kept the block deliberately, with the comment "edge
  case: message IS the context block". The likely reason is that a stripped, empty brief would be refused by the
  ISS-155 empty-brief gate, `if not (content or "").strip():` (`run_commands.py:3426`). That reason is INFERRED; the
  comment never said why.
- **Against keeping it.** The shipped contract text in `frontend/src/lib/workflowChaining.ts:120-123` says: "The
  backend strips the legacy `=== CONTEXT FROM PREVIOUS PIPELINE ===` block when `source_workflow_run_id` is also present
  (task 9.3 / Req 13 AC 11), so the two are never combined."

## Decision needed

What should happen to a chained launch (`source_workflow_run_id` set) whose message is only the legacy block?

- (a) Keep it as today: the block and the v2 payload both reach the run.
- (b) Strip it and let the empty-brief gate refuse the launch.
- (c) Strip it and launch with an empty brief, which means the empty-brief gate must waive admitted chained launches.
