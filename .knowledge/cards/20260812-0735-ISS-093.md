# ISS-093

## Title

**3 stale clarify-round tests in `backend/tests/unit/test_execution_engine.py` assert an event vocabulary the product no longer emits.** `test_clarify_engine_asks_once_then_limit_reached` (:152), `test_clarify_engine_rounds_knob_allows_multi_round` (:186) and `test_clarify_engine_empty_submit_proceeds_after_one_round` (:309) expect `clarification_limit_reached`; the engine now emits `['questionnaire_ready', 'questionnaire_complete']`. Reads as fallout from **ISS-027**'s "Option A force-proceed" change, which replaced the limit-reached path — the tests were not reconciled with it. Classify before fixing: this is *changed behaviour* (reconcile the assertions to the current vocabulary), **not** selector drift, and the tests must not simply be deleted.
