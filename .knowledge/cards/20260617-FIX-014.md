## Description

PPT preview shows validator checklist text instead of deck — checkbox syntax causes model to print results

## Root cause

od-ppt-validator/AGENT.md used - [ ] checkbox syntax for the checklist; Haiku prints ticked ✓ results (e.g. "✓ No stray markdown fences... P1 — Content quality:"). unwrap_artifact() finds no <artifact> tag → returns raw checklist as deliverable. Fix: replaced [ ] checkboxes with imperative commands; added explicit ❌ FORBIDDEN rules naming the exact output pattern; strengthened RULES with specific anti-pattern example
