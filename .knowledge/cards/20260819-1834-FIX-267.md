## Sequence Reasoning-then-Output as a real transition with stick-to-bottom scrolling

Fixes [ISS-169](20260819-1834-ISS-169.md) — see that card for what was wrong.

**`AgentDetailPanel`:** added `outputStarted` state — `false` until `agent.output`
first goes non-empty, reset per `agent.id` (mirrors the existing `viewed` reset
pattern, since this component is reused across agents rather than remounted).
Reasoning's `live` prop is now `isRunning && !outputStarted` and its new `defaultOpen`
prop is `!outputStarted`; Output only renders at all once `isRunning && outputStarted`.
Net effect: Output is invisible until the first token arrives, at which point
Reasoning collapses and drops its live tag in the same render, and Output becomes the
live one.

**`ReasoningCard`:** gained a `defaultOpen` prop, synced into local `open` state via a
`useEffect` keyed on `defaultOpen` — so the forced collapse doesn't fight a manual
re-expand afterward (the effect only fires when `defaultOpen` itself transitions, not
on every render). Also gained stick-to-bottom scrolling: a `stickToBottomRef` (a ref,
not state — scroll fires far too often to re-render on) tracks whether the reader is
within 24px of the bottom; the auto-scroll effect only forces `scrollTop` to the
bottom when that ref is true. Scrolling away disengages it for the rest of that
stream; scrolling back to the bottom re-arms it. Reopening a collapsed card also
re-arms it, so reopening always lands on the latest content rather than a stale
position from before it was collapsed.

**Spacing:** added `mb-3` to `ReasoningCard`'s outer wrapper, matching every sibling
card in the same list (`ValidationResultCard`, `RevisionInstructionCard`, etc.), which
already all used it.
