## What is broken

`test_sample_subagents_parallel_event_snapshot` fails at index 0:

```
actual: {'type': 'subagent_spawned', 'data': {'worker': 0, 'agent': 'custom-agent:apple', 'isolation': 'shared_read', 'depth': 0, 'task_id': None, 'task_author_id': None}}
golden: {'data': {'agent': 'custom-agent:apple', 'depth': 0, 'isolation': 'shared_read', 'worker': 0}, 'type': 'subagent_spawned'}
```

`agents/execution_engine/fanout.py` adds the two keys. `git log -S task_author_id` and
the golden's last change both point at `9efb704d` (#10), so the merge brought the code
without a matching golden.

## Disposition

Open. The failure is identical at `75a3c207` and after
[FIX-646](20261002-0332-FIX-646.md). Resolving it means either a sanctioned
`SNAPSHOT_UPDATE=1` re-pin with a reviewed diff, or adding the two keys to the
normaliser's volatile set. Either is an INV-3 decision, so it was not made here.
