## Two cleanups on the same surfaces

### The Chain action

The run-actions menu carried a "Chain" item that existed only to reach the
internal detail view's "Suggested next steps" panel — a second way into a screen
no normal user path mounts. It and the handler it needed are removed; `RowMenu`
keeps the actions that act on the row.

### ppt_v2 showed its raw manifest id

`SavedWorkflowsPage` and `WorkflowDetailView` each held their own copy of the
pipeline-id → display-name map, and **both** were missing `ppt_v2`, so a saved
deck workflow showed the raw manifest id to the user.

One map, `pipelineLabel.ts`, is extracted and imported by both, with the missing
entries added. A duplicated lookup table drifts by construction: the second copy
is only ever updated when someone notices the first was.
