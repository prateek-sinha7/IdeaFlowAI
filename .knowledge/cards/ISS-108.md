# ISS-108

## Title

clarifications accumulates with no identity and no per-run reset outside startPipeline. useWorkflow.ts:168 does clarifications: [...(prev.clarifications ?? []), round] inside retainClarifyRound, a direct UI call made when the questionnaire panel unmounts. Because it carries no frame, ISS-082's frame-identity gate cannot reach it — it is registered in the accumulator registry as driver: "ui" precisely so GUARD-1 still sees it, but its multiplicity cases are not driven. The per-run boundary is startPipeline's explicit clarifications: []; pipeline_start spreads ...prev and never clears it, so a path that reaches a new run without startPipeline (a history reopen, a chained run) would carry the prior run's rounds. Not observed — flagged, not claimed.
