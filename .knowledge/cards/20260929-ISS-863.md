## What is diverging

`test_routed_build_prompt_equals_oracle_byte_for_byte`,
`test_routed_build_task_2_equals_oracle_byte_for_byte`,
`test_routed_build_prompt_has_template_compliance_now` and
`test_regenerated_golden_build_prompt_equals_oracle[prototype.events.json]` assert
the routed prototype-build `context_message` equals the pre-Phase-7 (`acd1636`)
oracle. M10 (GAPS §0.2 / §0.3 step 0, FR-030 rows 20/21) removed that paste on
purpose — the agent now reads `.context/design/` itself — so the tests xfail on
every run. GAPS's FR-030 row 20 already anticipated this drift.

## Why a card

CI's offline partition rejects every skip/xfail except an `xfail(strict=True)`
carrying an `issue` marker (tools/ci/inventory_cli.py `verify-execution`). The
tests were `strict=False` with no card, so they failed the gate on a green tree.

## To close

Either an approved removal of the four tests (the contract they pin no longer
exists in the product; test-structure rules require the approval), or a
re-targeted oracle for the governance policy's intended contract.
