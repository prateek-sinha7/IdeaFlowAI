## Description

specRevisionCount over-counting — shows "Cycle 6" after 1 update_specs click

## Root cause

Detection incremented counter for EVERY agent_start of a "done" agent; update_specs re-runs 3 agents so 1 click = +3 (or more). Fix: arm/consume pattern — counter only increments once per revision cycle (when first agent re-starts), not once per agent
