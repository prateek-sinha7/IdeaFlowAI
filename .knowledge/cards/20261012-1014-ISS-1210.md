# ISS-1210

Found while fixing `QA-KB-117` ([FIX-785](20261012-1013-FIX-785.md)). Status: open. This is a spec-prose correction only; no test and no app code is involved.

## What is stale

`tests/integration/screens/09-settings.feature.md:92-99` reads:

> **Usage & Limits** — plan name, ..., `Manage plan`, then `DELIVERABLE ACCESS`:
> Product Requirements, Presentation, Interactive Prototype, App Builder, Custom
> Workflow, Platform Workflows, Mulesoft Migration, .NET Migration.
>
> This list is the user-facing face of `TIER_PIPELINES`. Notably it does **not**
> list the seven `ex_A*` fixtures, even though the enterprise tier is entitled to
> them and they appear on the home catalog — a second inconsistency behind D-04.

After FIX-785 the grid lists what the home catalog enables for the tier: launchable, non-beta, entitled rows, with the Engine examples in their own group. For enterprise, Platform Workflows, Mulesoft Migration and .NET Migration are therefore gone, and the Engine examples (eight of them, not seven) are listed. Both sentences now describe behaviour the app no longer has. The scenarios in the same file, S-09-09 and S-09-10, are unaffected: they assert "Product Requirements" and "Custom Workflow", and both labels were kept.

## Why it was not fixed with FIX-785

No QA-KB-117 card names this file. It is in the globs of [ISS-1203](20261012-0949-ISS-1203.md), which belongs to `QA-KB-112`, and that bug is still in flight. The fixer rule is to serialize on files, so editing the file now risks losing someone else's edit.

## Fix

Replace the list with the per-tier description that FIX-785 wrote into `tests/integration/screens/17-theme-and-tiers.feature.md` (the "Deliverable access" paragraph), and drop the "Notably ... behind D-04" sentence. The change is prose only.
