## Symptom

Two defects in the Steps-tab agent detail:

1. Clicking an agent opened its detail only on the **second** click.
2. Pressing Back produced a visible flicker — the detail closed, then briefly
   re-opened.

## Root cause

`AgentThinkingTab` navigated with `router.push` / `router.back`. Both are real
Next.js router navigations, so both remounted the `[...view]` catch-all
`page.tsx`. The remount reset `trackedRunIdRef` and raced the deep-link nonce,
which is why the first click was swallowed and why Back flickered in reverse.

The second defect had its own cause: `window.history.back()` reverts the URL
asynchronously, so the `initialAgentId` effect re-fired against the pre-Back URL
and re-opened the agent the user had just closed.

## Fix

`frontend/src/components/results/AgentThinkingTab.tsx`:

1. `router.push` → `window.history.pushState`, `router.back()` →
   `window.history.back()`. Agent-level navigation is now shallow and the page
   never remounts.
2. Added a `userClosedAgentId` guard on the `initialAgentId` effect so a
   just-closed agent is not re-opened while the URL is still catching up.

The shallow-nav approach is not new here — `DashboardLayout`'s
`handlePreviewPanelTabSelect` already switches run tabs the same way. This makes
agent nav consistent with it.
