## Related

## What was wrong

FIX-277 added an additive `visit_count` to `agent_start` / `agent_complete`,
but the frontend never read it. When a conditional gate looped back, the
re-entered step showed as running while every later step stayed badged done and
the "N of M" progress count never decreased — a pipeline state the engine cannot
be in.

## The fix (commit 97717eb9f)

`useWorkflow.ts` reads `visit_count`, treats a non-zero value as a revisit,
clears every later step, lowers the count and labels the pass;
`StepsOverviewSpine.tsx` renders the label. The reducer is covered by
`useWorkflow.loopRevisit.test.ts`.
