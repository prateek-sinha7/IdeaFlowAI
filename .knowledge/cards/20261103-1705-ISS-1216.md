## What is stale
`.kiro/steering/backend-engine.md:59` reads "Budget defaults are locked module constants in `budget.py`: max_subagents=8,
max_concurrency=4, max_depth=2, wall_clock=900s." In `backend/agents/execution_engine/budget.py` lines 43 to 46 the values
are 8, 5, 2 and 900. The concurrency change from 4 to 5 is recorded in FIX-574.
## Why it is a card and not an edit
The steering file is a workspace rule, not repo code and not a knowledge card, so neither the backend step nor the
`/velocity` book-keeping flow edits it. [FIX-792](20261103-1705-FIX-792.md) corrected the code comments that carried the
same number; this file is the one known copy left.
