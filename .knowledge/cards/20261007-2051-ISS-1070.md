# ISS-1070

## Provenance

The QA-KB-091 analyzer named this residual in [ISS-952](20261002-0147-ISS-952.md), "Residuals the
fixer should decide, not discover: Landing tab". The fixer took variant C, the analysis's safer
minimum, in [FIX-749](20261007-2051-FIX-749.md), so the residual stands and is recorded here.

- **CONFIRMED offline** (jsdom, the real `PreviewPanel` after FIX-749), in
  `evidence/qa-kb-091/fix-05-probes-before-after.txt`. Rows `G1 shell=failed|degraded pin=completed/null`
  and `G8 LIVE-FAILED|LIVE-DEGRADED`:
  - `tabs=["Preview","Steps","Workspace","Audit"] | landed=Audit`;
  - after a click on Preview: `{"distinct":true,...}`.
- **INFERRED in the browser.** The real page also sends a deep-link tab nonce for some routes, and
  that may land Preview first. Not driven.

## Mechanism (read)

- The panel renders once before the pin's fetch resolves. In that render `shellOnScreen` is true
  (`viewingVersion` is still null), so `terminalFailureNoDeliverable` is true and
  `defaultTabDiscriminator` (`PreviewPanel.tsx:1322`) is "failed". The effect latches
  `autoTabbedForState = "failed"` and selects Audit (`:1350-1357`).
- When the pin resolves, the discriminator becomes "idle" (no content, no failure). "idle" targets no
  tab, so Audit stays.

## Fix options (from the ISS-952 analysis, not applied)

- **Variant D:** read the pin's identity from the URL first,
  `pinTargetId = pinnedMemberId ?? viewingVersion?.id`, so the first render already knows the pin is
  foreign. Probe rows G1 and G8 land on Preview
  (`evidence/qa-kb-091/04-analyze-probes-real-tree-and-fix-variants.txt`, column D). The cost is that a
  pin whose fetch is in flight or has failed counts as foreign, so the shell's failed surface is hidden
  while the pin never loads. That is the state [ISS-955](20261002-0215-ISS-955.md) is about, and it
  needs a UX call.
- **Re-target on resolve:** when the pin resolves under a foreign-pin "idle", move an auto-selected
  Audit to Preview once. A user who clicked Audit on purpose must not be moved.

## Test conditions

Use the harness of `PreviewPanel.shellStatusForeignPin.iss952.test.tsx` (`liveRunId="r1"`,
`pinnedVersion="1"`, `reopenedRunStatus="failed"`, pin `completed` with `output: null`). Without
clicking, the selected tab is Preview and the body reads "No deliverable was saved for this version".
Control: the self-pin (`liveRunId="root"`) still lands on Audit with no Preview tab.
