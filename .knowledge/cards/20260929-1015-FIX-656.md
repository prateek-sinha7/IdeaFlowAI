## Change

One account per tier — `admin@`, `enterprise@`, `pro@`, `basic@velocity.ai` —
replaces the `qa-*@flowinqa.com` set in `seed_test_users.py`, the Playwright and
pytest e2e fixtures, integration suites and `.feature.md` files, API tool
environments, bug-hunter configs and agent docs.

The new default password satisfies the Cognito policy, so `E2E_BASE_PASSWORD` no
longer has to be set.
