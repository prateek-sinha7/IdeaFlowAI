## What was wrong

`frontend/src/lib/routes.ts` — `if (head === 'analytics')` matched on `segments[0]`
alone with no `segments.length === 1` guard. So `parseViewPath(['analytics', 'sub'])`
returned `{ screen: 'analytics' }`, `initialMainViewFor` mapped it to `"analytics"`,
and `DashboardLayout` rendered the real Analytics page under the bogus URL — a
URL/content mismatch per ADR-0018.

## What changed

`frontend/src/lib/routes.ts`:

```ts
// Before
if (head === 'analytics') {
  return { screen: 'analytics' };
}

// After
if (head === 'analytics' && segments.length === 1) {
  return { screen: 'analytics' };
}
```

`frontend/src/lib/routes.test.ts` — added two regression tests:
- `ISS-350: /analytics/<sub-path> is not the analytics screen` → asserts `{ screen: 'unknown' }`
- `ISS-350: exact /analytics still resolves to the analytics screen`
