## Symptom

`CanvasView.test.tsx` reports 2 failures on every run:

- `clicking a node selects it and binds the inline config rail (Model + Overrides toggles + AgentPromptSection)`
- `the Review-gate select attaches the picked (non-validation) review gate`

Both call `getByLabelText(/Review gate/i)`.

## Root cause

The rail no longer renders a "Review gate" `<select>`. After
[ADR-0013](20260824-1630-ADR-0013.md) split human gates by phase, gates are
checkboxes: `Before execute: Human gate`, `After execute: Conditional gate`,
`After execute: Human gate`. The tests were never updated.

## Evidence this is pre-existing, not a regression

Verified by reading `215b911e0`, not by assuming: the only "Review gate"
occurrence in `CanvasConfigRail.tsx` at that SHA is prose inside a comment
(line 710), so no such control exists there either and the query cannot
resolve. That line is untouched by [FIX-297](20260825-1115-FIX-297.md).

## Fix direction

Rewrite both tests against the current checkboxes — assert on
`After execute: Conditional gate` / `Before execute: Human gate` and the
resulting `selections[id].gates` array.

**Do NOT reintroduce a Review-gate select to satisfy them.** The app is
correct here; the tests are stale. Bending the app to a stale test is a
recorded failure mode in this area.

## Resolution (2026-08-25)

Both tests rewritten against the current checkboxes. **No app code changed.**

The second cause was in the fixture, not the queries: `PALETTE` declared only
`approval` and `code_test`, so `gateOptions` came back without `conditional` or
`before-human`. `CanvasConfigRail` renders each gate group as `null` when its
`names` array is empty, so the checkboxes never existed to be found — the
Config tab was open and `Model` resolved, which is what made this look like a
selector problem rather than a fixture gap. Added both gate capabilities to
`PALETTE`.

Test 1 now asserts the rail renders `After execute: Conditional gate`; test 2
asserts ticking it puts `conditional` into `selections[id].gates`, and that
`Before execute: Human gate` yields `before-human`.

`CanvasView.test.tsx` 24/24, `CanvasConfigRail.test.tsx` 24/24 — 48/48 with
`git diff` clean on both `CanvasConfigRail.tsx` and `CanvasView.tsx`.
