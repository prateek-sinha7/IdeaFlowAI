## Related

**Depends on:** [ADR-0027](20260825-2115-ADR-0027.md)

<!-- /RELATED -->

Migration 0039 added `base_version` to capture the base manifest's `version` when an override is
saved. No code reads it.

**Consequence:** edit `agents/workflows/ppt/workflow.yaml` — add a step, change a deliverable —
and every saved override keeps running the steps captured before that change. The user is never
told their version is behind, and there is no way to see it from the UI.

**Disposition:** open. Needs a comparison at read/launch time and a UI signal ("the original
changed since you saved this"). Spec: `specs/016-workflow-overrides/spec.md` §6 G-1.
