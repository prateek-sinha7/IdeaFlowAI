## Description

Application lifespan shutdown unreachable with live SSE streams — graceful-shutdown timeout + orchestrated teardown

## Root cause

uvicorn's default timeout_graceful_shutdown=None leaves streaming SSE connections open indefinitely; H11Protocol.shutdown() only clears keep_alive but does NOT close the transport. A live SSE stream makes lifespan.shutdown() unreachable; docker SIGKILLs at stop_grace_period=30s. Deploy downtime: 30s → 5-8s graceful exit. Concierge tasks must be AWAITED (never cancelled first) so durable chat_reply writes complete. Checkpointer pool must be closed LAST (after steps may still hold connections). Queue registries must be sentinelled. Part 2 (optional, behind SHUTDOWN_STOP_RUNS flag) optionally stops in-flight drivers and converts runs to "cancelled".
