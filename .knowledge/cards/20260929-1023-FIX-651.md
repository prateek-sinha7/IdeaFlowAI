## Change

- The chosen template's `assets/template.html`, `example.html` and references are
  seeded into `.context/design/template/` (`template_kit`, `od_context`,
  `od_loader`, `launch_context`). `assemble_prototype` pours the parts into the
  template's own frame and CSS (shell → template → example → guard → theme);
  builders get the template's class vocabulary.
- Screens carry a section/tab: one top-bar item per section with a tab strip;
  create/edit/detail pages stay out of the menu; template demo chrome and the
  status footer are removed. The prototype opens on the first section's landing
  page and an unwired sign-in submit is wired to it.
- Workflow prompts: planner does only its own phases, 6-8 realistic rows, no
  placeholder data, per-step model fallback lists, file-intake gap dedupe,
  mermaid labels, HOW TO DELIVER / HOW TO EDIT blocks.
- `skills/opendesign/TEMPLATE-DESIGN.md`: guide for authoring new templates.
