## Extend deep_agent_runner's thinking extraction to Anthropic/Bedrock content blocks

Fixes [ISS-163](20260819-1726-ISS-163.md) — see that card for the root cause.

**Change** (`backend/app/agents/deep_agent_runner.py`):
- Added `_extract_thinking(content)`, mirroring the existing `_extract_text(content)`:
  recognizes `{"type": "thinking", "thinking": ...}` (native Anthropic) and
  `{"type": "reasoning_content", "reasoning_content": {"text": ...}}` (Bedrock
  Converse) content blocks.
- The `on_chat_model_stream` handler's reasoning check now tries
  `additional_kwargs.get("reasoning_content")` (Ollama) **or**
  `_extract_thinking(chunk.content)` (Anthropic/Bedrock), yielding the same
  `{"type": "thinking", "thinking": ...}` event either way.

No other file changed — `engine.py`'s `"thinking"` → `agent_thinking` mapping and the
frontend (`useWorkflow.ts`, `AgentThinkingTab`) were already provider-agnostic.
