# ISS-159

## Title

**A chained run records NO lineage.** Chaining passes context by INLINING the parent's context block into the child's `input` text; neither `parent_run_id` nor `source_run_id` is set on the child. Revisions DO set `parent_run_id`, so chains are invisible to exactly the lineage queries revisions answer. Consequence: no query can reconstruct a chain, and analytics cannot attribute a chained deliverable to its source.
