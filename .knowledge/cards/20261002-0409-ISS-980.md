# ISS-980

## Description

Boundary / empty-case sibling of [ISS-791](20260922-1823-ISS-791.md) (bug QA-KB-056,
`BUGS.md#qa-kb-056`), derived from its root cause by the 3-analyzer and then **reproduced
offline** — the real `build_flat_payload` and the real `finalize_terminal_run` (DB stubbed),
not yet by a committed test or a live run.

The `streamed_text` block decides whether the stream is a *claim* on the RAW bytes — `if
_raw_streamed:` at `engine.py:1490` — before any transform runs. The resolver can return an
empty string from a non-empty stream: `unwrap_artifact` returns `m.group(1).strip()` for a
matched wrapper, which is `""` for an empty one (`_artifact.py:34-39`).

**Condition.** `ectx.last_streamed == "<artifact>\n</artifact>"` (a wrapper with nothing
inside, or only whitespace) on a `strategy: streamed_text` run with a declared name.

**Expected.** The same outcome as an empty stream, which an existing test pins
(`test_streamed_text_payload_v3.py::test_empty_last_streamed_still_degrades_untagged`,
lines 139-161): not a claim, so `output_unmaterializable`, `published_status == "degraded"`,
no tag. The `ppt` block already applies that rule AFTER its transforms ("An empty stream or a
stream that sanitizes to empty is not claimed as a materialization", `engine.py:1504-1506`,
`:1527`).

**Actual** (executed 2026-10-02, `evidence/qa-kb-056/analysis-proof-build_flat_payload.py`,
cases C and PART 2):

```
last_streamed        : '<artifact>\n</artifact>'
resolver output      : ''
payload.materialized : True  chainable=True
materialized bytes   : '<artifact>\n</artifact>'

finalize_terminal_run:
  empty stream ('')          -> published_status 'degraded' (output_unmaterializable)  tags []
  wrapper-only stream        -> published_status 'completed'                           tags ['v1']
```

So a run whose deliverable resolves to nothing is published "completed", tagged `v1`, and its
`.chain/<name>` is a chainable payload whose bytes are the wrapper itself.

## Why the root cause implies it

It is the same defect as [ISS-791](20260922-1823-ISS-791.md) seen on the *claim decision*
rather than on the bytes: `build_flat_payload` re-implements the resolver by hand, and the
hand-written copy tests for content before it transforms, where the resolver (and the `ppt`
mirror) transforms first. It is a separate card because the observable outcome is different —
the publish status and the tag decision flip, not just the file bytes — and because it
dictates how the fix must be shaped: the emptiness test has to run on the resolver's output,
not on `ectx.last_streamed`.

## Reachability

Rare: it needs the last agent to emit an empty `<artifact>` wrapper (a model that moved its
content into a tool call, a generation cut short after the wrapper closed). Filed because
it is the only case where the claim, not merely the bytes, diverges.

Out of scope here: a whitespace-only stream (`"   \n"`) is truthy, so it is claimed by the
resolver path and the payload path alike (verified: resolver `'   \n'`, `materialized=True`)
and stays claimed after any fix that keeps the truthiness test. Whether to `.strip()` first
is a separate decision and is the same for the `ppt` block.

## Fix pointer

The same single change as ISS-791 (see its "Analysis" section): take the resolver's output
first, then test it — `_resolved = _CAPABILITY_REGISTRY.resolve("deliverable",
"streamed_text").resolve(ectx)`; `if _resolved: _streamed_text = _resolved`. An empty result
leaves `_streamed_text` as `None`, the block falls through to "output file not found", and the
run degrades `output_unmaterializable` exactly as the empty stream does today. **Behaviour
change to call out in the FIX card:** this flips the publish status and tag decision for this
input from `completed` + `v1` to `degraded`, no tag.

## For the test writer

In `backend/tests/agents/test_streamed_text_payload_v3.py`, mirror
`test_empty_last_streamed_still_degrades_untagged` (lines 139-161):
`_make_streamed_ectx(run_id, sandbox, last_streamed="<artifact>\n</artifact>")`, then
`_finalize(run_id, ectx)`; assert `record.published_status == "degraded"` and
`sandbox.list_tags() == []`.
