# ADR-0001

## Decision

In the context of SSE streams that the backend closes on purpose, facing a spurious
"Reconnecting" banner on every stop, we decided that terminal frames mark the connection
non-reconnecting synchronously inside the frame dispatcher, to achieve a quiet
disconnect that cannot race the React render cycle, accepting that every new terminal
frame type must be added to that branch by hand.

**Area:** sse, frontend
