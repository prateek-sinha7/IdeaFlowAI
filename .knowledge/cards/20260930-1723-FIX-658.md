## Bug

Back from a run called `router.back()` (`goBackOr`). Switching run tabs pushes one entry per tab, and a run launched from a wizard has the wizard behind it, so Back walked through the tabs or into the wizard instead of returning to the list.

## Fix

`navigation.ts` adds `rememberBackOrigin` / `readBackOrigin` / `backToOrigin`. `DashboardLayout` records the origin when `mainView` is `history` (Runs) or `home` (dashboard), and the run's Back pops exactly the entries pushed since. `LaneRunHeader` labels the button "Back to runs" or "Back to dashboard".
