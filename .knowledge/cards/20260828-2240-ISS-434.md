## Resolution

Verified fixed in the current code on 2026-10-02 (feat/user-stories-v2, uncommitted tree after the QA-KB-001..046 line) by static review: a triage pass and an independent adversarial re-check both agreed. No tests were run for this closure.

**Triage:** The lane now always receives a non-empty derived filename, so SettledSummaryStrip renders DeliverableCard even when deliverable_filename is null. The card's proposed fix (add deliverableMimetype to PipelineRunState) is not needed.

**Evidence (re-check):** DashboardLayout.tsx:2627-2632 computes laneDerivedFilename via deriveDeliverableFilename; :3322 passes `laneDerivedFilename || undefined`. FilesTab.tsx:325-394: every branch returns a non-empty string (user-stories.md, custom-output.md, presentation.html, prototype.html, project.zip, or `fallback || "deliverable"` plus extension). RunChatLane.tsx:2030 `deliverableFilename ?? pipelineState?.deliverableFilename` is therefore truthy; :862-864 renders DeliverableCard. [ISS-313](20260828-1946-ISS-313.md) status: resolved. The proposed mimetype fix is unnecessary.

**Left over (outside this card's claims):** Side effect, not the card's claim: the lane filename is never empty, so the card also appears on a complete or idle run with no real deliverable. No claim in the card still demands a change. The status is manual/pending, so closing needs no code edit.
