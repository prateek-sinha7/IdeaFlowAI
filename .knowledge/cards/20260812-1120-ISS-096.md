# ISS-096

## Title

**Stale prompt-contract pin: `tests/agents/test_prompt_contracts.py::test_od_ppt_validator_deck_reemission_contract` asserts a sentence that is no longer in the agent's prompt.** `test_prompt_contracts.py:63` asserts `"exactly ONE <artifact>" in body`, where `body` is `load_agent_spec("od-ppt-validator").prompt_body`. That substring is absent from the current `backend/agents/prompts/od-ppt-validator/AGENT.md`. **Proven pre-existing:** reproduced identically at `fab9b646` in a clean detached worktree, so it is not a FIX-231 regression. The rest of that file is green (44 passed / 1 skipped alongside `test_live_contract.py` + `test_phase3_token_delta_live.py`). **Decide which side is stale before editing either** — this file is a deliberate durable pin (Phase 15-02) whose whole job is to fail when a prompt contract silently changes, so the correct fix may be to restore the prompt line rather than relax the pin. The `od-ppt-validator` output contract has been hardened three times (FIX-001, FIX-014, FIX-109) precisely because losing it makes the live deck render as raw QA checklist text, so treat a missing contract sentence as a possible product regression until the AGENT.md history says otherwise.
