## Decision
Commit `70f51ea20` ("Fix/foldet deletion") deleted the TTL sweep, its settings, its documentation and
`test_ttl_sweep_loop_v3.py`. The same commit tightened deployment checks (runs backup job and CloudWatch agent as release
gates on stage/prod). The reason "users lose folders" is inferred from the branch name and the commit text, not from a
reproduced incident.

## Consequence
Nothing now bounds disk use of run directories: [ISS-1219](20261107-0150-ISS-1219.md).
