## Description

Button labels in `InlineClarifyActions.tsx` implied "build always follows clarify"
which is incorrect for all workflow types — some workflows chain into further clarify
rounds, some produce non-build outputs. New labels are action-neutral and accurate
for any workflow type.

## Root Cause

Hardcoded strings referenced "start the build" as an implied next step after
clarification answers are submitted.

## Fix

Updated 3 string literals in `InlineClarifyActions.tsx`:
- "Submit answers & start the build" → "Submit answers & proceed"
- "Skip questions & start the build" → "Proceed with auto recommendation"
- Related aria-label updated to match
