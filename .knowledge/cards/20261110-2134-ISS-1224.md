# ISS-1224 — share-route test fails on Windows

## Observed

`pytest tests/unit/app/test_share_route_hardening.py::test_share_route_sends_csp_sandbox` fails
with `UnicodeDecodeError: 'charmap' codec can't decode byte 0x8d in position 4974`, raised from
`Path.read_text` with the default cp1252 encoding on Windows.

## Not confirmed

Which file the test reads has not been checked. Reading it with `encoding="utf-8"` is the
likely fix, but this has not been applied or tested.
