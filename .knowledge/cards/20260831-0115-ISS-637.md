## Symptom

```
test_alembic::TestAlembicMigrations::test_upgrade_then_check_reports_no_drift
  alembic.util.exc.AutogenerateDiffsDetected: New upgrade operations detected…
```

## Why this is its own card

It arrived as one line in a list of unrelated singles, but it means something
specific and serious: a model changed without a migration, so a database built
from the migration chain does not match what the ORM expects. That is a
deployment problem, not a test problem — and it stays silent until someone
provisions a fresh environment.

Run the autogenerate and read the diff it reports to find which table.
