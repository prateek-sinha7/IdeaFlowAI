# FIX-801 — loop-back route with no exit, and stale finalization on resume

## Symptom

Run `a57f82ce-ed7b-4c61-8cf2-836a3aa088e6` (saved workflow OMS Prototype, `workflows` row
`9c192e76-a886-4c27-8e7c-2e6cd92c9bb6`) finished the full build, then showed "Run failed"
and "Run degraded" in the UI. After a resume it still showed degraded.

## Root cause

### 1. The workflow could never finish (confirmed)

The `e2e-tester` route declared only `revise -> screen-planner`. The tester replied
`{"decision": "pass"}`. No outcome matched, `default_next` was unset, so
`ConditionalGate.evaluate` returned `GATE_BLOCK` (`backend/agents/capabilities/gates/conditional.py:206-210`).
The engine then ended the run with `pipeline_failed` (`engine.py` ISS-170 arm, around line 7571).

The compiler accepted the route. `_validate_route_targets` only checks that targets exist, so
nothing flagged a loop with no way out. `workflow_validated` reported `satisfiable: true`.

### 2. A resumed run reused the earlier finalization record (confirmed)

`finalize_terminal_run` returns early when `run_id` is in `_finalize_terminal_run_started`
(`backend/agents/execution_engine/engine.py:2215-2240`). Nothing removed the id on resume, so
attempts 2 and 3 returned the 16:01 record (`published_status=degraded`, `payload_materialized=False`)
and never committed, advanced the ref, or tagged the fresh build. The stale `degraded` then
flowed into the 18:30 `pipeline_failed`, the 18:35 `pipeline_complete` and
`WorkflowRun.status` through `_reconcile_terminal_status`.

## Fix

- `backend/agents/workflows/compiler.py`: new `_validate_route_has_exit`, called after
  `_validate_route_targets`. A step whose route has no `default_next` and no outcome of trigger
  `end` or `workflow`, and no `step` outcome to a later position, raises `CompilerError`. The
  message tells the author to add `"pass": {"trigger": "end"}`.
- `backend/agents/execution_engine/engine.py` `resume_run`: `_finalize_terminal_run_started.discard(run_id)`
  after `forget_run`.
- Data (not code): saved workflow `9c192e76…` gained `"pass": {"trigger": "end"}` on `e2e-tester`.
  Backup: `.agents/tasks/run-a57f82ce-rca/workflow-9c192e76-backup.json`.
