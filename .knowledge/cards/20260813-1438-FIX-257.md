## Description

The Concierge's file-attachment prompt forbade a tool that no longer exists, and converted questions into steering notes.

## Root cause

Two faults from dev's FIX-218 being authored against a superseded tool surface. (1) It says "NEVER call read_events when a file is attached" — FIX-233 DELETED read_events/list_refs/get_ref after measuring one question re-feeding 9,227,107 chars (~2.3M tokens); inert, but dead prompt text on every attachment turn. (2) CASE B routed "user just attached a file OR ASKED ABOUT STATUS" to propose_steering_note, which the later rule "NEVER call propose_steering_note for a status question" directly contradicts — so a question was silently converted into a steering note.
