## Decision

The Workspace replaces the Files tab as the surface for everything a run wrote.
Files showed one blessed deliverable; Workspace shows the whole run directory —
so it needed a grouping that holds for a deck pipeline, a prototype build and an
app-builder bundle alike.

## Why the spine is root + `.agents/`

The first cut was built around a ppt_v2 run and grouped by the folders that run
happened to produce. That does not survive contact with another workflow:
`.verify/` is meaningful for ppt_v2 and absent from prototype. Two things ARE
invariant — a run's root files are what it delivered, and `.agents/` is written by
the engine for every agent of every workflow. Those two carry the Artifacts view;
everything else lives in All Files as an ordinary folder.

## Consequences

- A new workflow needs no frontend change to appear correctly grouped.
- Anything the engine does not write to `.agents/` is not an agent output, by
  definition — there is no name-matching heuristic to drift.
- `.verify/` and other per-workflow folders lose their promoted position. That is
  the intended trade: a section that exists for one workflow is a section that is
  empty or absent for the rest.
