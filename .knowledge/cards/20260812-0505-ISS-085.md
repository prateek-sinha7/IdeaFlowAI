# ISS-085

## Title

**Switching artifact versions does not change the spec cards — only the raw output below them.** The owner tested the new ISS-065 picker and reported: "while changing the version there, i couldnt see the older version's content". Confirmed by reading the code. `AgentDetailPanel.tsx:738-740` computes `shownOutput = viewed?.content ?? agent.output` and correctly passes it to `OutputPreviewSection` (`:869`), so the raw output DOES follow the selection. But `:840` renders `<SettledArtifactCards agent={agent} model={cardModel} />` — passing the **raw agent**, not `shownOutput` — and that component parses `agent.output` directly at `:611` (`parseSpecSections`) and `:612` (`parseSpecOverview`). The prominent "Specification · N pages" card therefore always renders the LATEST spec regardless of which version is selected, while the less prominent raw-output section changes underneath it. `AnalysisPreview content={agent.output}` (`:687`) has the same flaw. So a user selecting v1 sees the v3 page-grid and reasonably concludes the picker did nothing. **Fix shape:** thread `shownOutput` into `SettledArtifactCards` (and the analysis preview) instead of `agent`, so one selection drives every consumer — there must be exactly one source for "what am I looking at". Check `discriminateArtifact(agent.output)` at `:130` for the same problem while in there.
