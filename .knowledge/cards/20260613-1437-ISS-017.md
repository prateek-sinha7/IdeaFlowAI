# ISS-017

## Title

Preview pane shows the empty-state "Output will appear here" placeholder on a run that reported `pipeline_complete` — no error/degraded affordance for a completed-but-empty run (compounds ISS-016: the user sees success chrome + empty canvas with no signal anything went wrong). **Gap-audit 2026-06-14:** the 16-04 fix landed the affordance on the LIVE execution path but its history-reopen half threaded through a DEAD `onSelectWorkflowRun`/`Sidebar` surface (unreachable — no live route mounts it), so the real `WorkflowHistory.tsx` detail view STILL showed "No preview available" for a terminal-empty failed/cancelled/degraded reopen — SC3 "BOTH paths" was half-met. **CLOSED 2026-06-14:** `DegradedRunAffordance` now renders in `WorkflowHistory.tsx` detail (server-status-gated on `selectedRun.status ∈ {failed,cancelled,degraded}`), sharing the lifted `parseFailedAgentIds` (`lib/parseFailedAgents.ts`) + the exported affordance (no dual-impl); +5 WorkflowHistory tests; independently verified (live PreviewPanel path unbroken, 19/19 tests).
