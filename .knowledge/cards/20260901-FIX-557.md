## Related

**Related to:** FIX-266 (agent save identity overlay reached the roster but not the banner log).

## What was wrong

The factory banner logged the template's generic `name` field (e.g., "custom") for
all composed workflows, making it impossible to identify which user-authored workflow
was running from run output alone. The FIX-266 change updated the roster display
but did not update the banner log.

## The fix (commit 127b20a3d)

- Extract `display_name` from the agent spec: `display_name=getattr(spec, "name", "") or ""`.
- Pass this to the factory banner log instead of the template's generic name.
