## Related

## What was wrong

Authz checks and SSE revocation checks were making synchronous DB calls on 
the main event loop. A single slow query (unbounded result set or N+1 pattern) 
would freeze the entire event loop, blocking all other requests. One incident 
froze the loop for 5 hours 19 minutes.

## The fix (commit 1e329e47b)

- Move authz DB calls off-loop via asyncio thread pool (A12).
- Move SSE revocation checks off-loop via asyncio thread pool (A16).
- Bound queries: add LIMIT clauses, reduce result set size, avoid N+1 patterns.
- Event loop remains responsive even if a query is slow.

Pinned by test_authz_bounded_calls.py verifying that DB calls are off-loop 
and bounded.
