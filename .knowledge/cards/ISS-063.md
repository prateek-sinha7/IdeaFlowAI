# ISS-063

## Title

The violet "Spec Revision Cycle N" banner (FIX-163) is LIVE-SESSION-ONLY state and never back-fills from durable events, so reopening a run that was revised shows no sign a revision ever happened. dashboard/page.tsx:357 holds specRevisionCount in useState(0) and :907-912 increments it only when revisionCycleArmedRef is armed by the FE's own click AND a matching live event arrives. Same invisibility family as FIX-217: a revision occurred and the screen does not say so. CORRECTIONS ON INVESTIGATION (2026-08-12) — this row was wrong twice. (1) *"armed by the FE's own click"* is wrong: arming was a derived-state condition in a useEffect (page.tsx:1646), never a click. (2) Far more importantly, the defect was not "live works, reload does not" — it was dead on every path for od_prototype, live included. FIX-164's arming predicate required EVERY agent to be "done" while the run was still isRunning, but the update_specs gate sits on prototype-analyze, agent 2 of 5; the only sites that mark the rest done also set isRunning:false. The arm was structurally unsatisfiable, so the counter never left 0 in ANY session, on the flagship workflow, since 219702a4 (2026-08-03). Severity accordingly raised minor → major. Two further sufficient mechanisms sat behind it (a post-commit ref frozen during the synchronous replay loop; the trailing resume pipeline_start zeroing the counter last on every replay) — all three are one root cause: FIX-163/164 modelled "a revision is happening" as assembled live-session state instead of a property derivable from accumulated events. Closed by deriving it in the reducer (agentStartCounts → deriveSpecRevisionCount), with the arm/consume machinery DELETED, not shadowed.

## Source / evidence

Filed from the live Playwright pass on run d5dbc9f2. Fixed the same day, shipped as ONE change with ISS-065/FIX-222 — see that row for why. 15 regression tests, all seen RED first; there had been zero coverage before, which is exactly how FIX-164 silently killed the feature FIX-163 had just shipped.
