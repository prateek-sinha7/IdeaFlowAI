# ISS-021

## Title

A custom workflow producing a non-markdown deliverable (HTML) has no faithful FE path: Preview shows "Output will appear here" (no renderer for the type) and the Files tab lists only the 4 per-agent `.md` outputs, NOT the resolved `prototype.html` deliverable (which IS in `pipeline_complete.final_output`, 21KB). The actual built artifact is unreachable from the UI. Inherent to the dynamic-composer design (FE can't know a custom type's deliverable shape) — but means SC-001 custom workflows are backend-complete yet UI-incomplete. Relates to ISS-014 (composer is dead UI anyway).

## Severity / Tag / Status (original row)

- Sev: minor
- Tag: product
- Status: **FIXED** (18-01/03; live render proof in Playwright pass)

## Source / Evidence

UI campaign S11 `07-preview.png` (empty) + `07b-files.png` (agent outputs only); backend final_output has the full HTML
