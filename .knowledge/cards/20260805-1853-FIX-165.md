## Description

Analyze gate approve requires 2 clicks — first click disables button but does nothing visible

## Root cause

onApproveReview in page.tsx never called setReviewGateData(null) after the POST, so InlineGateActions stayed mounted with unchanged props, useEffect([output,gateKey]) never fired, submitted stayed true, button remained disabled. All other gate handlers (reject/redo/update_specs) had the clear — approve was missing it
