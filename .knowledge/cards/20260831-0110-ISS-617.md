## What happened

Three tests failed:

```
test_default_run_single_gate_per_agent_with_real_payload
  AssertionError: precondition: the static inline gate set changed: set()
  assert set() == {'prototype-specify', 'prototype-plan', 'prototype-analyze'}

test_declared_human_gate_streams_ready_before_approval_and_resumes
  AssertionError: no review_gate_ready was ever received

test_declared_gate_rejection_cancels_the_run
  AssertionError: rejection never produced pipeline_cancelled
```

## Root cause

[FIX-323](20260828-1629-FIX-323.md) — *"remove prototype review gate defaults —
user opts in explicitly"* — removed BOTH sources of a static gate:

- `gate: Human_Gate` from `prototype-specify` / `prototype-plan` /
  `prototype-analyze` AGENT.md
- `gates: [human]` → `gates: []` on those same steps in
  `agents/workflows/prototype/workflow.yaml`

so `get_pipeline_agents("prototype")` yields nothing gated and a run with
`gate_agent_ids=None` pauses nowhere. That commit updated the frontend tests
(`ReviewGatesSection.test.tsx`) and did not touch this backend file.

The failure was not merge-caused: neither this test file nor the prototype
AGENT.md files differ between `602296cc8` and the merge, and no AGENT.md in
the repo declares `Human_Gate` any more.

It also had a second-order cost — the failing precondition is exactly what
stopped the restore in [ISS-616](20260831-0110-ISS-616.md) from running.
