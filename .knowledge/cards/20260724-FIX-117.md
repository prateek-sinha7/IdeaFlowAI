# FIX-117

## Description

Standard PPT revision routes to PptxGenJS agent instead of HTML deck editor

## Root cause

handleRevisePpt used workflowType === "od_ppt" to detect HTML decks but standard PPT runs dispatch as "ppt" type so isOdPpt was false → ppt_revision (PptxGenJS) fired instead of od_ppt_revision (HTML). Fix: also set isOdPpt=true when pptContent exists and pptxCode is absent — the definitive signal that the deck is HTML not JS.
