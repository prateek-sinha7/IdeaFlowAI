# ISS-1149

**Register source:** sibling derived during the `QA-KB-108` analysis on 2026-10-09 (root [ISS-1144](20261009-0725-ISS-1144.md)). Not its own bug row.

**Confidence:** the mechanism is CONFIRMED offline, row D of `evidence/qa-kb-108/04-analyze-sibling-probes-output.txt` (`EndpointConnectionError` patched in: 500, no `access-control-allow-origin` on all five probes; `ClientError` controls: `/forgot-password` 202, `/change-password` 503). The trigger split is CONFIRMED by two independent reads: the botocore service model (`06-analyze-botocore-service-model-auth-types.txt`) and a credential-free process (`05-analyze-handler-placement-and-signing-output.txt`, part 2). INFERRED: how often a network-level failure happens in a real deployment.

## Condition

- Trigger is NOT an expired SSO session. `ForgotPassword`, `ConfirmForgotPassword`, `ChangePassword` and `AssociateSoftwareToken` are `auth_type='none'` operations: botocore never resolves AWS credentials for them. In a process with no credentials at all, the signed operations fail with `NoCredentialsError` while these four reach the network layer and fail with `EndpointConnectionError` (part 2 of the output file). So the reported SSO failure cannot occur on them. A test should simulate a network-level error (`EndpointConnectionError`), not `TokenRetrievalError`, which botocore never raises for an unsigned operation.
- They can only fail with a network-level `BotoCoreError`: `EndpointConnectionError` (DNS failure, no route to `cognito-idp.<region>.amazonaws.com`), `ConnectTimeoutError`, `ReadTimeoutError`, a proxy or TLS fault. Handlers: `backend/app/api/auth.py:803` (associate), `:1084` (forgot-password), `:1129` (confirm), `:1202` (change-password), each `except ClientError` only.

## Expected vs actual

- `/change-password`, `/forgot-password/confirm`, `/mfa/totp/associate`: expected 503 `Authentication service unavailable` with CORS headers; actual 500 with none.
- `/forgot-password`: its docstring promises 202 "regardless of whether the address exists" so the endpoint cannot be used as an oracle (`auth.py:1053-1057`), and its `ClientError` fall-through returns the generic body on purpose: "Still generic to the caller — do not leak service state on this endpoint" (`:1094-1096`). A `BotoCoreError` skips that line and answers 500, so an unreachable provider is distinguishable from a normal request. Probe: 500 vs control 202.

## Why the root cause implies it

Same narrow handler pattern, a different trigger on a different subset of calls. It is a separate card because the trigger differs from the reported bug and because `/forgot-password` needs a DIFFERENT outcome from the other three.

## Fix direction (INFERRED, not applied)

- `/forgot-password`: route `BotoCoreError` into the generic 202 fall-through at `:1094-1096`, NOT into a 503. A uniform "BotoCoreError becomes 503" rule, and also the global safety-net handler proposed in [ISS-1144](20261009-0725-ISS-1144.md), would turn this endpoint into a state oracle. It needs its own local catch.
- The other three: the 503 fall-through each already has.

## Not covered here

`cognito._client()` builds a default client with no `botocore.config.Config` (`backend/app/core/cognito.py:263`), so botocore's default connect and read timeouts and legacy retry policy apply. A blackholed endpoint can therefore hold a request longer than the frontend's 30 s abort (`REQUEST_TIMEOUT_MS`, `frontend/src/lib/api.ts:345`). INFERRED, not filed separately; settle it by pointing a client at a non-routable address and timing the call.

## Test notes

Patch the specific wrapper (`app.core.cognito.forgot_password`, `confirm_forgot_password`, `change_password`, `associate_software_token`) with `side_effect=EndpointConnectionError(endpoint_url="https://cognito-idp.eu-west-1.amazonaws.com/")`. `/forgot-password`: set `settings.AUTH_EMAIL_MFA_ENABLED = False` or it answers 409 first; assert 202 and the generic message. Others: assert 503, string `detail`, CORS header. Runnable form: `evidence/qa-kb-108/04-analyze-sibling-probes.py` (section D).
