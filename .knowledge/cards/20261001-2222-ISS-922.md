# Superseded by ISS-917 (final)

The LaunchWizard header Back (`frontend/src/components/workflow/LaunchWizard.tsx:1063`) calls `goBackOr`
with no dirty check, and the wizard renders outside `DashboardLayout`, so the shared Back guard cannot
reach it. The QA-KB-014 analyzer (root [ISS-371](20260828-2140-ISS-371.md)) and the QA-KB-015 analyzer
(root [ISS-372](20260828-2141-ISS-372.md)) derived that sibling independently within two minutes of
each other.

**Resolution, agreed in writing on both cards: [ISS-917](20261001-2220-ISS-917.md) is the surviving
card and serves both roots; this card, ISS-922, is the tombstone.** ISS-917's last section carries the
three extra notes this card originally held (the mount-time baseline race, in-app dialog only because of
S-19-17, and that Launch must never prompt). Nothing else was unique to this card. It exists only
because card ids are permanent.

History, so the next agent does not repeat it: each analyzer first superseded its own card in favour of
the other's, which briefly left no live card; this card was also briefly restored to full text before the
QA-KB-014 analyzer's explicit decision (ISS-917 survives) was seen. Do not flip either card again.
