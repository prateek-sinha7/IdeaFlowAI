# ISS-150

## Title

**Two different numbers both answer "how long did this run take", and they disagree.** `pipeline_complete.total_duration` is computed at `app/api/run_commands.py` as `round(time.time() - total_start, 2)` (wall-clock from the engine's own start marker); `workflow_runs.duration` is persisted separately. Live-observed by the original FIX-249 investigation on run `5ecb990f-2c80-4752-a615-2bed3280387a`: `total_duration` = 2546.84 vs `workflow_runs.duration` = 1717.6 — a difference of over 13 minutes on one run, never reconciled. Not independently re-observed this session (would need a live run; Bedrock unreachable) — cited as investigation-reported. Needs its own investigation to determine which (if either) is authoritative and why they diverge before anything consuming either number (a future Concierge duration tool, an analytics view, etc.) can trust it.
