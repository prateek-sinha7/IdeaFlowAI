## What is stale

[FIX-517](20260917-1307-FIX-517.md) (register bug QA-PS-003) numbers the concierge chat's clarify cards:
`questionnaire_complete` now reads `Clarifications round N answered`, and
`questionnaire_ready` reads `Round N: Before I build, I need to lock a few things down.`
Three e2e-tier artifacts still encode the old round-less text:

- [test_controls_inventory.py](../../tests/integration/e2e/suites/23_controls_inventory/test_controls_inventory.py)
  lines 625-627: S-23-45 opens the newest run and checks `"Clarifications answered" in body`,
  skipping when it is absent. A run recorded after the fix reads `Clarifications round 1 answered`,
  so the scenario **skips instead of asserting**. Coverage is lost silently; no test goes red.
- [test_chat_lane.py](../../tests/integration/e2e/suites/18_chat_lane/test_chat_lane.py)
  lines 33-34 and 228-257: S-18-08 is the inverted `@defect` guard for D-21, which is this
  defect. It counts `CLARIFY_ANSWERED = "Clarifications answered"`. Once the completed run it
  selects was recorded after the fix, it fails with "D-21 is fixed; rewrite this as the spec's S-18-08".
  That flip is by design, and the test needs rewriting when it happens.
- [18-chat-lane.feature.md](../../tests/integration/screens/18-chat-lane.feature.md)
  lines 212-223: the S-18-08 Gherkin still says `"Clarifications answered" appears once`.
  A two-round run now shows two distinct numbered cards.

S-18-07 (the `CLARIFY_ASK` substring probe) still matches, because the round prefix keeps the
old sentence verbatim.

## Why it was not fixed with FIX-517

Neither of the cards that fix resolved names these files. They are browser-tier tests, and
rewriting an inverted defect guard is a spec decision. `chat_reply` rows are persisted at emit
time, so runs recorded before the fix keep the old text. Until a post-fix run is the one these
probes select, they stay green on the seeded QA runs.

## Disposition

Open. This is not part of QA-PS-003's verification. Resolve it once the three artifacts above
are rewritten for numbered rounds.
