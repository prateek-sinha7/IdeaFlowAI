## Related

## What was wrong

When models were asked to copy large HTML prototypes (60-90 KB), they would 
silently truncate the output, leaving incomplete interactive elements. The 
prototype appeared valid but was missing significant portions of the UI.

## The fix (commit 1e329e47b)

- New deterministic validator: `html_element_floor`.
- Counts interactive HTML elements (input, button, select, textarea, etc.).
- Configurable floor (minimum element count required).
- CRITICAL finding if final element count falls below floor.
- Detects truncation before validation-retry cycle can correct it.

Pinned by test_validator_html_element_floor.py with fixtures showing truncated 
and complete HTML versions.
