## Expected vs actual

Expected: the rollback-safety contract (R1, R4, R6) is exercised against today's legacy-chain API. Actual: these four tests never
reach the behaviour they name, so the file guards less than its 23 tests suggest.

## Fix direction (INFERRED, not applied, test-only)

- R1: import `select_legacy_payload` from `app.agents.sandbox`, as R6 does at `:647`, and give its stub a `list_prefix`.
- R4: call `render_summary_md`.
- R6: add `list_prefix` to both stubs.

Each test should be re-read against its docstring before it is changed, so the fix restores the contract the test names rather than
just turning it green.
