## Origin

INFERRED sibling of [ISS-739](20260922-1407-ISS-739.md) (root cause for
[QA-PS-014](../../BUGS.md#qa-ps-014)), derived from the same missing fetch-in-flight signal, not
independently reproduced. Would be settled by cold-navigating directly to `/runs/{id}` for a run
whose PERSISTED status is `failed`, `cancelled`, or `diverted`, and observing the Preview tab in
the first ~1-3s.

## Mechanism (traced, not reproduced)

`handleSelectWorkflowRun` resets `reopenedRunStatus` to `undefined` at the start of every reopen
fetch (`frontend/src/app/[...view]/page.tsx:2886`) and only sets it to the run's real, persisted
status once the fetch resolves (`:3213`, inside the same async function ISS-739 traces). Until
then, `PreviewPanel.tsx:1010-1013`'s `reopenFailureSignal` (`reopenedRunStatus === "failed" |
"cancelled" | "degraded"`) and `:1026`'s `isDivertedTerminal` (`reopenedRunStatus === "diverted"`)
are both `false` by construction — `reopenedRunStatus` cannot yet be any of those four values
because it is still `undefined`. `terminalFailure` (`:1014`), `showFailureAffordance` (`:1015`),
and `showDivertedAffordance` (`:1027`) are therefore all `false` for the same window ISS-739
documents, and the render falls through to the identical neutral `!hasContent` branch
(`:1676-1679`, "Output will appear here") — the success-shaped, non-alarming placeholder — before
flipping, once the fetch resolves, to `DegradedRunAffordance` (`:1656-1662`) or the diverted copy.
A user reopening a run they already know failed would see a placeholder that reads as "maybe this
one has no output" rather than any hint of the failure about to be shown a moment later.

## Disposition

Open, INFERRED. Settled by the same fix ISS-739 proposes (a fetch-in-flight flag gating a
skeleton ahead of the `!hasContent` branch) — the flag applies equally whether the eventual state
is empty-terminal or failed/cancelled/diverted-terminal, since both are downstream of the same
gap. No separate fix location; recorded so the fixer's test coverage includes a failed/cancelled/
diverted reopen, not only a successful one.
