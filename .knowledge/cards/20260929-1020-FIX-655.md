## Bug

From v1, picking a still-running v2 in the Version menu pinned it as a saved
snapshot. A running run has saved nothing yet, so its Steps page was empty.

## Fix

A non-terminal member navigates to that run, as if opened directly, so its SSE
stream attaches.
