# ISS-761

## Description

Sibling of [ISS-721](20260922-1242-ISS-721.md) (bug QA-PS-027,
`BUGS.md#qa-ps-027`), derived from its root cause rather than independently
reproduced — see that card's "Root cause" / "Blast radius" sections (added by
this same analysis pass) for the full mechanism.

ISS-721's own 3/3 reproduction ran `custom`-pipeline runs only (the composer's
default `custom/workflow.yaml`, launched via `agent_ids` selection). But the
completion-status mechanism it identified as broken —
`_unrecovered_agents` / `published_status` inside `_execute_impl`
(`engine.py:7376-7457`) — is the ONE shared execution path for every pipeline
type, per SC-001 ("the kernel stays workflow-agnostic — no
`if pipeline_type == ...` branch anywhere in it"). A native (non-composer)
`prototype`, `ppt`, or `user_stories` run whose agent produces
conversational/placeholder output without raising an exception would hit the
identical `published_status: "completed"` outcome.

## Why the root cause implies this

Read in full: `_execute_impl` (`engine.py:3961`) has no `pipeline_type`
conditional anywhere between where `results` / `ectx.failed_invocations` are
read (`:7376-7387`) and where `published_status` is published (`:7457`). The
gate is structurally incapable of distinguishing "custom" from any other
pipeline — it is never given a pipeline-type input to branch on. The only way
a native pipeline could be exempt is if its agents structurally cannot
produce placeholder output without raising, which nothing in
`agents/factory.py` / `app/agents/deep_agent_runner.py` guarantees — a model
can always answer with prose instead of calling a tool.

`single_file.py`'s own fallback branch 3 (`:158-165`, "no seeded original...
falling back to streamed output") already documents this exact shape for the
`prototype`/`prototype_revision` resolver specifically: when
`prototype.html` is never written, the resolver falls back to whatever the
agent streamed, raw, with the same zero content check ISS-721 found in the
`streamed_text` path.

## What would confirm or refute this

A live run of a native pipeline (e.g. `prototype`, agent `prototype-build`)
where the model responds with hedging/conversational text instead of writing
`prototype.html`. Not attempted by this card — this is a code-path inference
from ISS-721's mechanism, not a new reproduction.
