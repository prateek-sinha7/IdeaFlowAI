## What was wrong

Bearer token expiry was not decoded until the token was used, which could 
happen mid-run. If the token expired during a request, the run would fail 
with an auth error.

## The fix (commit 1e329e47b)

- Decode Bedrock bearer-token expiry claims at model factory launch (A4).
- Structural parsing of JWT claims (not string manipulation).
- Enable proactive credential refresh before expiration.
- Prevent mid-run auth failures due to expired tokens.

Pinned by test_model_factory.py verifying structural token expiry parsing.
