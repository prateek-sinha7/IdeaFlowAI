## Four defects, all the same shape

A table that a `_v2` type or a second id spelling was never added to.

### "Edit brief & run again" opened a BLANK composer — [ISS-218](20260828-1700-ISS-218.md) / [ISS-235](20260828-1830-ISS-235.md)

It read the brief from `recentRuns`. `GET /api/runs` **deliberately** omits the
heavy `input`/`output`/`agent_outputs` columns — its own docstring says "Heavy
fields … are excluded — fetch the full run". The lookup was therefore undefined
for every run and fell through to `submittedBrief`, which is empty on a cold
load of a run this session did not launch. The run is now fetched individually,
as the endpoint prescribes.

Behind that, the wizard hand-off was gated on `selectWorkflowWizardPath`, whose
table omits `prototype_v2` even though `wizardModeFor` renders the wizard for
it. So the brief was written to a slot nothing on that route reads — and the old
ternary would have put it in the DECK slot even if the gate had let it through.
The slot is now keyed off the wizard's own `STEPPER_MODE`.

### A saved ppt_v2 workflow's Run opened the wrong panel

It opened "GENERATE PRODUCT REQUIREMENTS" — the `user_stories` panel — because
the `/workflows/{id}/run` handler tested `=== "ppt" || === "prototype"` and then
wrote `${base}.draft`. Both halves are wrong for a `_v2` row. Replaced with one
map covering all four wizard types, and `workflowRunWizardMode` widened to
`LaunchMode`: the narrow `"ppt" | "prototype"` was itself what stopped a `_v2`
row opening its wizard, while the state feeds a `LaunchWizard` that accepts all
four.

### The Prompt User toggle read OFF for every before-human step — [ISS-306](20260828-1745-ISS-306.md)

`normaliseRoute` maps a bare authored `condition_agent: ask` through a map built
as `instance_id -> "{agent}:{instance_id}"`, so it arrives **qualified**, while
canvas nodes are keyed on the **bare** instance. The two never matched. The
comparison is now on the instance id: both spellings are load-bearing elsewhere,
and this boolean only drives one toggle's displayed state.
