# ADR-0006

## Decision

In the context of a run sandbox whose skills/ directory is shared by every step, facing
a later step reading a SKILL.md staged by an earlier one and answering with the wrong
capability, we decided staging prunes directories not attached to the current step
rather than wiping and rewriting the tree, to achieve enforced per-step skill scoping
without breaking staging idempotency, accepting that the prune set is per-step and would
be wrong under step-level concurrency.

**Area:** agents, runtime, workflow
