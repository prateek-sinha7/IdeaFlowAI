`cd backend && PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest tests/unit/agents/test_iss033a_fixloop_token_fold_offline.py -q -p no:cacheprovider -W ignore`

E       AttributeError: 'types.SimpleNamespace' object has no attribute 'pending_validation_fix'
agents/execution_engine/kernel_services.py:2145: AttributeError

## Condition

- `KernelServices.run_validation_fix_loop` seeds `ectx.pending_validation_fix[agent_id] = {...}` before it delegates
  (`backend/agents/execution_engine/kernel_services.py:2145`). Its comment says the field "defaults to {}" on the real context.
- The test builds `ectx = SimpleNamespace(od_context=None, disk_principal="u1", checkpointer=None, current_step=None)`
  (`backend/tests/unit/agents/test_iss033a_fixloop_token_fold_offline.py:183-188`), with no such field.
- `git log -S pending_validation_fix -- backend/agents/execution_engine/kernel_services.py` names `e7305f9dd` ("implement
  sandbox-git-versioning-v2 spec") as the commit that added the write.

FIX-772 does not touch either file, and the failure is raised before any model or planner code could matter.

## Fix direction (INFERRED, not applied)

The stand-in context is stale against the field the real one carries, so the fixture probably needs `pending_validation_fix={}`. Confirm
against the real context class before changing the test. Do not change `kernel_services.py` to fit the fixture.
