## Description

**INFERRED sibling of [ISS-390](20260828-2048-ISS-390.md)** (root cause of
BUG-20260828-014937-runs-id-stream) — derived by grepping every caller sharing the
`status === "failed" || status === "cancelled" || status === "degraded"` triad that
ISS-390/ISS-282 found in `PreviewPanel.tsx`. Not yet independently reproduced in a
browser; this is a code-read lead, not a confirmed defect.

`frontend/src/components/history/WorkflowHistory.tsx:593-596`, inside the run-history
library's selected-run detail view (`handleSelectRun` → the right-column deliverable
pane rendered alongside `RunDetailPage` as the left-column summary):

```ts
const reopenTerminalFailure =
  selectedRun.status === "failed" ||
  selectedRun.status === "cancelled" ||
  selectedRun.status === "degraded";
```

Used at `WorkflowHistory.tsx:817` and `:838`: when the selected run has no
`selectedOutput`, `reopenTerminalFailure ? null : <"No preview available" placeholder>`
— the intent (per the comment at `:588-591`) is that a terminal-failure run's absence
of a deliverable is already explained by `RunDetailPage`'s failure banner in the left
column, so the right column suppresses its own neutral empty state (renders `null`)
rather than doubling up on messaging.

Because `"diverted"` is not in the triad, `reopenTerminalFailure` is `false` for a
selected diverted run with no output — so instead of being suppressed, the right column
falls through to the generic "No preview available" placeholder, which (like
PreviewPanel's "Output will appear here") gives no indication the run diverted
permanently. This compounds with [ISS-395](20260828-2050-ISS-395.md): the left-column
summary that this suppression assumes will "already explain" the failure does not
render any diverted-aware banner either, so a diverted run selected in Run History shows
NEITHER an explanatory banner NOR a suppressed/honest empty state — just two generic,
unexplained placeholders.

## Reproduction (not yet run — for the next validator/test-writer)

1. Sign in as qa-admin. Open the Run History library (sidebar), select the seeded
   diverted run "Ex A4 Human Divert" (`940ca699-b21b-4666-8e44-3370a08a4561`).
2. Expected if this reproduces: the right-column deliverable pane shows "No preview
   available" (a FileText icon + that text) rather than being suppressed.
3. Contrast: select a `failed`/`cancelled`/`degraded` run with no output — expect the
   right column to render nothing (suppressed) since `reopenTerminalFailure` is true.
