# ISS-161

## Title

A pure question posted to a parent run over REST /messages was classified as a REVISION and minted a run. Asking "how many tokens did this run use?" produced "channel":"revision" and created run 0702ceaa. That run failed instantly on empty input and cost nothing, so the blast radius was zero here — but the classification is wrong, and a question that happens to carry more text could have launched real work. It also re-demonstrated ISS-153: the failed revision recorded no error reason.
