## The two locators

**S-15-16** looked for `aria-label="Copy a link to this run"`. The control is
`"Share this run"` since `b69f25696` (Option B public share link) — which is on
`feat/conditional-gates`, not from this merge.

**S-16-12 reported a credential leak that never happened.** Its regex

```python
re.findall(r"\b[A-Za-z0-9_\-]{24,}\b", shown)
```

matches on SHAPE, and `validator-handoff-fixture` — the NAME of a revoked key
left listed by an earlier run — is 25 characters of exactly that class. It was
on the page before the test began and still there after the reload, so the test
concluded the plaintext key had been re-shown.
