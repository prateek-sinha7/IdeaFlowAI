# ISS-141

## Title

**A reopened TERMINAL run still renders an actionable clarify card.** `useRunChat.ts`'s terminal auto-resolve covers only `cardKind === "gate"`, so the narrator CLARIFY card and its "Answer in Steps" affordance stay unresolved and clickable on a finished run. Independent of the destroyed-event damage and cheap (one extra `cardKind` in one existing condition), but it is a transcript-seed concern, not the run-state defect FIX-245 addresses, so it was filed rather than folded. NOTE: FIX-245 clears the run's `questionnaireData` on a terminal reopen, which removes the clarify PANEL; this row is about the chat CARD in the transcript, which is a different surface.
