## Description

Workflow configuration modal Agents tab overflows viewport — Per-Agent Model, Advanced, Capabilities sections inaccessible

## Root cause

Three bottom sections used flex-shrink-0 outside any scroll container; the flow grid's flex-1 overflow-y-auto consumed all remaining height, pushing all three sections below the modal's 90vh boundary. Fix: wrap all four sections in a shared flex-1 overflow-y-auto min-h-0 container; cap flow grid to min(45vh, 240px) so it doesn't consume all vertical space
