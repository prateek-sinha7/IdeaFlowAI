A step re-entered by a loop emitted the same `agent_start`/`agent_complete` pair each
pass, with nothing distinguishing them. The run panel could not show that `greet` had run
twice.

## Fix

`visit_count` added to both events, emitted ONLY when non-zero:

```python
**({"visit_count": _vc} if (_vc := ectx.step_visit_counts.get(spec.id, 0)) else {})
```

The non-zero condition is load-bearing: five characterization goldens pin `agent_start`'s
key set exactly (`['agent_id','icon','index','name','role','total']`), so an
unconditionally-emitted key would have broken all of them. A non-looping workflow emits a
byte-identical stream, which the A2 runners assert.

Depends on [FIX-275](20260824-1615-FIX-275.md) — while the counter read 0, this would have
emitted nothing.
