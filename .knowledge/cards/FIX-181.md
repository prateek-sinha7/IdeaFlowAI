# FIX-181

**Phase / trigger:** Phase 32 (Run screen redesign), user request

## Description

Three UI elements removed from the home dashboard (`HomeLaunchGrid`):

1. **Text input area** — the full Prompt block (textarea, Attach button, Build button,
   toolbar div, file input, attached image chips) — the input was present but not
   connected to any workflow launch path that was still in use.

2. **"Or start from a deliverable"** section label — the `<p>` heading above the
   workflow grid, no longer needed once the input above it is gone.

3. **"Create workflow"** button — the `<button>` in the same flex row as the
   section label that called `onSelectFeature("custom")`.

## Changes

| What removed | Location in file |
|---|---|
| `Paperclip`, `X`, `Plus` imports | import line |
| `useRef` import | import line |
| `internalBrief`, `briefValue`, `setBrief` state | Prompt section |
| `fileInputRef`, `attachedImages` state | Attach section |
| `handleAttachClick`, `handleFilesPicked`, `removeAttachment` handlers | Attach section |
| `buildDisabled`, `handleBuild` | Launch section |
| Prompt JSX block (textarea + toolbar div) | render |
| Attached image chips JSX block | render |
| Section header div (`Or start from a deliverable` + `Create workflow`) | render |

## Preserved

- `brief`, `onBriefChange`, `onBuild` props remain in the interface for API
  compatibility with callers that pass them — they are just not consumed.
- `handleClick` retained — still needed for the workflow card grid.
- `onSelectFeature` prop retained — still used by the card grid via `handleClick`.
- Grid spacing: `mt-10` moved from the removed section header onto the grid
  containers directly so vertical rhythm is unchanged.

## Invariants

- **INV-1/3/12/SC-001**: frontend-only UI removal, no engine/SSE/backend touch.
