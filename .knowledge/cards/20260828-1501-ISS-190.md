## What happened

`/create/prototype` (the legacy prototype wizard shell — tabs, template gallery, Back/Next)
renders correctly on a fresh visit. But: land on `/create/prototype` normally → press browser
**Back** (goes to `/dashboard`, renders fine) → press browser **Forward** (URL returns to
`/create/prototype`, title is correct) → the page body is completely empty. No header, no tabs,
no template gallery — just the page background. The state does not resolve after a 2+ second
wait; only a full `page.goto` reload recovers it.

Confirmed **CONFIRMED, 3/3, cold start every cycle** — each cycle re-navigated fresh to
`/dashboard`, then to `/create/prototype`, then `goBack()`, then `goForward()`, using real
Playwright `page.goBack()`/`page.goForward()` (not scripted `history.forward()`). All three
cycles produced identical results:

| cycle | body.innerText length after Forward | body.innerHTML length | blank |
|---|---|---|---|
| 1 | 0 | ~24000 (raw RSC payload) | yes |
| 2 | 0 | ~24000 | yes |
| 3 | 0 | ~24000 | yes |

`document.body.innerHTML` in the failure state is ~24000 characters of literal, un-executed
Next.js RSC streaming script/text payload — not rendered markup. `location.href` correctly reads
`http://localhost:3000/create/prototype` throughout, `auth_token` stays valid the whole time, and
every API the page needs (`/api/workflows/prototype`, `/api/prototype/templates`,
`/api/prototype/design-systems`, `/api/agents/library`, etc.) returns 200 OK — this is a
client-side hydration failure, not a data-fetch or auth failure.

## Expected vs actual

- **Expected:** Forward navigation back to `/create/prototype` renders the wizard shell exactly
  as a fresh visit does.
- **Actual:** The page silently renders nothing — an empty, contentless body holding only the raw
  un-hydrated RSC stream, no error, no loading indicator, no self-recovery, requiring a full
  reload.

## Conditions established

- Route: `/create/prototype` (the legacy-wizard route family per
  `bug-hunter/velocity.json` note at line 204 — `/create/ppt` and `/create/prototype` render the
  tabbed wizard shell, not the simple launch panel used by `/create/app` etc.)
- Tier: qa-admin (not varied — reproduces at 3/3 without needing to test other tiers)
- Entry path: `/dashboard` → `/create/prototype` (fresh nav) → browser Back → browser Forward
- Trigger is the Back-then-Forward sequence specifically — a fresh direct nav to
  `/create/prototype` (no Back/Forward involved) renders correctly every time.
- No timing variation needed: reproduced identically on the very first Forward click and after a
  2-second settle wait; the blank state is stable, not a race that resolves.

## Root cause (not yet investigated — filed for 3-analyzer)

Not diagnosed here (validator scope is manual repro only). The symptom — raw un-executed RSC
stream sitting in `body.innerHTML` after a bfcache/history-restore navigation — points at the
Next.js App Router client not re-hydrating a page restored from the browser's back-forward cache
(bfcache) or a client-side history-router restore. Candidate starting points: whatever renders
the `/create/prototype` route inside `frontend/src/app/[...view]/page.tsx` (the catch-all route
handler) and its data-fetching/suspense boundaries, and any `pageshow`/`popstate` handling (or
lack of it) around hydration re-entry.
