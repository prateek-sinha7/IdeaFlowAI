## What was wrong

This is bug report QA-KB-038. `test_deleted_pattern_absent_from_backend[F1-blocks\.append]` in
`backend/tests/unit/agents/test_migration_ledger.py` failed on committed code, with one match:
`backend/agents/capabilities/input_providers/pdf_pages.py:202`. A false positive looks the same
as a real move-don't-copy regression, so while this test was red it hid any real one.

## Root cause

[ISS-858](20260923-0148-ISS-858.md) has the full diagnosis. In short:

- The F1 gate is the bare regex `blocks\.append`
  (`specs/003-workflow-engine-decoupling/migration-ledger.md:83`). The test runs it over every
  `*.py` line in `backend/` except `evals/` (`test_migration_ledger.py:228`).
- `PdfPagesProvider._blocks_for_document` (spec 019) named its local list of multimodal image
  dicts `blocks`. It declared the list at `pdf_pages.py:130`, appended to it at `:202` and
  returned it at `:224`. That code is not the deleted system-prompt assembly F1 guards. It merely
  shares the identifier.

## Change

Three lines in `backend/agents/capabilities/input_providers/pdf_pages.py`. Line count and widths
are unchanged, because `blocks` and `images` are both 6 characters long:

- `:130` `blocks: list = []` became `images: list = []`
- `:202` `blocks.append(` became `images.append(`
- `:224` `return blocks` became `return images`

`load()` keeps its own `blocks` (`:83`, `.extend` at `:114`, `return` at `:120`). It does not
match the gate, and the card scopes the rename to `_blocks_for_document`. Inside that method,
`images` collides with no other name. The only other `images` in it is the `"images"` manifest
key string at `:147`. No comment was added, because a comment that spelled the token would
match the gate itself.

## Why there

This is the fix that [ISS-858](20260923-0148-ISS-858.md) chose, and that two reviewers agreed on
in the bug report. Renaming the local keeps the ratchet at full strength: the spec ledger regex,
its scope and the test are all untouched. Excluding `input_providers/` in the test would hide
future real regressions in that package. Narrowing the regex would mean editing a closed spec's
ledger. `_blocks_for_document` has a single caller (`pdf_pages.py:114`), so nothing outside the
file is affected.
