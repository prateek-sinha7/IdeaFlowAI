## Related

This side registered `FIX-258`-`265` on 2026-08-13. `dev` independently re-homed four
unrelated infra/auth fixes onto `258`-`261` on 2026-08-17. Both sides were reasonable
alone; only the merge made it a conflict — and because the filenames differed
(`20260819-FIX-258.md` vs `FIX-258.md`), git raised nothing.

Ours moved to the next free numbers, `FIX-290`-`293`; dev keeps `258`-`261` because their
`.planning/FIX-REGISTER.md` rows and the `specs/012` table cite those numbers.

## What the collision had already broken

```
ISS-162:23   **Referenced by:** [FIX-261](FIX-261.md)
```

That resolved to dev's card about EC2 heredocs while meaning this side's tooltip fix.
`validate_links.py` could not catch it — both files existed and the link resolved. Only
separating the ids made it visible.

Dev's six cards were also renamed to the `{YYYYMMDD}-{ID}.md` convention using their own
`date:` frontmatter; they had been failing the filename-shape check.
