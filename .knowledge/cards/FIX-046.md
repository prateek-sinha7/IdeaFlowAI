## Description

Prototype task checklist shows all tasks complete before build agent finishes — last task_progress fires before fix-loop

## Root cause

currentTaskIndex used realtimeCompletedCount directly; when last task_progress fires realtimeCompletedCount === totalTasks → isDone true for all tasks despite agent still running. Cap currentTaskIndex to Math.min(realtimeCompletedCount, totalTasks-1) when !buildTrulyDone so last task stays in active/spinner state until validate starts or isRunning=false.
