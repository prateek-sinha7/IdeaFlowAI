# ADR-0010

## Decision

In the context of two competing skill-attachment surfaces — a RUN-LEVEL bag applied
uniformly to every agent in a launch, and spec 012's PER-AGENT `Step.skills` — facing UI
in which the same word "skills" meant two different scopes depending on which panel you
opened, we decided to RETIRE run-level skill attachment entirely (UI, launch payload and
save payload) and make `AgentSkillsPicker` the single authoring surface, to achieve one
source of truth for "which skills does this agent get", accepting that runs with no per-
agent UI (revisions, chains, wizard launches) can no longer attach skills at all, and
that hooks stay run-level because no per-step hooks field exists.

**Area:** frontend, api, engine, workflow
