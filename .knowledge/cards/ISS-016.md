# ISS-016

## Title

A hard model error (ValidationException from ConverseStream) on EVERY agent is swallowed into an empty-but-successful agent_complete (0 tokens, dur ~0.2s, no chunks) — the run ends pipeline_complete with DONE badges + "User Stories complete" toast + empty Preview, instead of pipeline_failed. F3 family (13-06), different trigger: F3's pipeline_failed branch keys on agent_error counts, but a runner-level model exception becomes a silent empty completion, not an agent_error, so it rides through as success. Offline tests can't catch it (scripted model never raises ConverseStream errors).

UI campaign S01 2026-06-13: frames show 6× agent_complete/0-tokens/empty final_output; backend log deep_agent_runner.astream_events failed: ValidationException ... Operation not allowed; UI 06-terminal.png shows DONE + empty preview
