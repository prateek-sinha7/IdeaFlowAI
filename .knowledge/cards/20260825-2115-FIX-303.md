## Symptom

Clicking the **leftmost** "+" on the 6-agent `user_stories` canvas placed the new agent at
**position 6 of 7**, not position 1.

## Root cause

`IdeaInputPage.tsx` — `handleAddAgent(agent)` never accepted `insertBeforeId`, and computed:

```js
const insertIdx = effectiveType === "custom" ? prev.length : (prev.length > 0 ? prev.length - 1 : 0);
```

For every non-custom pipeline that is second-to-last, unconditionally. `CanvasView` was passing
the right slot id all along; the handler discarded it.

The head slot itself was correct (`insertBeforeId: pipelineAgents[0].id`) — this looked like a
`CanvasView` bug and was not.

## Fix

Accept `insertBeforeId`; resolve it to an index and use it when found. Keep the old heuristic as
the no-slot fallback (a `custom` composition appends; a built-in keeps its final compiler step
last). Also re-number `order` across the list — the splice previously left duplicate `order`
values behind the insert point, which the manifest projection reads.
