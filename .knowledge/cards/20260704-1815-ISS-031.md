# ISS-031

## Title

Bedrock prompt caching silently OFF in prod + no operator knob for extended thinking. deepagents' built-in `AnthropicPromptCachingMiddleware` caches ONLY `ChatAnthropic`, but production runs `ChatBedrockConverse` → every build re-sent its ~45-68k fixed prefix uncached across ~300 turns. Fix (FIX-034): a provider-agnostic `_BedrockCachePointsMiddleware` injects `model_settings['cache_control']` on ChatBedrockConverse requests (config-gated `BEDROCK_PROMPT_CACHE_ENABLED` default ON, `BEDROCK_PROMPT_CACHE_TTL` '5m') so `langchain_aws._apply_cache_points` appends cachePoints ≈ 55-80% cheaper billed input; plus an enable-only `THINKING_BUDGET_TOKENS` knob (default 0 = never fires) threading a clamped thinking budget into both `build_model` provider branches. INV-3 goldens byte/event-identical (scripted model is not ChatBedrockConverse; build_model not called under goldens; default budget 0).
