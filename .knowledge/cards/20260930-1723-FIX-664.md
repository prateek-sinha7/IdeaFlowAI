## Change

Backend (b88a0e74d):

- `DeliverableSpec.text_name` (plan.py, compiled from the manifest) names the text form of a binary deliverable. The backlog declares `name: Backlog.pdf`, `text_name: backlog.md`.
- `_mimetype.BINARY_MIMETYPES = {application/pdf}`. `single_file` and the validation gate read the text form, so `final_output` carries text and no binary is inlined.
- `effective_deliverable()` keeps the binary when its file is on disk, else declares the text form with its own name and mimetype.
- The chain copy carries both files.
- `GET /share/{token}` serves the sandbox file's bytes for a binary mimetype (404 if missing).

Frontend (8e846c782):

- New `SandboxPdfPreview` fetches the workspace file with the bearer token (an iframe cannot send it), re-types the blob as `application/pdf`, and shows it through an object URL. Any failure renders a fallback.
- `PreviewPanel`'s `GenericDeliverablePreview` and `WorkflowHistory` dispatch `application/pdf` to it.
