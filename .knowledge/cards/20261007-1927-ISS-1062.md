# ISS-1062

Found-but-not-fixed while resolving [ISS-1015](20261002-0605-ISS-1015.md) under [FIX-735](20261007-1927-FIX-735.md)
(bug QA-KB-078). ISS-1015's analysis already marked this comment CONFIRMED. FIX-735 changed only golden data, so the
comment is carded here instead of being lost with the resolved card.

## Condition

`backend/agents/execution_engine/fanout.py:568-570`, directly above the worker-identity stamp at `:576-578`:

    # Optional side channel (additive, default-off): a caller that
    # supplied event_queue gets this worker's raw per-agent event too.
    # None for every existing caller — dead branch, zero behavior change.

## Why it is wrong

`stream_fanout` (`backend/agents/capabilities/strategies/_fanout_stream.py:33`) always calls
`runner.run_fanout(requests, ctx, step=step, event_queue=child_events)`, and every parallel fan-out goes through it
(`parallel_group.py:132`, and the wave scheduler). So the branch runs on every parallel fan-out, and each forwarded worker
event gets `worker_index` / `task_id` / `task_author_id`. Anyone who trusted "zero behavior change" had no reason to
re-check the characterization goldens. That is how `sample_subagents_parallel.events.json` drifted unnoticed (ISS-1015).

## Disposition

Open, low. A comment-only edit: state that `stream_fanout` supplies the queue on every parallel fan-out and that the
copy is stamped with worker identity (`None` task ids on non-wave fan-out). Do it whenever `fanout.py` is next edited
for a real reason. No behaviour change, and no golden moves.

## Resolution (QA-KB-080 fix, 2026-10-07)

Resolved by [FIX-737](20261007-1957-FIX-737.md), on the trigger this card named: `fanout.py` was edited for a real reason,
[ISS-1024](20261002-0638-ISS-1024.md)'s docstring fix at `:354-359`. The false line is replaced by
`# parallel_group and wave_scheduler supply one on every fan-out;` / `# fanout_batch and the engine tool-result path pass None.`
(`fanout.py:571-572`). The worker-identity stamp on a copy is still described by the RESUME-06 lines directly below it.
Comment only: the executable AST of `fanout.py` is identical to HEAD (`evidence/qa-kb-080/fix-10-ast-equality.out.txt`), and no
golden moves.
