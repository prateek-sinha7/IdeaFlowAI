# ISS-1223 — run continues after a recoverable agent error

## Observed

Run `a57f82ce-ed7b-4c61-8cf2-836a3aa088e6`:

- seq 163, 16:00:49: `agent_error` for `custom-agent:screen-planner`, "The model rejected this request.", `recoverable: true`.
- seq 164, 16:00:51: `agent_start` for `custom-agent:plan-reviewer` with no plan to review.
- seq 167, 16:00:56: `agent_error` for Plan Reviewer, same message.
- seq 168, 16:00:59: `gate_blocked` on the Plan Reviewer conditional gate, `decision: None`.
- seq 169: `pipeline_failed` naming Plan Reviewer, so the error points at the wrong step.

## Not confirmed

Why the engine moves on after a recoverable error has not been traced. The model rejection
itself is also unexplained. The backend console log for about 16:00 would show the provider error.

## Next step

Trace how `agent_error` with `recoverable: true` is handled in `engine.py` and decide whether a
step error should stop the run before the next agent starts.
