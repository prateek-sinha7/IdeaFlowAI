## What happened

INFERRED sibling of [ISS-331](20260828-1840-ISS-331.md), derived from a
source-code read while analyzing that bug — not yet independently driven
live in a browser.

`frontend/src/components/handoff/IntegrationsCard.tsx` (the
`/flowin-handoff` settings page) has two independent clipboard-copy call
sites, both missing failure handling. This file is notable because its
OTHER handlers (`handleSavePat`, `handleDeletePat`, `handleCreateKey`,
`L96-159`) already show the app's own established convention for
user-visible failure feedback — `setPatMessage({type: "error", text: ...})`
— that convention is simply not applied to either clipboard-copy call.

## Root cause (confirmed by direct read — two call sites, two variants)

**Install command copy**, `IntegrationsCard.tsx:73-78` (`handleCopyInstall`):

```
const handleCopyInstall = useCallback(() => {
  navigator.clipboard.writeText(installCommand).then(() => {
    setInstallCopied(true);
    setTimeout(() => setInstallCopied(false), 2000);
  });
}, [installCommand]);
```

`.then()` with no `.catch()` — same silent-on-rejection mechanism as
[ISS-331](20260828-1840-ISS-331.md)/[ISS-560](20260829-0208-ISS-560.md): on
rejection, `setInstallCopied(true)` never runs, nothing is shown, and the
rejection is unhandled.

**API key copy**, `IntegrationsCard.tsx:316-323` (inline `onClick`, the
"New key — copy now" plaintext-shown-once flow):

```
<button
  onClick={() =>
    navigator.clipboard.writeText(newlyMinted.token).then(() => {})
  }
  ...
>
```

Worse than every other sibling: the `.then()` callback is an empty no-op, so
this button gives **no feedback even on success** — there is no `copied`
state at all for this button, success or failure. Given the token is
"shown once" per the surrounding UI copy, a user who trusts a silent click
and navigates away has no confirmation the copy ever happened, for a secret
they cannot recover afterward.

**What would confirm this live:** on `/flowin-handoff` -> Integrations,
click "Copy" next to the install command (verify no feedback on a forced
rejection), then mint a new API key and click its copy icon (verify there is
no feedback at all, success or failure, today).
