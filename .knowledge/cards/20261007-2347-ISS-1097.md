# ISS-1097

Adjacent to [ISS-1073](20261007-2135-ISS-1073.md) (QA-KB-096), found by its analysis on 2026-10-07. **CONFIRMED** by source and by the validator's own screenshot.
It is not caused by ISS-1073's root cause. It is filed because ISS-1073's fix leaves the fallback it sits in on screen for every version whose tag holds no
PDF (v1 of the family below), so the verifier will read this sentence.

## Condition

Any time the PDF preview falls back (`PreviewPanel.tsx:233-237`), or a deliverable has an unknown mimetype (`:301-311`).

## Mechanism (read)

- `PreviewPanel.tsx:235`: `{deliverable.filename} could not be loaded. It can be downloaded from the Files tab.`
- `PreviewPanel.tsx:310`: `This deliverable (...) can be downloaded from the Files tab.`
- `TAB_CONFIG` (`:535-548`) says why there is no such tab any more: "Files is HIDDEN from the strip. Workspace supersedes it ... Nothing links there any
  more." The panel keeps `files` only so an old `/files` deep link opens something.
- `evidence/qa-kb-096/07-validate-settled-attempt1-preview-could-not-load.png` shows both at once: the tab strip reads Preview, Steps, Workspace, Audit, and the
  pane says "It can be downloaded from the Files tab".
- Nothing pins the copy: no test asserts "Files tab" or "could not be loaded" (grep over `*.test.*`).
- `WorkflowHistory.tsx:1108` words its fallback differently ("{name} could not be loaded.", no tab named).

## Expected vs actual

Expected: copy that says where the file is. For a version whose tag holds no PDF, which is v1 of family `78e185fb`, it should say that none was saved: nothing is
downloadable as a PDF from anywhere for that version (header Download is disabled; the v1 tree holds `backlog.md` and `.chain/backlog.md` but no PDF).
Actual: a pointer to a tab that is not there.

## Fix direction

Copy only. Name the header Download button or the Workspace tab, or say "no PDF was saved for this version" when the resolve at the ref comes back empty (the
state ISS-1073's fix creates for v1). The wording is the fixer's call; it needs no product decision.
