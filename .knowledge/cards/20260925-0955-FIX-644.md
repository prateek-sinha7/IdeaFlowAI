## What was wrong

`allFileGroups()` made one group per top-level directory and `describe()` labelled
each file with its path relative to that directory. Deep sandboxes read as a column
of truncated paths. Not a merge regression: `dev`, the pre-merge worktree
(864c8ec6d) and every other branch had the same one-level grouping.

## Fix

`FolderTree` renders a directory group as nested sub-folder rows (folder icon, file
count, guide line), collapsed until clicked, with files named by basename.
`folderLevel(files, prefix)` splits one level; `allSubDirs()` feeds Expand all.
Artifacts pane and the agent spine are unchanged.
