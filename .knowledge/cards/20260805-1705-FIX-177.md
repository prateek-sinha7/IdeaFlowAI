## Description

Build agent shows DONE / all subtasks complete while last subtask is still running

## Root cause

constructionComplete in AgentThinkingTab.tsx flips true when laterAgentStarted=true (validation agent fires immediately after agent_complete) even if completedTaskCount < totalTasks. The KAN-99 N-1 cap is bypassed. Fix: guard constructionComplete with completedTaskCount >= totalTasks in addition to laterAgentStarted
