# ISS-118

## Title

**Eight offline tests CONSTRUCT a real LLM provider client. They cost nothing today only because none of them invokes it — one added `.ainvoke`/`.astream` in any of them is live spend.** They are currently exempted by exact nodeid in `_CONSTRUCTS_BUT_NEVER_INVOKES` (`backend/tests/conftest.py`), which is what keeps FIX-238's guard from turning 8 green tests red; the dict is the visible inventory, not a fix. **The list:** `tests/unit/test_brief_max_chars.py::{test_full_brief_reaches_planner_uncut, test_ceiling_still_enforced_above_cap}`; `tests/unit/test_cached_invoke.py::{test_bedrock_call_places_cache_control_on_stable_prefix, test_cache_control_suppressed_when_flag_off}`; `tests/agents/test_iss056_clarify_quality_fixes.py::TestH3SmartPlannerDesignNote::{test_design_note_present_when_design_context_supplied, test_design_note_absent_when_design_context_none, test_design_note_absent_when_both_names_missing}`; `tests/agents/test_mcp_client.py::test_bound_mcp_tool_augments_a_deepagents_agent`. **Five of the eight go through `SmartPlanner._build_llm` (`agents/planner/smart_planner.py:167-201`), which builds its client WITHOUT `build_model()`** — the same bypass that made the provider classes, not the factory, the correct chokepoint. The eighth is different in kind: `create_deep_agent(model="anthropic:claude-3-5-haiku-latest")` makes langchain's `init_chat_model` build a `ChatAnthropic`, so the live client is constructed by the LIBRARY from a string the test passes. **Fix shape:** each should stub its construction seam the way `tests/unit/test_model_factory.py:77/83/89` already does (replace the class attribute on the SOURCE module) so the exemption can be deleted; the MCP one may instead pass a scripted `BaseChatModel` instance, since `create_deep_agent` accepts one. Do them as one deliberate pass with a before/after per test — **not** as a drive-by inside another change.

## Resolution

Closed by [FIX-429](20260831-1818-FIX-429.md) (2026-08-31). All nine entries (the eight
enumerated above plus ISS-120's, added later by [FIX-427](20260831-1813-FIX-427.md)) now
stub their own construction seam and `_CONSTRUCTS_BUT_NEVER_INVOKES` is `{}`:
a shared `stub_provider_classes` fixture in `backend/tests/conftest.py` for the five
`SmartPlanner._build_llm` sites, `_RecordingBedrock.model_construct(...)` for the three
`tests/unit/test_cached_invoke.py` sites (one edit at their shared

`create_deep_agent` in place of the `"anthropic:..."` string for the MCP one. Done as the
deliberate pass this card asked for, with the before/after per seam recorded on FIX-429.
