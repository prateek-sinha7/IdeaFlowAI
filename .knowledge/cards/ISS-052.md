# ISS-052

## Title

One "Update the Specs" click costs FOUR approvals: the re-run specify gate, the re-run plan gate, then the analyze gate RE-OPENS after the sub-pipeline returns. The doubled analyze gate is redundant and the two are visually identical, so the user cannot tell which one they are on. This is the real UX fix behind ISS-050.

## Source / evidence

Observed live driving run 5ecb990f end to end on Bedrock (2026-08-11).
