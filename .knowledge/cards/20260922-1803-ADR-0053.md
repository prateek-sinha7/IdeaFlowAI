## The decision

1. **Capability, not id-matching.** Each catalog `ModelEntry` declares
   `reasoning` (a mode plus allowed levels) and `supports_prompt_caching`.
   `reasoning_fields()` maps the mode to the request shape:

   | mode | sent |
   |---|---|
   | effort | `{"reasoning": {"effort": <level>}}` (GPT-5.6) |
   | adaptive | `{"thinking": {"type": "adaptive"}}` (Sonnet 5) |
   | budget | `{"thinking": {"type": "enabled"}}` (Claude <= 4.6) |
   | none | nothing |

2. **Default model = GPT-5.6 Luna** (`global.openai.gpt-5.6-luna`), spec 020 FR-13.

## Why

`_ADAPTIVE_THINKING_MODEL_FRAGMENTS` (model_factory) and `_THINKING_FRAGMENTS`
(api/capabilities) were kept in sync by grep. They had already drifted by one
entry (`opus-4`), so the Analytics reasoning row disagreed with what the runtime
actually sent for Opus 4.5/4.6. A single capability field makes that drift
impossible.

## Consequences

- **Data residency.** GPT-5.6 is published only as Global CRIS:
  `list_inference_profiles` on eu-north-1 returns no `eu.openai.*`. Global
  profiles route to any region with capacity, so every run that does not set a
  model now leaves the EU. `global.anthropic.*` exists but was declined for
  exactly this reason.
- **Prompt caching** is off for GPT-5.6 on Converse. The `cached_invoke` path
  (SmartPlanner, ClarifyEngine, handoff agents) was found only when a live
  planner failed silently.
- **Claude Haiku 3.5 removed.** AWS serves it in no form in eu-north-1. Its
  `us.` id only resolved because GEO-01 rewrote it to an `eu.` profile that has
  never existed. No database rows referenced it.
- **Parity.** Replaying `build_model` over every catalog id against the old tree
  gave 21 of 24 combinations byte-identical. The 3 that differ are the two new
  GPT ids and Haiku 3.5, which had been sent a thinking field it does not
  support.

## Composer fixes the feature depended on

- `agentToManifestStep` dropped per-step `model` and `effort`, so a full
  manifest save discarded the author's model override.
- `handleSave` leaked its re-entrancy lock on two early returns, so after one
  rejected save every later Save silently did nothing.
- `AgentRow`'s model pill rendered "0" for every Claude model. It now reads the
  label from the catalog.
