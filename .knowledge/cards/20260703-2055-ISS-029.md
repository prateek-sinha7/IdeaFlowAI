# ISS-029

## Title

**od_ppt event-golden diverged for ~3 weeks — a planning agent was leaked `example.html`.** `test_characterization_od_ppt::test_od_ppt_event_snapshot` failed: idx 3 (`od-ppt-brief-analyst`) + idx 7 (`od-ppt-composer`) gained a `TEMPLATE EXAMPLE (example.html)` block absent from the golden. Root cause: **KAN-63 commit `b5f5885e` (2026-06-15)** widened the `opendesign` example gate from `is_builder` to `(is_builder or "workspace" in spec_tools)` to feed the deck COMPOSER (intended), but the broad `workspace`-tool proxy ALSO fed the full `example.html` to the order-1 PLANNER `od-ppt-brief-analyst` (`injects:[template]`, `tools:[workspace]`) — violating the **locked Phase-7 decision** (`07-REVIEW-0706.md`: a proposal to loosen the gate and "re-leak example.html to planning agents" was explicitly REJECTED) and degrading planning (a finished example nudges copy-continue over decompose). The golden (last regen `0b7ada2b`, pre-KAN-63) was never regenerated → INV-3 broke; Phase 24 hand-waved it as "environmental" and deferred WITHOUT a tracked ID. **FIX (B-explicit — proper, no-shortcut; validated by a 5-agent deep investigation):** re-keyed the gate to `(is_builder or "template_example" in injects)` (`opendesign.py`) + declared a new `template_example` inject on `od-ppt-composer/AGENT.md` (composer only) — a declarative per-agent opt-in (SC-001 name-free), keeping `is_builder` as the prototype-builder path the oracle pins. REJECTED alternatives (evidence-backed): `design_system`-coupled gate (would re-leak to `prototype-specify`/`prototype-plan`, both `injects:[template,design_system]`+`tools:[]`, breaking the prototype oracle); make-the-composer-a-builder (semantically false — it streams the deck as text, and `prototype_emit_only` drags in the injection-parts branch); regen-only Option A (pins the violation). Regenerated ONLY `od_ppt.events.json` (composer keeps the block, planner drops it). 2 regression pins added (`test_context_providers.py`: builder/`template_example`→example ✔ vs `workspace`-planner→✗) — closes the coverage gap that let it ship silently. Verified independently: 5 goldens byte/event-identical (od_ppt now green, other 4 untouched — INV-3 held), oracle 10/10, lint-imports 4/0, scope=4 files. Out-of-scope latent gap noted (composer's `TEMPLATE SEED/REFERENCE` injection-parts branch is prototype-tool-gated → a `workspace` composer receives none; separate follow-up, NOT this fix).
