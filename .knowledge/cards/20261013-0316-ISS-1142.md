While validating [FIX-773](20261013-0316-FIX-773.md), the broader `tests/integration/api/test_run_sandbox_api.py` file produced 182 passes and one unrelated failure on Windows. `TestRead.test_a_hostile_filename_cannot_smuggle_a_header` tries to create `we"ird name.md`; Windows rejects the filename with `OSError: [Errno 22] Invalid argument` before the response-header behavior runs.

This node was not one of the 100 authoritative CI failures and was not changed in the focused repair. A follow-up should preserve the response-splitting assertion with a platform-valid hostile filename or isolate filename sanitization at the HTTP boundary without weakening the security behavior.
