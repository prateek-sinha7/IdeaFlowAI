# ISS-119

## Title

**Two `TestRouting` tests assert a routing contract the product deliberately superseded, and they will stay red until someone decides which side is right.** `tests/unit/test_chat_messages_endpoint.py::TestRouting::test_clarify_waiting_routes_to_answers_seam` asserts `channel == "answers"` and `test_gate_paused_routes_to_gate_seam_approve` asserts `channel == "gate"` with "default action approve". Both POST bare `text=` with no `action` and no structured `responses`. `app/api/chat_router.py::route_chat_turn` now routes exactly that shape to **`CHANNEL_CONCIERGE`** in both phases, on purpose and with the reasoning in-comment: at `PHASE_CLARIFY_WAITING` "a plain text turn with NO structured responses ... must NOT be auto-submitted as a freeform clarify answer — the user may be asking a question"; at `PHASE_GATE_PAUSED` "a plain free-text turn with no action ... must NOT default to 'approve'". Both are **safety** behaviours: the old contract could silently answer a questionnaire or approve a gate on the user's behalf. So the tests encode the pre-safety contract and the product is almost certainly right — but **reconciling a safety-critical routing contract is not a side effect of a money fix**, which is why FIX-238 left the assertions untouched and the tests red. Since FIX-238 they fail cleanly offline (`JSONDecodeError` on `resp.json()`, because the Concierge branch returns `text/event-stream`) instead of on a swallowed Bedrock error. **Decide:** reconcile the two cases to assert `concierge` (and add cases pinning that a *structured* clarify answer still reaches `answers` and an *explicit* gate action still reaches `gate`, which nothing currently proves for the bare-text neighbours), or establish that the routing change was wrong. Do not delete or loosen them. A third red in the same class, `test_terminal_routes_to_revision`, is unrelated and still open on `AttributeError: '_FakeUser' object has no attribute 'tier'` (`run_commands.py:2497`, the KAN-161/ISS-055 entitlement gate reading `user.tier` off a stale test double at `:33`).
