## Description

Workflow History always opens detail view for running runs — no active-run awareness

## Root cause

WorkflowHistoryProps had no activeRunId/onViewRunningPipeline props; handleSelectRun opened the history detail for every run unconditionally. Added two props, branched in handleSelectRun (run.id === activeRunId → navigate to execution), and passed pipelineState?.pipelineRunId + setMainView("execution") from DashboardLayout
