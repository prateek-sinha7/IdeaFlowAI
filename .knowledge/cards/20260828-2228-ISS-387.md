## Root cause

`frontend/src/components/results/AgentThinkingTab.tsx:84` declares
`selectedAgentId` (and `:85`'s `selectedTaskIndex`) as plain `useState`. The
only writers are `onOpenAgent={(id) => { setSelectedAgentId(id);
setSelectedTaskIndex(null); }}` (`:295`), the task-level equivalent
`onOpenTask` (`:282`), and their `onBack` resets (`:254` clears the task,
`:260` clears the agent). None of them call `router.push`, `router.replace`,
or `window.history.pushState`/`replaceState`.

Confirmed by grepping the whole component plus its two collaborators,
`StepsOverviewSpine.tsx` and `AgentDetailPanel.tsx`, for
`router\.|useRouter|window.history|pushState|replaceState`: the only hit in
either file is `StepsOverviewSpine.tsx:43,52`, an unrelated
`router.push(routes.runStream(...))` on a "divert to another run's live
stream" link — not an agent/task selection.

Because no browser history entry is created when the user drills from the
list into an agent (or from an agent into a task), pressing Back after that
click does not step back to the level the user just left — it navigates to
whatever page/route preceded the Steps tab being opened at all (e.g. the
dashboard, or wherever the run was opened from).

This is the same missing-URL-sync mechanism [ISS-277](20260828-1659-ISS-277.md)
already names for the OUT direction ("the manual in-page click ... writes
only to component state, never calling router.push/replace"). This card
records that mechanism's distinct, independently-observable consequence —
browser back/forward semantics — separate from ISS-277's own focus
(shareability/bookmarkability of a fresh `page.goto`).

## Confirmed vs inferred

**CONFIRMED** (read directly): no router/history call exists anywhere in
the three files that implement Steps-tab selection state, and
`selectedAgentId`/`selectedTaskIndex` are plain component state with no URL
involvement (`AgentThinkingTab.tsx:84-85,254,260,282,295`).

**INFERRED**: the exact Back-button behavior (that it lands on the
pre-Steps-tab page, rather than doing nothing or erroring) follows
necessarily from "no history entry was ever pushed for the selection," but
was not itself driven live in a browser during this analysis pass.
Confirming it: from a completed run's Steps tab, click an agent row, then
press the browser Back button, and observe which page renders.
