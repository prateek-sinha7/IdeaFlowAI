# ISS-100

## Title

**The handoff pipeline's model spend is 100% invisible: there is nowhere to even put the number.** Three call sites construct/call agents that ACCEPT a `usage_sink` and are given none — `app/services/handoff_pipeline.py:403` (`classify_task`, sink at `classifier.py:33`), `:494` (`TestAgent()`, sink at `test_agent.py:109`), `:514` (`ComplianceAgent()`, sink at `compliance_agent.py:121`) — and `app/agents/handoff/coder.py:235` drains `astream_events` with no `usage` branch, exactly the defect FIX-233 fixed in the Concierge. `handoff_sessions` has **no token column at all** (21 columns, none cost-related), so even a correctly captured number has no home. **Why it was split out rather than fixed with ISS-092:** different code (a generator over `websocket_handoff.py`, not `run_commands.py`), different lifecycle, no shared ctx / ScopedStore / run_events stream — nothing in the Concierge fix is reusable. The wiring is ~10 lines; the missing cost SURFACE is a feature, not a bug fix. And it is unverifiable offline: it needs a real repo, a real clone and real GitHub credentials, so bundling it would have put an unprovable half inside a fully-proven one.
