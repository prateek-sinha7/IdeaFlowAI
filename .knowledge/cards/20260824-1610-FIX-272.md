Saving a PPT or Prototype workflow via `LaunchWizard` failed with
`422 Unsupported base_pipeline_type: 'od_ppt'`.

**Root cause:** `MODE_CONFIG[mode].savePipeline` still used the retired values
`"od_ppt"` / `"od_prototype"` (`LaunchWizard.tsx`); the backend's current pipeline
registry/entitlements only accept `"ppt"` / `"prototype"` (the `od_` label was collapsed
onto the bare name — see `frontend/src/lib/entitlements.ts`'s own header comment on the
same collapse for the entitlement-gating side of this).

**Fix:** updated the `savePipeline` field's type and both `MODE_CONFIG` values
(`prototype.savePipeline: "od_prototype" -> "prototype"`,
`ppt.savePipeline: "od_ppt" -> "ppt"`). Updated the one stale test assertion
(`expect(body.base_pipeline_type).toBe("od_prototype")` ->
`.toBe("prototype")`) in `LaunchWizard.test.tsx` to match the corrected behavior.
