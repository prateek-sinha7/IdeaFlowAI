# ISS-951

## Description

Observed while regression-testing [FIX-707](20261002-0134-FIX-707.md). **Not analysed.** It is
recorded here so it is not rediscovered from scratch.

`backend/tests/integration/agents/test_engine_runner_error_arm.py::test_task_loop_all_tasks_succeed_stays_clean`
(`:446`) is the [ISS-028](20260614-0527-ISS-028.md) dormancy guard. It drives the `prototype`
pipeline with `fail_on_build_call=0`, so no build task errors, and asserts a CLEAN
`pipeline_complete` with no `status` key (`:463`). The test file is unchanged from HEAD (last
touched `1d95275b4`).

## Evidence (observed 2026-10-02, `backend/.venv/bin/python -m pytest <file> -q`, conftest SQLite, offline)

- Shared working tree: 5 passed / 1 failed. The failing assertion:

  ```
  AssertionError: ISS-028 dormancy: an all-success task_loop must NOT carry a degraded status key
  (INV-3 byte-parity); got {'pipeline_type': 'prototype', ..., 'agents_completed': 6, 'agents_total': 5,
  ..., 'status': 'degraded', 'published_status': 'degraded', ...}
  ```

- A scratch copy of the tree with FIX-707's two hunks reverted gave the same id, 5 passed / 1
  failed.
- A scratch copy with every modified file under `backend/agents` and `backend/app` replaced by its
  HEAD `024c03ef8` version (tests unchanged; none of the files this test imports differ from HEAD)
  also gave the same id, 5 passed / 1 failed. **So the failure is present at HEAD and comes from no
  in-flight QA-KB fix.**

The run makes no `agent_error` (that assertion, `:456`, passes). It still publishes `degraded`,
and it counts one more completed agent than the roster holds (6 > 5).

## What would settle it

Find where the `prototype` task_loop's terminal `pipeline_complete` gets `status: degraded` on an
all-success run. Candidates to read first are the `published_status` / degraded reconciliation and
whatever counts `agents_completed`. The 6-of-5 count suggests a step is counted twice, possibly a
validation re-run of `prototype-build`. Then decide whether the product or the guard has drifted.
