## Change

- Step commit: a binary file git refuses is logged; the rest of the step is
  still committed.
- Run status: a degraded run names its cause (`degraded (no reason was
  recorded)` instead of an empty failed-agent list); an unhandled exception
  finalizes the run as **failed**, not completed.
- A manifest step's `model.fallback` list is honoured.
- Fan-out `subagent_result` events carry the worker's `model_id`, so the UI can
  show which model each sub-agent ran on.
- `AGENT_RECURSION_LIMIT` 1000 → 2500: the backlog Reviewer was cut off at 360
  tool calls with fixes unfinished (run `5ab1be23`).
