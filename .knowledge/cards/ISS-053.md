# ISS-053

## Title

update_specs_eligible is an FE affordance only — _run_review_gate (engine.py:5470) acts on the gate action WITHOUT ever consulting it. A replayed or hand-crafted POST can therefore trigger a revision from a gate where the UI does not offer one, bypassing whatever eligibility rule is in force.

## Source / evidence

Found by the si4 planner while evaluating whether suppressing the affordance would be a sufficient fix for ISS-050.
