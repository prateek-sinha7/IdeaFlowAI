## Change

- Listing shows every file, reserved subtrees included, `.git` last. Anything
  listed can be opened and is in the zip — a listed `.uploads/`, `.logs/` or
  `.extract/` file previously 404'd.
- `.extract/` readable by agents, excluded from previous-run context.
- `.family.lock` is never a deliverable.
- Single-file read/download cap raised from 8 MB to 64 MB: the backlog's
  14-18 MB `Backlog.pdf`/`.zip` returned 413.
- Workspace tab Refresh button re-lists the same run without closing the open
  file or collapsing the tree.
