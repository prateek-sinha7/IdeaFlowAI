## Origin

Split out of [ISS-671](20260917-1345-ISS-671.md) ("Defect 2") when
[FIX-522](20260917-1449-FIX-522.md) resolved ISS-671's git-search escape. ISS-671 called this
"independently worth a fallback error state regardless of the backend fix". FIX-522 did not change
it, so it is recorded here as a separate, open issue.

## Mechanism

All in `frontend/src/components/preview/PreviewPanel.tsx`:

- `RefVersionPreview` (`:337-340`) renders `Loading {tag}…` whenever `content === null`. It has no
  failure state.
- The ref-scoped fetch effect (`:1255-1269`) returns early unless `deliverableFile` is set
  (`:1257`). `deliverableFile` comes from a separate effect (`:1188-1248`) that calls
  `resolveRunDeliverable(token, activeRunId, declared)` (`:1239`) with no ref, so it resolves
  against the LIVE tree.
- When that resolution returns null or throws (the catch at `:1242-1245` is silent), the ref fetch
  never runs.
- When the ref fetch rejects, its catch (`:1263-1267`) only calls `console.warn`.

Either way `content` stays `null`, and the Preview shows `Loading {tag}…` indefinitely.

## Reachability after FIX-522

QA-PS-008's path is closed. Menu tags now come only from a sandbox's own repo, and finalize maps
each tag to its run or rolls it back (`backend/agents/execution_engine/engine.py:2283-2329`).
Still reachable, by reading the code (not reproduced):

- **(a)** A pinned member's declared deliverable is absent from the live tree but present at the
  tag, e.g. a later revision renamed or removed it. This is the same ref-blind resolver class as
  [ISS-665](20260917-1311-ISS-665.md).
- **(b)** `GET /sandbox/file?ref=` rejects for any reason.
- **(c)** A tag in the menu matches no `FamilyMember`, and `handleVersionMenuSelect` takes its
  no-match branch (`:819-824`) on a run whose live tree has no deliverable.

## Disposition

Open. It needs a small UX decision (failure copy, and whether to offer "Back to latest" inline),
plus a test that renders `RefVersionPreview` through `PreviewPanel` with a failing
resolution/fetch.
