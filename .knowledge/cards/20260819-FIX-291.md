# FIX-291

**Phase / trigger:** `hotfix/permissions-issues`, merged to `dev`
(`0520e2f44`, 2026-08-19). Same squashed commit as FIX-290
(`ec1ea70f5`).

## Description

`od_prototype` owned only the LAUNCH half of the prototype lifecycle
(only `od_prototype` loaded template context — see the eligibility note
that used to live in `app/api/launch_context.py`) while
`prototype_revision` owned the REVISION half, bridged by hand-written
remap tables in the API layer that existed in only one of the two entry
points. A run launched as `od_prototype` therefore could not be revised
over REST at all: `get_pipeline_agents` never resolved the alias while
`compile_for_run` did, so one label meant "5 agents" to one code path and
"unknown" to the other.

## Root cause

Two independent, hand-maintained alias tables (`_OD_ALIAS_BASE` in
`registry.py`, plus a separate `_ID_ALIAS_TYPES` frozenset in
`loader.py::_discover_supported_pipeline_types`) that could silently
diverge, each requiring manual updates whenever a label was added or
retired.

## Fix

Collapsed the `od_prototype`/`od_prototype_revision` labels onto
`prototype`/`prototype_revision`. `_OD_ALIAS_BASE` is kept as an empty
dict (not deleted) — `resolve_alias` stays a declared port with real
callers, and an empty table makes it the identity function; a future
legacy label costs one line here. `_ID_ALIAS_TYPES` (the third,
non-disk-derivable source of `SUPPORTED_PIPELINE_TYPES`) is deleted
entirely — every supported pipeline type is now derivable from disk
(ADR-0005), with no exceptions. Persisted rows carrying the old label are
migrated in-place by `alembic/versions/0043_collapse_od_prototype_label.py`,
so nothing needs to stay compatible with it at runtime. No compatibility
alias was kept for `od_ppt`/`od_ppt_revision` either, for the same reason
this fix gives: v1 never shipped, so no persisted run carries those
labels.

## Files changed

- `backend/agents/loader.py`
- `backend/agents/registry.py`
- `backend/alembic/versions/0043_collapse_od_prototype_label.py` (new)
- `backend/app/api/launch_context.py`
- characterization goldens for `od_prototype` deleted (no longer a
  reachable label)
