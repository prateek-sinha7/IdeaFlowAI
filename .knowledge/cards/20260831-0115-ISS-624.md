## Symptom

```
S-12-18 test_every_top_level_screen_survives_a_hard_refresh
        [chromium-/library?tab=hooks-[data-testid="tab-hooks"]]
assert 0 > 0     #  before = page.evaluate("() => document.body.innerText.length")
```

The same test passes for `/workflows`, `/runs`, `/analytics` and
`/settings/constitution`. Only the hooks tab of the library comes back blank.

## What to do

Reproduce in the browser before assuming a test-timing problem — an empty body
on a cold load is the shape of a render that threw, not of a slow one. If it is
timing, the fix belongs in the test; if the page really renders nothing, this
is user-visible on any refresh or shared link.
