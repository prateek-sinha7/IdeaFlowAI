# ISS-1058

## What is wrong

Found while recording the goldens baseline for [FIX-728](20261007-1848-FIX-728.md) (QA-KB-068). It is unrelated to
that fix and was not fixed.

- `backend/tests/conftest.py:446-458`: `_CANONICAL_SUITE_MARKERS` accepts `"agents"` and `"ci"` as legacy suite
  folders.
- `backend/tests/conftest.py:484`: `pytest_collection_modifyitems` tags every item with `getattr(pytest.mark, suite)`.
- `backend/pyproject.toml:156`: `addopts = "-ra --strict-markers --strict-config"`.
- `backend/pyproject.toml:160-176`: the `markers` list registers `unit`, `integration`, `contract`, `e2e`,
  `performance`, `security`, `property` and `smoke`, but not `agents` or `ci`.

So under `--strict-markers`, `getattr(pytest.mark, "agents")` fails for any item under `tests/agents/` (133
`test_*.py` files), and the same applies to `tests/ci/`.

## Observed (2026-10-07, working tree at `64d7b8429`)

    cd backend && python3.11 -m pytest tests/agents/test_event_contract.py -q
    INTERNALERROR>   File ".../backend/tests/conftest.py", line 484, in pytest_collection_modifyitems
    INTERNALERROR> Failed: 'agents' not found in `markers` configuration option

    python3.11 -m pytest --markers | grep -E "^@pytest.mark.(agents|unit|ci)\b"
    @pytest.mark.unit: fast, fully isolated tests ...          (agents and ci absent)

    python3.11 -m pytest tests/agents/test_event_contract.py -q -o "markers=agents: legacy suite"
    24 passed, 1 warning

Neither file has a working-tree change (`git diff --stat -- backend/tests/conftest.py backend/pyproject.toml` is empty).
`"agents",  # legacy` entered `conftest.py` in `09270703b` (2026-09-22). `git log -S'"agents:' -- backend/pyproject.toml`
finds no commit that ever registered the marker.

## Impact

The line's agents run `tests/agents/` files one at a time: regression files, goldens and new red tests, such as the
untracked `tests/agents/test_ex_a4_runner_gate_answer_qa_kb_094.py`. Each one dies at collection unless the caller
overrides `markers`, so a red or green result read from such a run says nothing about the code.

INFERRED: some earlier FIX cards record `tests/agents/` counts. Those runs either used an override or ran before
something in the environment changed. That was not established.

## Where the fix belongs

Register the two legacy suite markers in `backend/pyproject.toml`'s `markers` list (for example
`"agents: legacy suite folder (to be removed in Batch 6) — marker applied automatically by folder hook"` and the same
for `ci`). The other option is to stop tagging the two legacy folders in `conftest.py:484`. Adding the markers is
additive and keeps the hook's documented contract.
