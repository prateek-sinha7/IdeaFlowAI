## Bug

An API spec derived from AWS documentation carried AWS's published example key as a sample value. The secret scan returned its first match, so the copied `AKIAIOSFODNN7EXAMPLE` marked backlog run 3976f8ce degraded.

## Fix

`secret_scan.py` iterates over every match and skips one only when it is exactly one of the two documented example values (`_AWS_DOC_EXAMPLES`), bare or as a quoted assignment value. The marker it returns is still truncated to 16 characters.
