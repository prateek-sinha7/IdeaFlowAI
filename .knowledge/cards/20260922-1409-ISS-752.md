## Origin

INFERRED sibling of [ISS-739](20260922-1407-ISS-739.md) (root cause for
[QA-PS-014](../../BUGS.md#qa-ps-014)), derived from the same missing fetch-in-flight signal
feeding a different tab, not independently reproduced. Would be settled by cold-navigating
directly to `/runs/{id}/steps` for a completed run, or switching to the Steps tab within the
first ~1-3s of a cold `/runs/{id}` load, and observing the tab content.

## Mechanism (traced, not reproduced)

`AgentThinkingTab` receives `agents`/`pipelineState` as props (`DashboardLayout.tsx:3305-3306`,
`agents={pipelineState?.agents}`), sourced from the SAME `pipelineState` reducer that
[ISS-739](20260922-1407-ISS-739.md) traces `handleSelectWorkflowRun` populating asynchronously —
`resetPipeline()` clears it at fetch start, `handleWebSocketMessage` replay refills it once the
durable events are fetched and processed. `AgentThinkingTab.tsx:248-250`:
```
const hasAnyData = pipelineState?.plannerStatus ||
  agents.some(a => a.thinkingText || (a.toolCalls?.length ?? 0) > 0 || a.inputPrompt || a.status !== "idle") ||
  !!runInput || (resolvedClarifications?.length ?? 0) > 0;
```
is `false` for the whole fetch window (empty `agents`, no `runInput` yet), so line `252`
(`if (!hasAnyData) return <EmptyState />;`) renders `EmptyState` (`:69-88`) — whose copy reads
"Pipeline trace / **Start a pipeline** to see real-time agent reasoning, tool calls, and context
flow." For an already-completed run whose trace is simply still loading, this is more actively
misleading than ISS-739's neutral "Output will appear here": it tells the user no pipeline has
ever run, not that data is on its way. No spinner or skeleton appears anywhere in this branch —
`grep -n "animate-spin\|Skeleton" frontend/src/components/results/AgentThinkingTab.tsx` returns no
matches.

## Disposition

Open, INFERRED. Settled by the same class of fix as ISS-739/ISS-740 (thread the fetch-in-flight
flag down far enough that `AgentThinkingTab` — or its `PreviewPanel` wrapper — can show a loading
state ahead of the `hasAnyData` gate instead of `EmptyState`'s "start a pipeline" copy). Recorded
so the fixer's test coverage is not scoped to the Preview tab alone.
