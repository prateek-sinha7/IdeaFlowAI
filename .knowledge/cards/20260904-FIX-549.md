## Related

## What was wrong

In staged upload ingest, a single corrupt file would cause the entire stage 
to fail silently, and all sibling files would be dropped without explanation. 
Failure logs included bound parameters from IntegrityError, exposing the user's 
document text.

## The fix (commit 1e329e47b)

- Each upload stage is isolated; failures do not cascade to siblings.
- Corrupt file fails its own stage; siblings continue independently.
- Failure logs record exception TYPE ONLY (e.g., 'IntegrityError'), never bound parameters.
- Prevents unintended exposure of user document text in logs.

Pinned by test_run_files_upload.py verifying per-stage isolation and 
exception type logging.
