## Description

chat_router auto-approved gate / auto-submitted clarify on plain chat text

## Root cause

PHASE_GATE_PAUSED: plain text with no gate action defaulted to action="approve" — any chat message during a review gate silently approved it. PHASE_CLARIFY_WAITING: bare text mapped to freeform clarify answer — any chat message during clarify questions unblocked the pipeline. Both now route to CHANNEL_CONCIERGE when no explicit action/responses present.
