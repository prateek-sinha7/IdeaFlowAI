## Change

- `@register` accepts `reads` / `process` / `writes` for mechanical capabilities;
  `publish` and `assemble_prototype` declare them; `/capabilities` returns them.
- Canvas config rail: a Reads / Process / Writes card for code steps, a Data tab,
  the agent prompt expanded and rendered as markdown, and a kind icon per node
  (`composer/stepKind.ts`).

## Bug fixed alongside

Canvas edits were undone when the manifest was re-projected over the edited tree.
