## Origin

`bc0a0366e` — *"feat(agents): a playwright tool set agents can be granted
(spec 018)"*, on `feat/conditional-gates`. The same addition moved two count
pins recorded in [ISS-621](20260831-0110-ISS-621.md).

Decide whether a smoke-test fixture is genuinely exempt from parity. If it is,
the exemption belongs in the parity tests explicitly — not as four red rows
someone has to re-diagnose next sweep.

## Resolution

[FIX-435](20260831-1909-FIX-435.md) — the fixture IS genuinely exempt, and the
exemption is now explicit: `playwright_smoke_test` was added to `_PLANNER_SKIP_IDS`
and to the pinned clarify-defaults dict in BOTH parity files, with the same
rationale comment `sample_subagents_parallel` and the `ex_A*` family carry. The
manifest is unchanged — forcing `planner: run` on a one-step fixture that exists
to finish in under a minute would have destroyed the only property it has.
