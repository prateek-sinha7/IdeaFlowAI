## What changed

All three tests in `backend/tests/agents/test_declared_gate_streaming.py` take
the `monkeypatch` fixture, and each patch site became:

```python
monkeypatch.setattr(engine_mod, "compile_for_run", _patched_compile_for_run)
```

The three manual restores in the `finally` blocks were deleted — monkeypatch
restores at teardown however the test exits, including an exception raised
before the `try` is entered.

This was chosen over moving the precondition assertion above the patch: that
would have fixed the one assertion that happened to fail, and left every other
line between the patch and the `try` able to leak the same way.

Deliberately NOT done: making `_isolate_compiled_plan_cache` tolerate a missing
`cache_clear`. That hides the leak instead of preventing it, and a silently
un-cached `compile_for_run` changes what the tests downstream are measuring.
