## What was wrong

`LibraryPage` calls `useSearchParams()` unconditionally at the top of the function
(to read `?tab=` and `?category=`). The Next.js App Router requires any component
calling `useSearchParams()` to be wrapped in a `<Suspense>` boundary; without one the
component suspends during static/SSR rendering, producing an empty body on hard
refresh. `DashboardLayout.tsx` rendered `<LibraryPage />` with no Suspense wrapper.

The symptom was specific to `/library?tab=hooks` (and would also affect `?tab=skills`)
because those test paths exercise the `useSearchParams` code path with a non-null
query string.

## What changed

`frontend/src/components/layout/DashboardLayout.tsx`:

- Added `Suspense` to the `react` import.
- Wrapped `<LibraryPage />` in `<Suspense fallback={null}>`. The `null` fallback is
  intentional — the `mounted`/`isAuthenticated` gate in `page.tsx` already prevents
  any render until the client is ready, so there is no visible flash.
