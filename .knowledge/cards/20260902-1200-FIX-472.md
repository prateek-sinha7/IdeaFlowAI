## What was wrong

`AgentSkillsPicker.tsx` — "the ONLY skill-attachment UI in the app" — carries a
`detailSkill` state that opens a `role="dialog" aria-modal="true"` popup for a single
skill's details. The popup had a backdrop `onClick` and a Close button `onClick` to
dismiss it, but `grep -n "Escape\|keydown\|KeyboardEvent\|addEventListener"` returned
zero matches in the file. Pressing Escape while the skill-detail popup was open did
nothing.

This is reachable from three independent embedding surfaces: `AgentCapabilitiesModal`'s
Skills tab (`AgentsPopup.tsx:870`), the Composer Simple view's per-agent row
(`AgentRow.tsx:267`), and the Composer Canvas view's config rail
(`CanvasConfigRail.tsx:468`).

## Root cause

`frontend/src/components/workflow/composer/AgentSkillsPicker.tsx` — no Escape/keydown
handler anywhere in the file.

## What changed and why there

[FIX-388](20260829-0053-FIX-388.md) already created `frontend/src/hooks/useEscapeToClose.ts`
for exactly this class of missing handler. This is a two-line change per FIX-388's
own note: "Both are still INFERRED — no live repro, no test — and both own their own
files under their own cards, so they are out of this fix's globs. **The hook they
need now exists; each is a two-line change when its own card is worked.**"

Changes in `AgentSkillsPicker.tsx`:

1. **Import** added (alongside existing hooks):
   ```ts
   import { useCallback, useLayoutEffect, useMemo, useRef, useState } from "react";
   import { useEscapeToClose } from "@/hooks/useEscapeToClose";
   ```

2. **Hook call** placed alongside the `detailSkill` state (hooks must precede any
   early returns — there are none here, but placement keeps hooks grouped):
   ```ts
   const closeDetailSkill = useCallback(() => setDetailSkill(null), []);
   useEscapeToClose(closeDetailSkill, detailSkill !== null);
   ```

`enabled = detailSkill !== null` ensures the document-level keydown listener is only
registered while the popup is actually open — a hidden dialog must not swallow Escape
from whatever is on screen below it.
