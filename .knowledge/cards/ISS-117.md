# ISS-117

## Title

Validation frames are dropped on replay, so no run reopened from history can ever show a gate verdict. useRunStateStore.ts:395-403 lists pipelineFrameTypes and omits validator_result, gate_passed and gate_blocked; :405 is an explicit if (!pipelineFrameTypes.includes(msg.type)) return; early return. So even the one reachable path (gate_blocked, which has 3 real producers) cannot rehydrate validationPassed when a run is opened from Run History — ValidationResultCard (AgentDetailPanel.tsx:839) self-gates on passed === undefined and renders nothing. This is independent of ISS-116: fixing the producer gap alone would still leave history blind.

## Source / evidence

The ISS-087 investigation flagged this as suspected without tracing the replay path; quick-260812-kpb read the filter and its early return directly. Not observed on screen — the DB has no such rows to replay.
