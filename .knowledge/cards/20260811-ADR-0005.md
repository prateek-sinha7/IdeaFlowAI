# ADR-0005

## Decision

In the context of a hand-maintained frozenset of supported pipeline types that had to be
edited by hand for every new workflow, facing SC-001's rule that launchability keys on a
declared flag and never on a hardcoded name list, we decided the set is derived from
disk once at import and template agents mark themselves with a `template: true` flag, to
achieve adding-a-workflow-is-adding-a-folder, accepting that four test-fixture manifests
become visible and two ISS-015 assertions must move from "absent" to "not launchable".

**Area:** loader, registry, workflow
