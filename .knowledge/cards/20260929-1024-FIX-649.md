## Bug

Attach the same file twice, remove one chip: the side-list filter removed every
upload with that filename, the remaining chip stayed on screen, and the run
launched with no files.

## Fix

`withoutOne` in `lib/uploadTypes.ts` removes only the first match; used by the
LaunchWizard, IdeaInputPage and `useChatAttachments`. The picker also accepts
`.html`/`.htm` (see [FIX-646](20260929-1024-FIX-646.md)).
