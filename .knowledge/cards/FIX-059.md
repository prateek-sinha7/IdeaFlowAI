## Description

Option B: Replace custom_prototype manifest copy with runtime deliverable override via __deliverable__ selections key

## Root cause

custom_prototype was an exact copy of prototype/workflow.yaml with clarify.mode:skip — a manifest-copy anti-pattern (INV-12 violation). Option B: FE resolveDispatchType now returns {type:"custom", deliverableOverride:{strategy,name,mimetype}} for prototype agents; handleRun injects __deliverable__ into the selections map; engine._apply_selections reads it, calls DeliverableSpec(**override) and dataclasses.replace(compiled.clarify, mode="skip") — same skip behaviour, zero manifest copy. custom_prototype manifest deleted; all references removed from loader/registry/entitlements/websocket/types/DashboardLayout/page.tsx.
