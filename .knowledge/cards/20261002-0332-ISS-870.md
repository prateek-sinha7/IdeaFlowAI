## What is broken (read from config, not run)

The `container-scan` job (`.github/workflows/ci.yml`, about line 1013) builds
`./backend/Dockerfile` with `context: .`. `backend/Dockerfile` is written for
`context: ./backend`:

- `COPY pyproject.toml uv.lock ./` and `COPY app/ ./app/` expect those paths at the
  context root.
- `COPY --from=opendesign` needs the `opendesign` named build context, which this step
  does not pass.
- No `.dockerignore` applies either: there is no repo-root `.dockerignore` and no
  `backend/Dockerfile.dockerignore`.

The deploy build (`deploy.yml` "Build + push backend": `context: ./backend` plus
`build-contexts: opendesign=./skills/opendesign`) is set up correctly. That is the only
build that exercises [FIX-646](20261002-0332-FIX-646.md)'s bake block and `RUN` guard.

## Disposition

Open. Docker is not available on the machine where this was found, so the job's real
outcome was not observed. Point the backend leg at `context: ./backend` and pass the
`opendesign` build context, matching `deploy.yml` and `_docker.yml`.
