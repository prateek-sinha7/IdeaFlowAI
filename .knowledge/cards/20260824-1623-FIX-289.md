`/workflows/{type}/canvas` worked when typed directly but opened empty when reached by
clicking, and a cold load showed the agents with `0 review gate` and no Route badge.

## Root cause, two seeds

**Agents.** The existing re-sync effect is one-shot:

```js
if (resyncedAgentsFromLibrary.current || ALL_LIBRARY_AGENTS.length === 0) return;
resyncedAgentsFromLibrary.current = true;
if (initialManifestSteps?.length) { ... }
```

On a COLD load the library is also still empty, so it returns early and gets a second
chance once both are ready — which is why direct URLs worked. On CLIENT-SIDE navigation
the library is already populated, so it fired with no props, burned its ref, and never ran
again.

**Gates.** `selections` was seeded by a `useState` initializer only and never re-derived,
so gates were missing even when agents were present.

## Fix

Both now keyed on `initialManifestSteps`, so they fire when the props actually arrive.
Verified live: `ex_A1_loop` renders 4 agents, `1 review gate`, and route edges
`ok` (forward) and `retry ↺3` (backward).
