# ISS-070

## Title

The gate-action discriminator is unvalidated, and an unknown action silently APPROVES. run_commands.py resolve_gate dispatches on action with else: # approve as the fallback, so any unrecognised string — a typo, a stale client, a probe — resolves the HITL gate as approved. GateCommand.action is a bare str with no enum (live OpenAPI confirms {"type": "string", "default": "approve"}) while the frontend declares the closed union `"approve" \
