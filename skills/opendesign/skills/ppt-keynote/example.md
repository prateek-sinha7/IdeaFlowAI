# HTML Anything · Product Introduction

## The Problem We're Solving
- Markdown is easy to write but ugly once published
- Screenshots for tweets look terrible
- Newsletters / Zhihu each have their own formatting rules

## Our Solution
**Any input → world-class HTML**, using your local AI agent

## Three Essentials
1. Reuses the local agent you're already logged into (Claude / Cursor / Codex) — no API key needed
2. 9 world-class templates (slides / resume / poster / social post / data report ...)
3. One-click copy to newsletter / Twitter / Zhihu, or export as PNG

## By the Numbers
- 80 seconds to generate a ready-to-ship 31KB article
- 9 templates, 8 local agents supported
- 0 API keys, 100% reuse of local sessions

## Why Now
The Claude team no longer writes markdown — they switched entirely to HTML. HTML is the final form meant for readers, and AI means "verbose" is no longer a problem.

## Get Started
`pnpm dev` → open your browser → ⌘+Enter
