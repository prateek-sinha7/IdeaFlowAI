# knowledge-arch-blueprint

Cream paper (`#F0EAE0`) background + a single rust-red (`#B5392A`) accent + hard black-outlined cards + dashed feedback-loop arrows. Inspired by `20260405-architecture-diagram-v2.html` — a genuine "technical whitepaper architecture diagram," like a building blueprint.

**Visual traits:** warm off-white paper background, a faint 48px grid for blueprint feel, crisp 2px black-bordered cards, pipeline step-boxes lined up with a raised hero box, a red insight callout in the top right, uppercase kickers with 2.5-4px letter spacing, SVG feedback-loop dashes + arrows, large Playfair serif numerals, no gradients or shadows — extremely restrained.

**Use when:** presenting system architecture, data flow, or process breakdowns; you want the content to look like a serious technical whitepaper rather than a marketing post; you need a formal, print-like feel that can be screenshotted straight into a README.
