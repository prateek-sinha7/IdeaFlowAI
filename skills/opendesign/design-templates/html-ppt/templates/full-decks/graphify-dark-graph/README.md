# graphify-dark-graph

Deep-night dark background + force-directed knowledge-graph overlay + warm glassmorphism cards. Inspired by `20260413-graphify/ppt/graphify.html`'s `#06060c` gradient background, drifting orb glow, glass cards (warm/blue/green/purple variants), and rainbow-text headings.

**Visual traits:** `#06060c → #0e1020` diagonal gradient, three 400-520px blurred orbs drifting slowly, a force-directed graph SVG as the cover background, rainbow-shift gradient headings, JetBrains Mono `.cmd-glow` command line, glassmorphism cards with top highlight and subtle inner shadow, warm accent palette (#e8a87c amber / #7ed3a4 mint / #7eb8da mist blue / #b8a4d6 lilac).

**Use when:** Introducing a developer tool, CLI product, knowledge graph / data visualization project — when you want the live demo to feel "AI-native + high-tech + warm."

**Source inspiration:** `20260413-graphify/ppt/graphify.html`.
