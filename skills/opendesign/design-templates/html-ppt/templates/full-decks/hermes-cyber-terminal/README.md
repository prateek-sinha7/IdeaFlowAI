# hermes-cyber-terminal

Black background (`#0a0c10`) + terminal chrome + scanlines + mint-green glow display type + JetBrains Mono typewriter feel throughout. Inspired by the dark `#15151b` codebox in `20260414-hermes-agent/ppt/hermes-record.html` and the hands-on-comparison tone of `hermes-vs-openclaw.html` — merged into one "honest cyber review" deck.

**Visual traits:** 56px cyber grid + CRT vignette + translucent scanline overlay, window traffic-light chrome, `$ prompt`-style command-line headings, mint-green text-shadow glow `#7ed3a4`, monospace throughout, bar charts rendered stroke-only, blinking cursor, amber/green/red severity tags.

**Use when:** reviewing a dev tool / CLI / agent, showing benchmark data, traces, diffs; you want an instant "honest technical review" tone; works well for long traces / long code blocks.

**Source inspiration:** `20260414-hermes-agent/ppt/hermes-record.html` + `hermes-vs-openclaw.html`.
