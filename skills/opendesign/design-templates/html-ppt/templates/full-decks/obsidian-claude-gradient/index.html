03 / 08
● COMPARE

Notion vs Obsidian · AI-friendliness

NOTION

Database-native

Great for structured tasks and team collaboration, but —
• AI has to go through the API, no real-time full-text access
• Nested block structure is complex, expensive in tokens
• Poor local access, can't serve as long-term memory

OBSIDIAN

Pure Markdown + backlinks

Naturally AI-friendly —
• Everything is just a file, Claude reads it directly
• Backlinks form a natural graph, entity extraction is nearly free
• Offline, git-able, diffable, revertible

💡 Key insight: AI doesn't need a "smarter database" — it needs a "file system it can read for itself."
04 / 08
● SETUP · 4 STEPS

From zero to your first "AI-written note"

1

Install Obsidian + enable the Local REST API plugin

A community plugin — one checkbox turns it on. It lets an external process read/write your vault.

2

Connect Claude Desktop + the obsidian-mcp server

MCP connects with a single config file — just fill in your vault's API key as the token.

3

Install the 5 obsidian-skills

markdown / bases / canvas / cli / defuddle — so Claude knows how to use Obsidian correctly.

4

Let Claude do a pass on its own

"Merge the duplicate concepts across my last 10 notes into a new MOC" — done in 90 seconds.

05 / 08
● MCP CONFIG

claude_desktop_config.json

// ~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-obsidian"],
      "env": {
        "OBSIDIAN_API_KEY": "xxxxxxxxxxxxxxxx",
        "OBSIDIAN_HOST": "http://127.0.0.1:27123"
      }
    }
  }
}

Restart Claude Desktop, type /mcp, and you'll see obsidian connected.
