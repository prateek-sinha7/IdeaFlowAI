The Fix

The Answer Isn't
a Bigger Window.

It's this: write your knowledge, preferences, and history into a file system.
Have the LLM read it before every conversation.

× Window stuffing

Cram everything into the prompt — expensive, slow, and it eventually overflows.

✓ Files + retrieval

Load on demand, never overflows, structured and diffable.

Minimal Setup

4 Lines of YAML
to Get Started.

memory:
  root: ~/.llm-wiki
  format: markdown
  retrieval: hybrid  # embedding + bm25

You now have a second brain that grows over time. It gets read and updated on every conversation.
