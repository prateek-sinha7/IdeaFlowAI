# dir-key-nav-minimal

8 slides, each a solid-color or gradient mono-background (indigo / cream / crimson / emerald / slate / violet / white / charcoal). Directly inspired by `20260405 Presentation Slides [Directional Key Edition].html` — eight `t-*` theme classes, one background per slide, arrow-key navigation, minimal editorial tone.

**Visual traits:** each slide has its own background color + single accent, a huge 160px title with no supporting image, a 4px short blunt accent-line divider, an arrow-prefixed mono list, bottom-left `← →` keyboard hint + bottom-right page label, full-screen breathing negative space, JetBrains Mono for numbers / code / keyboard hints, and every background has its own `.dk-accent` color.

**Use when:** you have something to say and not many images, and want typographic rhythm to carry the audience's attention; keynote-style minimal talk decks; one idea per slide; public talks / keynotes / speeches.
