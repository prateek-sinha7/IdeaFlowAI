The most important call of 2026

Stop asking
whether AI can do the work
Start asking: who's on the hook when it fails

The cost of an AI mistake is no longer a single bad response — it can write 300 tickets, open 80 PRs, and send 5,000 emails in one go.

Risk now scales

The cost of getting it wrong scales by N; the payoff of getting it right scales by N.
That's why testing, review, safety, and risk control will be the most valuable skills of the next 3 years.

risk tiers · 3 levels03 / 08

Three risk tiers, three responses

L1 · Green

Reversible

Writing drafts, generating images, drafting docs.
Wrong? Ctrl+Z, zero cost.
Policy: let it run

L2 · Amber

Partially reversible

Sending draft emails, opening PRs, editing staging data.
Wrong? You apologize / roll back.
Policy: human review

L3 · Red

Irreversible

Sending real emails, payments, dropping databases, deleting prod data.
Wrong is really wrong.
Policy: hard block + two-person sign-off

Never let an agent escalate itself

An L1 task can't silently become L2. Authorization must be explicit, revocable, and time-boxed.

policy as code04 / 08
Don't govern rules with docs · Govern rules with code

Thirty lines of YAML,
a hard-blocked red line

# safety-policy.yaml · compiled → runtime guard
level_1_allow:
  - tools: [write_draft, generate_image, read_docs]

level_2_require_review:
  - tools: [send_email_draft, open_pr, write_staging_db]
    reviewer: human

level_3_hard_block:
  - tools: [send_real_email, transfer_money, delete_prod]
    unless: two_human_sign_off AND within_24h

forbidden_always:
  - "rm -rf /"
  - "drop table"
  - "force push origin main"

red-team checklist06 / 08

7 questions you must clear before launch

✓
Can it delete things? Is there human review? Can you roll back within 60 seconds?
✓
Can prompt injection escalate its privileges? (Have you run red-team prompts?)
!
Does it handle PII? Does PII end up in the logs too?
✓
If an upstream/downstream call fails, will it start touching other resources randomly?
!
Will 100 concurrent agents deadlock each other?
✓
Can it be stopped immediately when wrong? (Does the kill switch take effect within 2 seconds?)
!
Is someone on call when it fails? Does the on-call runbook have an agent-specific section?
