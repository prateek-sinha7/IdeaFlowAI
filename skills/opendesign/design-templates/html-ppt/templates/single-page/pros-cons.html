Trade-offs · An honest tally

Pure HTML slides: what's great, what hurts

✓ Pros

  • Zero build: runs from a single file
  • Diffable: Git-friendly, easy to review
  • Programmable: animations are fully customizable
  • Shareable: works as a URL, PDF, or PNG

✗ Cons

  • Collaboration isn't as real-time as Keynote
  • A bit steep for non-developers
  • Complex animations still need JS
  • Some fonts are missing in offline environments
