Quickstart

Deploy your first project in under five minutes. The CLI is the fastest path; the dashboard and the API client all wrap the same engine.

1. Install the CLI

The CLI is distributed as a single binary for macOS, Linux, and Windows.

# macOS · Homebrew
brew install anchor

# Linux · curl
curl -fsSL https://get.anchor.dev | sh

Verify the install:

anchor --version
# anchor 0.6.4

2. Authenticate

Sign in with your Anchor account. The token is stored in ~/.config/anchor/credentials.

anchor auth login
# → opens your browser
# ✓ Logged in as you@example.com
Note
On servers without a browser, use anchor auth login --device for a device-code flow.

3. Deploy a project

Pick a local directory and link it to a remote environment. Anchor builds it and pushes zero-downtime releases in the background.

cd ~/projects
anchor init my-team
anchor deploy

Excluding files

Add a .anchorignore at the root of the deployed project. Same syntax as .gitignore:

node_modules/
*.log
build/

4. Where to go next

Read Rollback strategy to understand how Anchor reverts a bad release, or skip to the CLI reference for the full subcommand list.
