# GIT_VERSIONING_BUGS — open defects, off-spec behaviour, and misleading documentation

> **Purpose:** `GIT_VERSIONING_GAP.md` is the spec audit and `GIT_VERSIONING_TASK.md` is the work programme. Both are closed as programmes. This file is the single list of what is still **broken, deliberately off-spec, or undecided** on this branch, so the other two can be retired.
> **Updated:** 2026-09-15 12:47. **Branch:** `feat/git-versioning`. **Spec under test:** `specs/019-sandbox-git-versioning/spec.md` rev 8.
> **2026-09-15/16:** the datestamp above had been left at 2026-09-12 while the 2026-09-14 fix round was written into the rows beneath it. Corrected, and **B22 – B31** added. B22, B23 and B25 came from the owner using the product; the rest came from sweeping for the *classes* those three belong to, which is how B24, B26, B27, B28, B29, B30 and B31 were found. **The dominant class is a capability that is built, registered, unit-tested and declared by no workflow** — B23 (chain context), B27 (provenance audit) and B31 (seven validators) are three subsystems dark right now for that one reason, and no test in the suite can see it. The second class is two declaration systems for one concept that disagree — B26 and B30. The third is one rule implemented several times where only one copy gets fixed — B17, B28 and B29.
> **The 2026-09-12 revision** re-verified every previously-recorded open item against the tree rather than copying it forward. Three items were newly found, three were closed as already fixed, one was found to be misattributed, and four whole sections of the older documents were found to be stale. Everything below was checked on 2026-09-11/12; nothing is inherited on trust.

## Severity

- **P0** — a headline feature does not work, or a stated guarantee can be broken.
- **P1** — wrong or misleading behaviour, or a decision the owner must make.
- **P2** — verification debt and hygiene.
- **S** — shipped behaviour that deliberately contradicts spec 019's text. Not defects; the spec is what is out of date. Listed so the divergence is explicit rather than implied.
- **D** — documentation that is now actively wrong and will mislead the next reader.
