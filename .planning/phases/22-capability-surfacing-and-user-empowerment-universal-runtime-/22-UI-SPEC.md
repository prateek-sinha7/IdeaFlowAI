## Spacing Scale

The live composer uses an 8-point-compatible scale with dense `0.5`/`1.5` half-steps for the inspector chrome. Declared values (all multiples of 4 except the documented half-step exceptions inherited from the live `AgentsPopup`/`AgentModelPicker`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`, `mb-1`) | Icon-to-label gaps, inline chip padding |
| sm | 8px (`gap-2`, `p-2`, `mb-2`, `px-2`) | Compact element spacing inside palette rows |
| md | 12px (`px-3`, `py-3`, `gap-3`, `mb-3`) | Default row padding, section gaps |
| lg | 16px (`px-4`, `p-4`) | Panel padding, section breaks |
| xl | 24px (`px-6`, `py-6`) | Popup outer padding |
| 2xl | 32px (`px-8`) | Header/footer rails |

**Exceptions (inherited from live components — do NOT introduce new ones):**
- `py-0.5` (2px), `py-1.5` / `px-1.5` / `px-2.5` (6px / 10px), `gap-1.5` (6px) — the existing dense inspector rhythm in `AgentModelPicker.tsx:107,119,132,136,144` and `AgentsPopup.tsx`. New palette rows and Advanced-expander lever rows MUST match this density (they sit inside the same popup), not the looser 8-point page scale.
- Palette/expander scroll regions cap at `max-h-[200px] overflow-y-auto pr-1` (matching `AgentModelPicker.tsx:132`).

## Typography

The composer uses a deliberately micro type ramp (it is a dense inspector inside a popup, not a page). Declared roles (4 sizes, 2 weights) extracted from the live anchors:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Section eyebrow / group header | 10px (`text-[10px]`) | semibold (600), `uppercase tracking-widest` | 1.2 |
| Row label (capability name / agent name / lever label) | 11px (`text-[11px]`) | semibold (600) | 1.4 |
| Row body (capability description / helper / lock reason) | 11px (`text-[11px]`) | regular (400) | 1.5 |
| Control / option text (`<select>`, chips, catalog `display_name`) | 12px (`text-[12px]`) – 13px (`text-[13px]`) | regular (400) / semibold (600) for emphasis | 1.4 |

> **Weights:** exactly two — regular (400) and semibold (600). The live files also use `font-bold` and `font-medium` sparingly; for THIS phase's new elements, restrict to 400/600 to keep the palette/expander legible at micro sizes. Catalog `display_name` (UXFIX-01) renders at the catalog's existing card title size — do not shrink it to inspector scale.
> **Group headers** (SURF-01 "grouped by kind") reuse the eyebrow style verbatim: `text-[10px] font-semibold text-gray-500 uppercase tracking-widest` (from `AgentModelPicker.tsx:109`).

## Color

The live system is a light surface with a single deep-navy brand accent. Extracted from `tailwind.config.ts`, `src/styles/globals.css` (`@theme`), and the composer hex usage (`#1B2A4A` appears 12× — the dominant accent).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f5f5f0` page bg (`--background`) / `#ffffff` surface (`--surface`) | App background, popup/card surfaces |
| Secondary (30%) | grays — `bg-gray-50` (`#f9fafb`), `bg-gray-100`, `border-gray-100/200`, text `gray-500/700/800` | Palette rows, lever-row backgrounds, sidebar, borders |
| Accent (10%) | `#1B2A4A` (deep navy) | See reserved-for list below |
| Destructive | `#dc2626` (`--error`, `text-red-600`/`bg-red-50`) | Error states only (reuse `AgentModelPicker.tsx:119` error chip) |

**Accent (`#1B2A4A`) reserved for:**
- Active/selected lever in the Advanced expander (selected validator/gate/model/retry chip border + icon, matching `focus:border-[#1B2A4A]` at `AgentModelPicker.tsx:144`).
- The "Advanced" expander toggle icon + label on hover (matching `hover:text-[#1B2A4A]` at `AgentsPopup.tsx:864`).
- The capability-kind group-header icon.
- The primary CTA ("Save workflow" / "Launch") button fill.
- The auto-attach inline notice icon/accent border (EMP-04/D-07).

> Accent is NOT applied to every interactive element — default rows are gray; navy marks **selection, primary action, and the active group**. Do not navy-fill the locked rows (they are visually recessed — see below).

**Semantic states (reuse existing idioms — do NOT invent colors):**
- **Locked / visible-but-locked (EMP-02/D-04):** recessed gray — `bg-gray-50 border-gray-100`, label `text-gray-400`, `cursor-not-allowed`, `opacity-80` (the live disabled idiom: `AgentsPopup.tsx` already uses `cursor-not-allowed`, `opacity-30/80`, `text-gray-300/400`). A `Lock` lucide icon (`h-3 w-3 text-gray-400`) prefixes the row. No navy, no destructive red — locked is neutral-recessed, not an error.
- **Trust badge (user-allowed):** no badge needed for allowed rows (default state); locked rows carry the lock + the engineer-only/upgrade microcopy.
- **Auto-attach notice (EMP-04):** info-tone, navy-accented inline pill — `text-[10px] text-[#1B2A4A] bg-[#1B2A4A]/5 border border-[#1B2A4A]/15 rounded-md px-2 py-1` (derive from the accent; do not introduce a new blue — note `--accent: #2563eb` exists in globals but the composer's own accent is `#1B2A4A`; stay consistent with the composer).

## Interaction & State Contract

**Capability palette (SURF-01/03, EMP-02):**
- Fetches `GET /api/capabilities` on mount via the reused `getCapabilities` shell; states: `loading` → `error` → `empty` → `populated` (same state machine as `AgentModelPicker.tsx:54-103`).
- Rows are **grouped by `kind`**; one group header per kind; ≥1 row per kind present in the payload.
- Each row shows: name (label), description (body), trust state (allowed = composable; `user_allowed=False` = locked), security-gated flag (lock + engineer-only copy), config-schema affordance (expandable iff `config_schema` non-empty).
- **Locked rows are rendered, never hidden** — SURF-01 "every kind visible" is satisfied by showing locked rows for privileged caps. Locked rows are non-interactive for selection (no checkbox/toggle enabled) and carry `aria-disabled="true"`.

**Per-agent Advanced expander (EMP-01/04):**
- Collapsed by default; toggle via the "Advanced" button per agent row. `aria-expanded` reflects state; `ChevronRight` (collapsed) → `ChevronDown` (expanded).
- Expanded reveals lever rows in fixed order: **Validator → Gate → Model → Retry** (then deliverable type / context provider / compaction / fan-out / limits where user-allowed). Each lever reuses the gray lever-row chrome (`bg-gray-50 border-gray-100 rounded-lg px-2.5 py-1.5`).
- Selecting a lever that requires a coupled gate (D-07) triggers the **auto-attach inline notice** and visibly adds/marks the required gate row; the selection feeds the per-step selections map persisted in `manifest_json` (EMP-03).
- An unselected lever = no override emitted (parity with the model picker's "Default" semantics).

**Catalog-as-home (UXFIX-03):** default landing renders `WorkflowCatalog` (data-driven, `GET /api/workflows`); the hardcoded `CreationHub.WORKFLOWS` array no longer drives home. Friendly `display_name` shown per card.

**Generic renderer (UXFIX-04):** a custom/unknown mimetype renders via the generic path as the **primary** route; the 4 first-party types route through the same dispatch table and render identically (regression-proof via the per-type tests).

## Responsive Behavior

The composer is a popup/panel (not a full page); these surfaces inherit `AgentsPopup`'s existing responsive container. Contract:
- Palette + Advanced expander live inside the popup's scroll region (`max-h-[200px] overflow-y-auto pr-1` per group/section) — content scrolls, the popup chrome does not.
- Row labels truncate (`truncate flex-1 min-w-0`, per `AgentModelPicker.tsx:138`); the `<select>`/control caps at `max-w-[140px]` (per `:144`) so long model names never overflow the row.
- Catalog home reuses `WorkflowCatalog`'s existing responsive grid (P20) — no new breakpoints introduced.

## Accessibility

| Element | Contract |
|---------|----------|
| Palette rows | Group headers are headings (`role="group"` + `aria-label={kind}`); each row labelled by its name. |
| Locked rows (EMP-02) | `aria-disabled="true"`; the lock reason is exposed via `aria-label` / `title` (not color/icon alone) so screen readers announce "Engineer-only — not available to compose". |
| Advanced expander | toggle is a `<button>` with `aria-expanded` + `aria-controls` pointing at the lever region; **keyboard operable** (Enter/Space toggles, Tab moves through lever controls). |
| Lever controls | native `<select>`/checkbox elements (keyboard-native), each with an associated visible label; focus ring reuses `focus:outline-none focus:border-[#1B2A4A]` (visible focus via border, per `AgentModelPicker.tsx:144`). |
| Auto-attach notice | rendered as `role="status"` (polite live region) so the gate-added message is announced when a coupled cap is selected. |
| Error chip | reuse the live `AlertCircle` + text pattern; not color-only (icon + text). |
| Contrast | `#1B2A4A` on white and `text-gray-700/800` on `#f5f5f0`/white meet WCAG AA; locked `text-gray-400` is used only for disabled rows (exempt from AA contrast minimum, but paired with the `Lock` icon + text label, never color-only). |
