<objective>
Emit narrator milestone cards LIVE (A.4) and harden the deep-link nonce (Phase-29 WR-02)
BEFORE exposing it. The narrator's `project_milestone_card` / `persist_milestone_card`
(chat_narrator.py:188/234) have ZERO live callers, so milestone cards never appear. Its
deep-link nonce is a process-global in-memory set (`_ISSUED_NONCES`, chat_narrator.py:109)
— unbounded, unscoped, and lost on restart: any caller can consume any nonce (no owner check),
and the set grows without limit. Harden it to a DB-backed, owner+workspace-scoped, bounded,
single-use store FIRST, then wire the live call-site.

Purpose: Live milestone cards are a headline B-check surface; exposing a spoofable/replayable
nonce live is a security regression. The hardening must land before the emission. Traces
REQUIREMENTS CHAT-01 (chat_reply rows through the single stamping boundary) + the WR-02 nonce
deferral. Additive-only (Q3): new table carries owner_id + workspace_id; IDOR→404.

Output: An additive `0025_deep_link_nonces` migration + model, an owner-scoped DB-backed
mint/consume, and the engine event-sink call-site that persists cards — proven offline with
the 5 goldens byte-identical and lint 4/0.
</objective>
