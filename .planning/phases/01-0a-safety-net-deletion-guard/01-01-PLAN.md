<objective>
Stand up the offline characterization harness coverage and record **deliverable byte-snapshots** for all five named pipeline families: `prototype`, `od_prototype`, `prototype_revision`, `od_ppt`, and `app_builder` (the code-gen pipeline). This is the byte-identity half of SAFE-01; the semantic event-stream half is plan 01-02.

This plan REUSES the existing offline driver `backend/tests/agents/_scripted_model.py::_drive()` (D-01) — it already runs `ExecutionEngine.execute()` end-to-end with no network/DB/Bedrock and returns ordered event dicts. The only harness change is EXTENDING `_scripts_for()` with PPT agent scripts (D-02) so `od_ppt` drives deterministically (its three agents `od-ppt-brief-analyst` / `od-ppt-composer` / `od-ppt-validator` are currently unscripted and fall through to the default stub — verify and script them).

Purpose: lock current deliverable output byte-for-byte BEFORE any engine refactor (INV-3 / §24). No runtime code changes — `engine.py` / `factory.py` are read-only this phase.
Output: 5 `test_characterization_<pipeline>.py` modules, the `characterization/` package + `golden/` deliverable snapshots, and extended PPT scripts in `_scripted_model.py`.
</objective>
