## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-10 | Tampering / Elevation | launching a saved composition (seeded agent_ids/model_overrides) | mitigate | the run path is UNCHANGED and re-validates `agent_ids` + `model_overrides` server-side at launch (websocket.py:1385-1406,1466) against the LIVE allow-list — a stale/disallowed saved agent or model is rejected at launch, never trusted from the seed. The FE seed is not a security boundary. |
| T-21-11 | Elevation | base_pipeline_type seeded from a saved row | mitigate | launch re-checks `can_run_pipeline(tier, base)` (websocket.py:576-581); a downgraded user cannot run a saved custom workflow. No new capability grant — exec/network/secrets/spawn stay OFF (pure-data replay, SC-001). |
| T-21-12 | Denial of Service / state corruption | seed not cleared between launches | mitigate | `handleSelectFeature` clears `savedComposition`; the IdeaInputPage re-derive effect is guarded only when `initialAgentIds` is present, so a normal custom launch starts from the empty filter (no stale seed bleed). |
| T-21-SC | Tampering | npm installs | mitigate | no new npm packages (reuses @playwright/test + the existing e2e fixtures); no package-legitimacy checkpoint required. |
