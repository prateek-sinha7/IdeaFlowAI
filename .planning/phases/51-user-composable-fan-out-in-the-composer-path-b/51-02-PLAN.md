<objective>
P5 (backend half) — the additive compile-time guardrail (D9). Today the compiler accepts any `task_source.source_step` string with NO check that it names a real, earlier step (`compiler.py:436-457`), and `presort`/`validate` key on produces/consumes, not `task_source`. Add a pure-data, INV-5-safe guard: when a compiled step's `strategy == "fanout_batch"` and its `task_source.source_step` is set, raise `CompilerError` unless `source_step` is the id of an EARLIER compiled step.

Purpose: A composed fan-out relies on producer-before-fanout ordering surviving `presort`; this guard catches a forward/unknown `source_step` deterministically at compile time (SAVE + LAUNCH both compile). Independent of the engine/synthesizer/FE work — safe to land in Wave 1.
Output: One additive guard in `compiler.py` + compiler tests (reject forward/unknown ref; pass `sample_fanout`).
