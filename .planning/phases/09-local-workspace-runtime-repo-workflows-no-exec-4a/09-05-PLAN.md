<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest → MCP tool reference | a manifest can name arbitrary `server.tool` — must be compile-validated against reachable servers |
| run → external MCP server | powerful/write servers can mutate external state — must be gated |
| owner → MCP credentials | per-owner creds must never be readable cross-owner |
| MCP tools → deepagents runtime | tools must AUGMENT the runtime, never replace it (INV-13) |
