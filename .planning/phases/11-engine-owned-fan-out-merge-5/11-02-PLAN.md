<objective>
Implement the two Phase-11 isolation scopes behind the existing `IsolationProvider` port (09-01): `sub_sandbox` (an isolated child dir `{run}/subagents/{step}/{worker_i}/` under the run root, shared-read of parent refs, writes isolated) and `worktree` (a git worktree off the run's working branch, branch-per-worker `fanout/{step}/{worker_i}`, spawn-point commit captured for the 3-way merge-base in 11-03). The engine (INV-7, NOT the manifest) selects the scope: `worktree` when the base workspace `has_git=True`, else `sub_sandbox`. `LocalWorkspace` stays the SINGLE git-subprocess owner — worktree add/remove + branch delete are NEW methods on it, reached by `run_fanout` through the `ctx.runner` handle. Each worker in `run_fanout` now binds to its allocated isolated workspace (replacing the 11-01 shared/per-run placeholder). Teardown wiring lands fully in 11-05 (cancel path); this plan implements the allocate + the happy-path remove.

Purpose: Isolated worker writes (FANOUT-05) — the precondition for deterministic merge (11-03). Engine-decided scope keeps INV-7 (isolation is never manifest-controlled).
Output: grown `IsolationProvider` doc + `LocalWorkspace` worktree/sub_sandbox alloc + the engine scope-selection in `run_fanout` + per-worker workspace binding, with the `test_isolation.py` suite.
</objective>
