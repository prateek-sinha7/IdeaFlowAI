<objective>
Accept the optional per-agent `model_overrides {agent_id → model_id}` map in the websocket `run_pipeline` payload, validate it at ingress against the catalog allow-list AND the run's agent set (rejecting unknown values before execution), thread it into `execute()`, seed `ExecutionContext.model_overrides`, and persist the validated map to `run_capabilities.model_overrides` via the existing `ScopedStore.record_capabilities` (MODEL-03). `{}` persists as NULL for INV-3 row parity.

Purpose: Per-agent overrides are the top tier of the resolver's precedence and the user-facing model-selection surface. This plan is the security chokepoint — the [HIGH] threat (arbitrary/unknown model id) is mitigated here by allow-list ingress validation. No new migration (column exists, 0014).
Output: `websocket.py` (ingress read + validation + error + execute arg), `engine.py` (execute/_execute_impl param + ctx seed + persist arg), new cases in `tests/unit/test_run_pipeline_validation.py` + `tests/unit/test_run_capabilities.py`.
</objective>
