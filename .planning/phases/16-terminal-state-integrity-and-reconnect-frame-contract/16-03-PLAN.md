<objective>
Close ISS-008 + ISS-009 (cluster B, same handler region `websocket.py:763-822`) — make durable-replay/reconnect frames match live-attach frames.

ISS-008: the durable-replay loop (`websocket.py:763-768`, `for _r in _missed:`) hardcodes `"section": None`. `section` is a WS-frame-wrapper field, NEVER persisted (`RunEvent` has no column). WR-03 (commit `d71c55e6`) fixed only the live-attach drainer (`:807/:822`) via `_reattach_section` computed inside `if _has_live_task:`; the replay branch never got it — so a revision run replayed on reconnect emits frames with `section:None` while live-attach emits the real `<target>_output`, diverging in an FE that routes on section.

ISS-009: the live-attach `pipeline_reconnected` ack (`:792-796`) omits the `live` key; only the no-live-task branch (`:783`) sets `live:False`. The FE tolerates via `useWorkflow.ts:455 if (live !== false)`, but the FE comment already (wrongly) assumes the BE sends `live:true` — make the ack symmetric and self-describing.

Fix together (both small): in the replay branch derive `_replay_section` ONCE before the loop from the owner-scoped run row's `type` via the WR-06 inverse — `f"{run_type.removesuffix('_revision')}_output"` when `run_type.endswith("_revision")`, else `None` — and apply it at the replay send (`:767`). The run row is already loaded in this branch (`get_run`); hoist it before the loop. Add `"live": True` to the live-attach ack `data` dict (`:794`).

Per CONTEXT B: round-trip proven faithful for all revision types (`od_ppt_output`↔`od_ppt_revision`, etc.); non-revision keeps `section:None` (byte-identical to live-attach). REJECTED hacks: synthesize a fake/constant section, special-case a workflow name (SC-001), add a `section` DB column (over-engineering + a non-additive-feeling migration for a presentation-only field), or have the FE infer liveness from the `message` text.

Purpose: reconnect/replay frames must not lie about section/liveness.
Output: the two one-liner fixes + a revision-replay section assertion mirroring the WR-03 live-attach contract test.
</objective>
