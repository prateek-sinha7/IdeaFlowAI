<objective>
Close ISS-016 (MAJOR): a runner-surfaced model/tool error is currently swallowed into an empty-but-successful `agent_complete`, so a run whose agents all hard-failed ends `pipeline_complete` with DONE badges instead of `pipeline_failed`.

The runner (`backend/app/agents/deep_agent_runner.py:507-527`) swallows every non-throttle exception (e.g. a `ValidationException` "Operation not allowed") into `yield {"type":"error", "error": str(exc)}` and returns. The `_run_agent` event-consume loop (`engine.py:2326-2377`) branches only on `chunk`/`usage`/`tool_call`/`tool_result` — it has NO `error` arm — so that event is dropped, the stream "ends clean", `output=""`, and a normal `agent_complete` (`engine.py:2619`, `output_length:0`) is emitted. F3 terminal gating (`engine.py:1704-1891`) keys on `agent_error` counts (`_failed_agent_ids`), which this path never produces → clean `pipeline_complete`.

Add an `elif etype == "error":` arm that captures the message, marks the agent failed, emits an `agent_error` (mirroring the existing `timed_out` degrade emission at `:2454-2478`), and SKIPS the result-append + `agent_complete` for that agent. The EXISTING engine terminal machinery then maps `_failed_agent_ids` → `pipeline_failed` (all agents) / `status:degraded` `pipeline_complete` (some agents) — no FE change, no F3 logic change. The runner stays as-is (the 06-05 D-05 LOCKED non-throttle swallow is preserved).

Purpose: make an abnormal run TELL the truth on the live wire (ISS-017 / Plan 04 makes the FE SHOW it).
Output: the engine `error` arm + a fault-injection test + the flipped `test_non_transient_propagates`.
</objective>
