## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| restart scan → durable store | `restore_non_terminal_runs` reads `workflow_runs` + owner-scoped `run_events` at startup; the durable rows are the trust source |
| app endpoint → in-memory store | `POST /{id}/gate` + `POST /{id}/answers` set the HITL events; `_gate_is_pending`/`review_event_pending` read the per-process registry |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-01-01 | Elevation | branch-(a) re-arm reading another owner's durable rows | mitigate | The re-arm reads via `ScopedStore(owner_id=wr.owner_id or wr.user_id ...)` (the `_is_resumable_in_flight` owner derivation, :5107) — default-deny, keyed on the run's own owner; no cross-owner read introduced |
| T-49-01-02 | Tampering | a re-armed row left `waiting_for_user` with no live waiter (hung forever) | mitigate | Arm-then-classify: the store event is armed and the driver spawned BEFORE the status is left `waiting_for_user`; any arm/spawn exception fail-safes to the WR-05 fail (never a phantom-live row) |
| T-49-01-03 | Info disclosure | `review_event_pending`/`_gate_is_pending` leaking gate existence across owners | accept | The accessor reads only the per-process in-memory event registry keyed on `gate_key` (`{run_id}:{agent_id}`); ownership is enforced at the REST layer by the unchanged `_review_gate_owned_by`/`_deny_unknown_gate` (404 never 403) — this refactor moves no ownership check |
| T-49-01-04 | Denial of Service | a compilable-but-not-resumable row spawning a runaway driver | mitigate | No driver spawns unless a durable open gate is derivable AND `_is_resumable_in_flight` (≥1 durable row) is True; the KAN-88 no-gate case spawns nothing (parked, harmless) |
| T-49-01-SC | Tampering | npm/pip/cargo installs | accept | This plan installs NO packages — all changes are to existing backend modules + one new pure stdlib module; no dependency surface added |
