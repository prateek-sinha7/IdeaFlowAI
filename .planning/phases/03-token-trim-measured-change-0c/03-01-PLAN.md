<objective>
Wire the dead `_extract_html_skeleton` helper into the `is_build_task_2_plus` branch of
`_build_context_message`, replacing the full `--- CURRENT HTML (modify this …) ---` block
(up to 120k chars) with a distinctly-marked ~1-3k char skeleton state-map that points the
agent at `read_file('prototype.html')` (D-01). Task 1 and all non-build agents are unchanged.
Then prove the compaction with a deterministic, fully-offline CI gate that asserts the
task-2+ context message is <=50% the size of the old full-HTML version on a representative
multi-page HTML, and asserts the build sub-agent retains `read_file` access.

Purpose: This is the live capability increment for COMPACT-01 (skeleton wired / L13) and the
falsifiable CI half of COMPACT-03 (the >=50% reduction gate). After this plan the compaction
is live for both `prototype` and `od_prototype` (the od alias rides the same `prototype-build`
path) AND it is provably measured in CI — an independently-verifiable vertical slice.

Output: A single-branch engine edit + one new offline test module.
</objective>

still `read_file('prototype.html')` for full detail on demand.
</phase_goal>
