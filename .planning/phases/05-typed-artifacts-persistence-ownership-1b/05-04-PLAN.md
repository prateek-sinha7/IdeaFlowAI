<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WS run start → execute() | `user_id`/`session_id` cross into the engine; an unauthenticated run must still get a real non-None principal. |
| engine emit → durable log | Every event is persisted; a malformed/duplicated seq would break replay ordering / idempotency. |
| revision run → parent artifacts | `_handle_revision` reads parent-run artifacts; cross-owner reads must be denied by the scoped helper. |
| disk principal vs DB principal | Decoupling owner_id from the sandbox key prevents an anon DB-principal change from altering disk paths (CTX-05 / 0A break). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-ANON | Spoofing | `execute()` owner derivation | mitigate | `ctx.owner_id = user_id or f"anon:{session_id}"` (never None — AUTHZ-03); the DB principal is always a real scoped subject. |
| T-5-CTX05 | Tampering (byte-drift) | RunSandbox / create_runner disk keying | mitigate | `ctx.disk_principal = user_id or "anon"` decoupled from `owner_id`; no disk-keying site uses owner_id (Task 1 grep gate); anon disk paths byte-identical → 0A snapshots hold (Highest-Risk Behavior 1). |
| T-5-REPLAY | Tampering | run_events seq/event_id sink | mitigate | One monotonic counter at the single emit boundary; `event_id` is a uuid (idempotent replay); `seq`/`event_id` stripped from the 0A multiset so parity holds; `assert_seq_contiguous` enforces deltas==1 (Highest-Risk Behavior 5). |
| T-5-SEED | Elevation | `_handle_revision` parent-artifact reads | mitigate | Reads route through the scoped helper (owner-scoped); `assert_owns(parent_run_id)` gates cross-owner parent seeding above the graceful-degrade try (D-07). |
| T-5-IDOR | Information Disclosure | websocket clarifications read | mitigate | Rewired to the owner-scoped typed store (no cross-owner read of another session's clarifications). |
| T-5-SC | Tampering | npm/pip/cargo installs | accept | No packages installed this phase (RESEARCH Package Legitimacy Audit — N/A). |
</threat_model>
