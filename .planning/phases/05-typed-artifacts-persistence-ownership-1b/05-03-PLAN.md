<objective>
Relocate Phase 2's pure `assert_owns` predicate UP from `agents/execution_engine/authz.py` to `agents/authz.py` (plan §32) and GROW it into the default-deny store-layer scoped-query helper (D-06/D-07, AUTHZ-02). The helper is constructed with the caller principal `(owner_id, workspace_id)` + a DB session and exposes the one enforced read/write path for artifacts, runs, workspaces, events, and capabilities — every read filtered `WHERE owner_id = :owner AND (workspace_id = :ws OR visibility IN ('workspace','public'))`. `assert_owns` becomes a real-lookup method (looks up the parent run's `owner_id` from the store, raises the typed `PermissionError`). DELETE the old `agents/execution_engine/authz.py` (move-don't-copy, INV-12). Purpose: Establish the single enforced ownership boundary (the helper) before the engine wires reads/writes through it (05-04) and before the endpoints query it (05-05). Default-deny must hold at the store layer.
Output: `agents/authz.py` (relocated + grown helper), deletion of the old module, the extended `test_parent_run_ownership.py` denial suite (AUTHZ-04 + AUTHZ-03).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller principal → store reads | Every artifact/run/workspace/event read crosses the ownership boundary; the scoped helper is the single enforcement point (§19 "not scattered in callers"). |
| revision run → parent run sandbox/artifacts | `assert_owns` gates cross-owner parent seeding (L16); a cross-owner parent must raise, not silently seed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-IDOR | Information Disclosure / Elevation | scoped read methods (`get_ref`/`list_refs`/`get_run`/`read_events`/workspace read) | mitigate | Default-deny filter `owner_id = :owner AND (workspace_id = :ws OR visibility IN ('workspace','public'))` on every read; cross-owner returns nothing → 404 at the API (runs.py:14–17 precedent). AUTHZ-04 tests (Task 2) assert artifact + workspace denial. |
| T-5-SEED | Elevation | relocated `assert_owns(parent_run_id)` real store lookup | mitigate | Looks up the parent run's true `owner_id` from the store and raises `PermissionError` on mismatch (D-07); the L16 E2E denial test stays green (Highest-Risk Behavior 4 — relocated helper must not regress L16). |
| T-5-ANON | Spoofing | anon principal | mitigate | `owner_id` is a real principal `anon:<session_id>`, never None; subject to the same default-deny filter; AUTHZ-03 test asserts a second anon session cannot read the first's rows. |
| T-5-SQLI | Tampering | helper `.filter()` queries | mitigate | SQLAlchemy ORM `.filter()` is parameterized; no string SQL interpolation of `run_id`/`owner_id` (RESEARCH Security Domain V5). |
| T-5-WEBIMPORT | Elevation (import-direction) | `agents/authz.py` imports | mitigate | Helper imports `app.models` only, never `app.api`; `lint-imports` (Task 1 verify) keeps the `engine → authz → app.api` chain from forming (RESEARCH #1). |
| T-5-SC | Tampering | npm/pip/cargo installs | accept | No packages installed this phase (RESEARCH Package Legitimacy Audit — N/A). |
