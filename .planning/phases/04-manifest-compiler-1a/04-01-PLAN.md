Build the capability seam — the hexagonal port boundary (`agents/capabilities/base.py` Protocol ports) and the central name registry (`agents/capabilities/registry.py`) — that the Phase-4 compiler validates every declared reference against (MAN-03 / INV-4). Register the 14 known capability **names** only: no impls (Phase 7), no trust flags (Phase 8). Purpose: INV-4 requires every declared capability reference to be validated against a registry. This plan makes the seam real so 04-02's compiler can reject an unknown reference naming the bad name. Per D-07.

Output: `agents/capabilities/base.py` (ports), `agents/capabilities/registry.py` (`CapabilityRegistry` + 14 names + `resolve_alias`), `tests/agents/test_registry_capabilities.py`.
</objective>
