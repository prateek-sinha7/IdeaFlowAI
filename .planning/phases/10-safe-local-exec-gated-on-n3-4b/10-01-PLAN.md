<objective>
Build the exec FOUNDATION layer: the hardened argv subprocess body, the live constraint policy, and the bypass-proof audit trail. This is the lowest tier of the three-layer enforcement stack — everything downstream (gates, validators, run-path wiring) reaches exec through what this plan builds.

1. 2. The `exec_runs` audit table (additive migration 0018) + `ExecRun` ORM + `ScopedStore.record_exec_run` default-deny writer + `KernelServices.record_exec_run` best-effort handle.
3. The recorder callback wired so EVERY `exec_command` outcome (allowed/denied/killed) is audited at the enforcement point — bypass-proof regardless of caller path.

Purpose: closes EXEC-01's EXEC-PROFILE / EXEC-POLICY / EGRESS-DENY / AUDIT requirements and the IN-02 `shell=True` command-injection surface. No manifest grants exec yet, so this layer is dormant for every existing run (parity preserved).

Output: a hardened, audited, capped `exec_command` that an exec-granted workspace can call; a reversible 0018 migration; a default-deny exec audit trail.
</objective>

| Boundary | Description |
|----------|-------------|
