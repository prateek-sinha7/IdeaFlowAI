<objective>
Build the COMPILE-TIME layer (tier 1 of 3) of the exec enforcement stack: the trust-conditional grant ceiling and the D-01 gates-required check. Today `workflow_ceiling = ToolPermissions()` (compiler.py:312) collapses `exec` to False for EVERY manifest — even a file-trust manifest declaring `tools.exec:true`. This plan makes the ceiling trust-conditional so file/builtin manifests can grant exec, user/db manifests hard-fail, and an exec grant without `gates: [security, approval]` is unauthorable.

It also resolves the INV-12 dual-surface debt: `plan.py:ExecutionPolicy.check` is a documented "FORWARD SURFACE — NOT yet wired" (plan.py:152) that would become a SECOND place deciding "is exec allowed" once 10-01's `LocalExecutionPolicy` enforcement lands. Per CONTEXT Claude's-discretion + RESEARCH Pitfall 5/A3, this plan DELETES it (the live surface is `LocalExecutionPolicy.allows` + the pre-spawn allow/deny check 10-01 built) and records the deletion in the migration-ledger.

Purpose: closes EXEC-01's GRANT-PATH requirement; resolves the INV-12 forward-surface debt. Dormant for parity — no existing manifest grants exec, so the trust-conditional branch never fires for any existing run and the 5 characterization snapshots stay byte/event-identical.

Output: a trust-conditional compiler ceiling, a D-01 gates-required CompilerError, deleted dual policy surface, and a migration-ledger row.
</objective>
