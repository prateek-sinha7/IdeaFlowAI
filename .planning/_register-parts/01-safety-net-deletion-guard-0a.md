### 7. Gotchas, Survivors & Carry-Forward
- **Live survivor — INV-1 reservation in `engine.py`:** `if pipeline_type ==` / `spec.id ==` (10 matches) is LIVE and warn-only here; it is NOT a leak to remove in 0A. It dies with L7 in Phase 7. → 01-04-SUMMARY.md (key-decisions).
- **Order-canonical multiset deviation (accepted):** the event snapshot is sorted by canonical JSON (`_canonical_order`), NOT strict positional order, because the prototype/app build loop interleaves `tool_result`/`task_progress`/retry `tool_call` nondeterministically across runs of the UNCHANGED engine — a raw positional snapshot was flaky. Strict emission order stays covered by `assert_seq_contiguous` + the existing positional sequence tests in `test_phase3_cutover_verify.py`. A future agent must keep the multiset framing, not "fix" it back to positional. → 01-02-SUMMARY.md (Deviations) / 01-VERIFICATION.md (Gaps Summary, Accepted deviation).
- **`assert_seq_contiguous` is vacuous today** — the engine stamps no `seq`; the function is wired in all 5 modules and proven to raise on a synthetic gap, so it activates automatically if a `seq` is ever added. INFO-severity, not debt. → 01-VERIFICATION.md (Anti-Patterns Found).
- **od_ alias gotcha:** `od_prototype` and `ppt` have NO AGENT.md of their own (aliases of `prototype` / `od_ppt`); `get_pipeline_agents` returns ∅ for them. The harness resolves the alias for agent LOOKUP only and forwards the original label to `execute()` — mirror this if extending characterization, do not give aliases their own agents. → 01-01-SUMMARY.md (Auto-fixed Issues #1).
- **Pre-existing non-fatal `sqlite3.IntegrityError (FOREIGN KEY) … INSERT INTO workflows`** logs during `_drive` (offline harness lacks the parent users row). It does NOT interrupt the run or affect snapshots — expected noise, not a bug to chase. → 01-01-SUMMARY.md (Notes) / 01-02-SUMMARY.md (Notes).
- **CHECK-row classification is by explicit `CHECK:`/`test:` marker, NOT a metacharacter heuristic** — a single-token grep pattern (e.g. `SKIP_PLANNER_FOR_PROTOTYPE`) was being misclassified as prose and silently dropped. When adding ledger rows, mark prose gates explicitly or the ratchet may skip them. → 01-03-SUMMARY.md (Deviations).
- **Deferred to later phases (not 0A scope):** tightening the import-linter contract to its final kernel form (Phase 7/8); flipping ledger rows to ☑ + enabling their grep enforcement (each owning phase); INV-1 hard-fail (Phase 7); pre-commit mirrors of the CI gates (opportunistic). → 01-CONTEXT.md (Deferred Ideas).
