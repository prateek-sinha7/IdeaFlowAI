### 1. Goal & Success Criteria (what was PLANNED)

A granted step fans out N workers (self-copies or named from `allowed_workers`) into engine-selected isolated workspaces, parallel (capped) or sequential, under engine-enforced budgets; both the declarative `step.fanout` and the runtime `spawn_subagents` tool funnel through ONE kernel `run_fanout`; results merge deterministically via a registered `MergeStrategy`; conflicts are first-class (`merge_conflict` artifact + event + 4 `on_conflict` policies); every child gets an owner-scoped `subagent_runs` row; cancellation propagates to children with isolated-workspace teardown. The engine alone decides isolation/caps/merge (INV-7). → 11-SPEC.md (Goal), 11-CONTEXT.md (Phase Boundary).

"What must be TRUE" — the 13 acceptance criteria → 11-SPEC.md (Acceptance Criteria): single spawn path reached by both entry points; `spawn_subagents` permission-bound (`user_allowed=False`) + spawn-free; self×N / named worker selection with pre-spawn rejection (zero rows); parallel ≤ cap 4 / sequential ordered; isolated writes no cross-contamination; 4 merge strategies registered, `copy_disjoint` deterministic + overlap→conflict; 4 `on_conflict` policies per spec (human_gate via the ONE durable HITL, merge_agent ≤ 2, partial, abort); reserve-before-spawn with module-constant defaults 8/4/2/900s; per-workspace ceiling + `budget_snapshot_json` persistence; 0019 reversible + cross-owner read = ∅; cancel teardown zero residue; 5 characterization snapshots byte/event-identical; SC-001 (a fanning workflow needs zero engine edits). **Depends on:** Phase 10 (exec_runs 0018 recipe + ScopedStore None-degrade), Phase 09 (IsolationProvider port + LocalWorkspace single git-subprocess owner), Phase 08 (`@register`/`discover()` + tool_provider/perms-intersection + ONE durable `run_human_gate`), Phase 07 (KernelServices `ctx.runner` handle + `task_loop` TaskSource precedent + SC-001 proof pattern), Phase 05 (ArtifactGraph + `ScopedStore.write_ref` + allowed `merge_conflict` kind). → 11-CONTEXT.md (Canonical References), 11-01-SUMMARY.md (Dependency graph).

### 5. Key Decisions & Locked Constraints (do NOT contradict)

- **D-01 worker shape:** one child = ONE isolated `KernelServices.run_agent` invocation (NOT a nested mini-run); per-worker `thread_id = {run_id}:{step}:{worker_i}` (+ `:d{depth}` segment for nested fan-out). Workers carry NO gates, NO per-worker fix-loop. Children are `subagent_runs` rows, NEVER `workflow_runs` rows. → 11-CONTEXT.md (D-01).
- **D-02 declarative entry = `fanout_batch` ExecutionStrategy** (the Q8/base.py reserved name); runtime entry = `spawn_subagents` tool whose request the engine derives via the `report_task_complete` post-loop tool-event-derivation pattern (`_derive_fanout`) — keeps INV-13, tool body spawn-free. → 11-CONTEXT.md (D-02), 11-RESEARCH.md (Pattern 3).
- **D-03 child events lifecycle-only:** parent stream carries `subagent_*`/`merge_*`/`budget_warning` ONLY; worker chunk/tool events NOT forwarded (workers run silent). `subagent_chunk` tagged streaming is deferred. → 11-CONTEXT.md (D-03).
- **INV-7 (engine decides, never the manifest):** isolation scope derived SOLELY from `base_workspace.has_git` (worktree if True else sub_sandbox); merge strategy engine-selected keyed on the scope (worktree→git_3way, sub_sandbox→copy_disjoint). A user manifest can NEVER downgrade isolation or name the merge strategy on the isolated path. → 11-02/11-03-SUMMARY.md (Decisions).
- **Budget defaults are LOCKED module constants** (not suggestions): max_subagents=8, max_concurrency=4, max_depth=2, wall_clock=900s, merge_agent_attempts=2, warn@80%. `reserve()` gates countable units (subagents/concurrency/depth) before spawn; tokens/wall-clock are check-at-boundary (D-05 dual shape — cannot pre-reserve unknown token spend). depth enforces `depth+1 > max_depth`. `arm()` idempotent (first deadline wins). → 11-04-SUMMARY.md (Decisions Made), 11-SPEC.md (Constraints).
- **Trust-conditional `Limits` (and `spawn_subagents`):** file/builtin manifests may RAISE a Limits cap; user/db manifests may only LOWER (raising any → `CompilerError`). `max_tokens` excluded from the raise-rejection set (no module ceiling — declaring it only self-constrains). `spawn_subagents` rides the SAME trust ceiling as `exec` (file may grant, user/db collapses OFF + CAP-03 rejects). Compiler defines its OWN `_LIMITS_DEFAULT_CEILING` constants (mirror of budget.py) because import-linter forbids `agents.workflows → agents.execution_engine`. → 11-04/11-05-SUMMARY.md (Decisions).
- **ONE durable HITL preserved (D-02, Phase-10):** merge `human_gate` delegates to `run_human_gate` → `_run_review_gate`; NO sibling `run_merge_gate`. Conflict-as-first-class: an overlapping target is EVICTED from the applied set (never silently overwritten). merge_agent bounded at 2 then human_gate fallback (no oscillation). → 11-03-SUMMARY.md, 11-SECURITY.md (T-11-03-04).
- **`write_fragment_artifact` is the SINGLE producer of typed fragment refs (INV-12)** — 11-04 (BudgetExceeded abort) and 11-05 (cancel) CONSUME it, they do NOT re-introduce it. Both fragment + merge_conflict writes delegate to the engine's single `_dual_write_artifact` path. → 11-03-PLAN.md (dependency_note).
