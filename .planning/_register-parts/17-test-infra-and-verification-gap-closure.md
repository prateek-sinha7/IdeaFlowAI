### 5. Key Decisions & Locked Constraints (do NOT contradict)

1. **TEST-ONLY / zero production code.** The defect in all three is in the harness; the fix lives there. No `backend/app/**`, no non-test `backend/agents/**`, no migrations, no new deps (`17-CONTEXT.md <decisions> INVARIANTS`). 2. **ISS-003 — clarify-off via the shared wrap, NOT a production change.** REJECTED (do NOT do): re-add the `ALWAYS_CLARIFY` engine flag (dual-impl, INV-12); add a clarify timeout in `clarify_engine.py` (perturbs production HITL — the gate is deliberately no-timeout); flip the `prototype` manifest `clarify.mode` (breaks INV-3 + `test_manifest_parity.py`). Suppressing clarify removes a HANG, not the A/B token-delta measurement (clarify emits no `input_tokens`).
3. **ISS-010 — closed by an in-memory exporter test, NOT a live collector.** The #1 LANDMINE: the hook caches a module-private `_TRACER` and never calls `set_tracer_provider()`, so a global-provider test would silently MISS its spans (false green). Inject via the hook's OWN `_build_span_processor` factory + reset `_TRACER=None`; use `SimpleSpanProcessor` (synchronous, no `force_flush`). REJECTED: stand up a live OTLP collector / `pip install opentelemetry-exporter-otlp` to go green (env-dependent, adds a deliberately-optional dep); a global `set_tracer_provider` test. Live OTLP export remains an OPTIONAL end-of-milestone smoke, not a blocker.
4. **ISS-011 — SKIP-not-FAIL on credential expiry; transient classification UNTOUCHED.** The re-check resolves `live_skip_reason()` via the `live_harness` MODULE (so the offline simulation can monkeypatch it). REJECTED (DANGEROUS): adding "expired"/"security token" to `_TRANSIENT_SUBSTRINGS` / `model_policy.py` so the runner "retries" — an expired SSO token can't be refreshed by a botocore retry, and it would mask real `AccessDenied`/`ValidationException` faults and perturb production error semantics (INV-3-relevant). Also REJECTED: "just re-run" with no harness change (leaves the recurring fault). **The transient-error classification stays as-is — do not widen it.**
