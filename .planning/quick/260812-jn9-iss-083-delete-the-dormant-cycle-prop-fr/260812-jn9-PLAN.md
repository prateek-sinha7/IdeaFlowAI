<objective>
Delete the dormant `cycle` prop from `frontend/src/components/chat/ResultCard.tsx` (ISS-083).

**Purpose:** `ResultCard` holds a second, contradicting copy of the spec-revision cycle number.
The header renders `` `Revising spec — cycle ${cycle ?? 1}` `` (`:117-120`) while the body
renders the backend narrator's own text (`backend/app/agents/chat_narrator.py:157`,
`f"Revising spec — cycle {attempt}"`). Nothing in production ever passes `cycle` — the sole
mount, `MessageBubble.tsx:214`, passes only `message` + `onRequestOpenTab` — so if the card
ever mounted, the header would print "cycle 1" directly above a body saying "cycle 2". That is
a textbook INV-12 dual implementation over one datum. This deletes the superseded copy.

**Output:** One datum, one producer, one renderer. `CARD_SPECS.spec_revision.title`
("Revising spec", already at `:83`) becomes the header; the cycle number lives only in the
narrator text, in the body.
</objective>
