# Phase 260703-174 Plan 01: Apply Workstream-C UI-Review Findings Summary

Wired the two dead revision-lineage affordances (the "revision of v{n}" chip and the live
"Original brief (v1)" expander) into both AgentThinkingTab mounts and aligned the Clarifications
timeline dot to its sibling-dot convention — closing the 3 FLAGs from WORKSTREAM-C-UI-REVIEW.md
with a WIRING + one-className change, zero backend, zero new visual language.

## What was built

- **FIX 1+2 — PreviewPanel (LIVE mount).** After the existing `activeParentRunId` derivation,
  added `activeParentIdx`/`revisionParentVersion` (1-based family index of the active run's
  parent via `parent_run_id` lookup) and `originalBriefRootRunId` (`runFamily?.root_id` only when
  the active member has a non-null parent). Threaded both to the `<AgentThinkingTab>` mount.
  Closes C-FLAG-1 (dead chip in production) and C-FLAG-2 (live Original-brief asymmetry).
- **FIX 1 — WorkflowHistory (REOPEN mount).** Inside the `if (selectedRun)` render block, derived
  `revisionParentVersion` from the fetched `family` state (sorted by `revision_index`) +
  `selectedRun.parentRunId`, and threaded it to the reopen `<AgentThinkingTab>`. The
  `originalBriefRootRunId` prop was already threaded — left untouched. Closes C-FLAG-1 (reopen).
- **FIX 3 — ClarificationsCard (cosmetic).** Timeline DOT only: `bg-[#E8EDF5]` → `bg-[#1B2A4A]`
  and glyph `text-[#1B2A4A]` → `text-white`, matching the Starting-point first dot and Planner
  done dot. The header ICON CHIP (the remaining `bg-[#E8EDF5]`) is intentionally unchanged. No new
  hex introduced. Closes C-FLAG-3.
- **Tests.** Extended `WorkflowHistory.runInput.test.tsx` with a revision-reopen case (real DOM:
  open run → Thinking tab → assert "revision of v1" chip + Original-brief expander). Added
  `PreviewPanel.revisionChip.test.tsx` — the only PreviewPanel spec that renders the REAL
  AgentThinkingTab (versionChip stubs it), so the live-mount computation is observable: a revision
  family (liveRunId=r2 → parent r1) renders "revision of v2" + the expander; a root run
  (liveRunId=root, parent null) renders NO chip.
