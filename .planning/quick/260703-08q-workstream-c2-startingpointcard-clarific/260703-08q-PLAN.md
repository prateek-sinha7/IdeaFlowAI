- `parseClarificationArtifacts(nodes: { content?: string }[]): ClarifyRound[]` — JSON.parse each node's content (list of `{question_id, question_text, impact_level, answer, round}`), flatten, group by `round`, sort ascending. Returns `[]` on empty/malformed (never throws).
