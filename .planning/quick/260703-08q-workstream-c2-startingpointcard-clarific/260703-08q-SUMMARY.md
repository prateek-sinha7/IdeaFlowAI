# Phase 260703-08q Plan 01: Workstream C2 — StartingPointCard + ClarificationsCard + Run-input Files rows Summary

The VISUAL SURFACE of Workstream C — two props-driven Thinking-tab cards (StartingPointCard before PlannerCard, ClarificationsCard after) plus a Files "Run input" section (prompt.md always, clarifications.md when rounds exist) — wired on BOTH the live (PreviewPanel) and reopen (WorkflowHistory) mounts, completing the timeline narrative Starting point → Planner → Clarifications → Agents. FRONTEND-ONLY, zero backend (INV-3 by construction), zero net-new visual language, and no second parser (consumes C1's parseRunInput). This is the final build unit of the Revision-Families & Run-Inputs effort.

## What shipped

- **clarifications.ts lib** — `parseClarificationArtifacts` (artifact nodes → grouped/sorted `ClarifyRound[]`, ordered by the content `round` field, never throws) + `renderClarificationsMarkdown` (rounds → plain markdown for the clarifications.md download). Pure, GREEN vitest lib spec (TDD RED→GREEN).
- **StartingPointCard (D3)** — clones the PlannerCard collapsible shell + a first solid navy timeline dot; consumes C1 `parseRunInput`; variant by parsed shape (NORMAL brief + expandable attachment chips / REVISION instruction-primary + "revision of v{n-1}" chip + lazy "Original brief (v1)" expander via the B3 dynamic-import idiom / CHAINED "From previous workflow" chip). No `workflowType` string, no marker regex (SC-001/INV-12). Renders from props alone on reopen.
- **ClarificationsCard (D4)** — clones the PlannerCard shell + QuestionnairePanel Q/A summary card (question semibold + emerald "✓ answer") + amber (high) / gray (medium) impact badges; renders NOTHING for a PROCEED run; reopen loading is `aria-busy` + Loader2.
- **Files "Run input" section (D7)** — first content section in both layouts; prompt.md (parsed brief) + clarifications.md (rendered Q&A, only when rounds exist), both plain `renderFileRow` rows falling into the default `downloadBlob` path; counted in totalCount + "Download All"; type-agnostic.
- **Both-mount wiring + live seam** — AgentThinkingTab places both cards + a `hasAnyData` guard extension; PreviewPanel threads `runInput` + `clarifications (?? pipelineState?.clarifications)` to both tabs; DashboardLayout `submittedBrief` → PreviewPanel.runInput; page.tsx threads the captured `submittedBrief` (makes C1's captured-only brief live); WorkflowHistory adds the reopen `getRunArtifacts(kind="clarifications")` fetch effect and threads `selectedRun.input`/`rootRunId`/rounds to both tabs.
