Find each object literal `{ ... }` inside; from each object extract the `pattern:` and `page:` values where each value is a single- or double-quoted string (regex over `pattern\s*:\s*(['"])(...)\1` and likewise `page`).   3. If it is `{` -> OBJECT form. Brace-match from that `{` to its closing `}` (reuse the round-2 brace-match approach in _extract_routes_map). Strip comments as above.   3. No match -> return None (the route would hit the app's fallback — genuinely unreachable via the table).
