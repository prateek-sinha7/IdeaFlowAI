fallback. Add a tolerant extract-and-repair parser + a stricter prompt so the single round is
genuinely content-aware, keeping the static library as the LAST resort (never crash the gate).

Purpose: make the single clarify round actually useful — one smart, content-aware questionnaire,
then run — instead of a 3x re-ask of static questions.
