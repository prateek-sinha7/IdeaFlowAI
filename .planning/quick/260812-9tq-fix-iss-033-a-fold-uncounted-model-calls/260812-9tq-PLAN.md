## The three changes

### 1. `app/agents/handoff/test_agent.py` — the 43-04 miss

Phase 43-04 routed "handoff Test(classifier)" — but `classifier.py` is the
coding-vs-test router, **not** the Test agent. `TestAgent.analyse` still calls
`llm.ainvoke` raw: **uncached and uncounted**. `compliance_agent.py:121-164` is the
finished template (ctor `usage_sink` + `cached_invoke(system=…, model=llm,
usage_sink=…)`); this is that template applied to the module 43-04 meant to fix.

Replace-don't-shadow (INV-12): the local `_extract_text` and the
`SystemMessage`/`HumanMessage` imports are **superseded by `cached_invoke` and get
deleted** — exactly as `compliance_agent.py` deleted its own when it was routed.

**Honest scope note:** the handoff pipeline has no cost surface at all
(`handoff_pipeline.py:494` constructs `TestAgent()` with no sink, as it does
`ComplianceAgent()`), so what lands today is *caching* + a *countable seam*, at
parity with Compliance. Wiring a handoff cost surface is part B / ISS-092.

### 2. `engine.py` fix-loop — stop discarding `usage`

`_run_validation_fix_loop` drains the fix sub-agent's stream with a bare `continue`,
throwing away every `usage` event (≈929k input tokens ≈ 6.9% of input on the real
run `fa66227a`). Seam, per the investigation:

* `KernelServices.__init__(..., aux_usage_sink=None)` → `self._aux_usage_sink`
* `KernelServices.run_validation_fix_loop` threads it into the engine loop
* `_run_validation_fix_loop(..., aux_usage_sink=None)` routes `usage` events to it
* `engine.py:2095` constructs `KernelServices(..., aux_usage_sink=aux_token_usage.append)`

`aux_token_usage` is the accumulator 43-04 already folds into the run totals at
`engine.py:2793-2796`, and the runner's `usage` event already carries exactly the
four keys it consumes (`deep_agent_runner.py:509-515`) — no new type, no new
accumulator, no second fold.

**It must NOT append to `results`** — `agents_completed = len(results)`
(`engine.py:2820`) would count fix attempts as agents. Pinned by a test.

**Ordering constraint:** the usage capture goes *before* the `cancel_event` return.
A token the model already reported was already spent; a cancel must not erase it.

Invariants: keyed on `event["type"] == "usage"` and the KernelServices handle, never
on a workflow/agent name (**SC-001**, **INV-1**); the discard is *deleted*, not
paralleled (**INV-12**); no `create_deep_agent` outside the adapter (**INV-13**);
the sink is a constructor param, not engine-singleton state (**INV-2**).

### 3. `tests/agents/test_model_pricing.py:195` — the dead INV-12 guard

`_WEBSOCKET = _BACKEND/"app"/"api"/"websocket.py"` points at a file the SSE cutover
deleted, so the guard has raised `FileNotFoundError` instead of checking **since
Phase 44**. The INV-12 "both cost sites share one implementation" contract has been
unenforced for the persistence site ever since. Repoint to the real persistence cost
site (`app/api/run_commands.py:2107`) and make the failure mode loud: assert the path
exists, naming the contract, so the next file move fails as an assertion instead of
dying silently. Strengthen both guards from `"estimate_cost_usd" in src` (a comment
satisfies that) to the real **import** of the shared module.
