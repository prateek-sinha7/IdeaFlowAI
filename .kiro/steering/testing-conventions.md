## Suite semantics

| Suite | Speed | Real infra | Purpose | Share |
|---|---|---|---|---|
| `unit/` | ms | never | one function/class; branches, validation, error paths | ~70% |
| `integration/` | 100 ms–s | Postgres, vector store; LLM/3rd-party HTTP faked | SQL, ORM, migrations, router+DB | ~20% |
| `contract/` | ms | no | OpenAPI stability, consumer contracts | few |
| `e2e/` | s+ | full stack | user journeys over HTTP | ~5% |
| `performance/` | long | yes | latency/throughput budgets | opt-in |
| `security/` | varies | usually TestClient | auth bypass, injection, rate limits | small, high value |
| `property/` | ms–s | no | invariants over generated inputs | small |
| `smoke/` | ms | deployed env | health, DB ping, one auth call | 5–10 |

`tests/fixtures/` = data files. Pytest fixtures (functions) = `conftest.py`. Never mix the meanings.

## conftest hierarchy — place a fixture at the HIGHEST level where it is valid, no higher

| Location | Fixtures |
|---|---|
| `tests/conftest.py` | marker hook, `settings` (monkeypatch), seeded `faker`, `frozen_time`, sample DTOs — zero I/O, no import of `<pkg>.main` at module level |
| `tests/unit/conftest.py` | `mock_session` (`MagicMock(spec=Session)`), `mock_async_session` (`AsyncMock(spec=AsyncSession)`), `mock_<x>_repo` (spec'd), `fake_chat_model` (`FakeListChatModel`), `fake_embeddings` (`DeterministicFakeEmbedding`), `mock_httpx_client` / `respx_mock` |
| `tests/unit/api/**/routers/conftest.py` | `client` (TestClient + `app.dependency_overrides`, cleared in teardown), `as_admin` / `as_user` / `as_anonymous` |
| `tests/integration/conftest.py` | `postgres_container` (session), `engine` (session), `db_session` (function; outer transaction rolled back), `alembic_upgrade` (session) |
| `tests/e2e/conftest.py` | `base_url` from env, `auth_headers`, compose lifecycle |

Fixture rules:
- Scope `function` by default; `session`/`module` only for expensive immutable resources.
  Any shared-scope fixture yielding mutable state resets it per test.
- Every mock fixture uses `spec=` / `autospec=True`. Every awaited dependency uses `AsyncMock`.
- One-line docstring per fixture: what it provides, what it isolates.
- Never duplicate an existing fixture — extend or relocate it and say so.
- Fixture names are nouns for what they provide (`db_session`), not how.

## Naming

| Item | Convention | Example |
|---|---|---|
| Unit test file | `test_<module>.py`, mirrors source path | `<pkg>/services/order_service.py` → `tests/unit/services/test_order_service.py` |
| Integration variant | suffix `_db` / `_api` / `_external` | `test_order_repository_db.py` |
| Test class | `Test<FunctionOrClass>` | `class TestCreateOrder:` |
| Test function | `test_<function>_<outcome>_when_<condition>` | `test_create_order_raises_not_found_when_user_missing` |
| Factory | `<Model>Factory` | `OrderFactory` |
| Fake | `Fake<Thing>` | `FakeOrderRepository` |
| Marker | lowercase = folder name | `@pytest.mark.integration` |

## Target pytest / coverage configuration (merge into existing config; ONE config file only)

```toml
[tool.pytest.ini_options]
testpaths = ["tests"]
python_files = ["test_*.py"]
python_classes = ["Test*"]
python_functions = ["test_*"]
asyncio_mode = "auto"
addopts = "-ra --strict-markers --strict-config"
# pythonpath = ["src"]            # src layout only
markers = [
    "unit: fast, fully isolated tests (default)",
    "integration: requires Postgres / containers",
    "contract: API schema and consumer contracts",
    "e2e: full stack via docker-compose",
    "performance: load and benchmark tests, opt-in",
    "security: auth, injection, hardening",
    "property: hypothesis-based property tests",
    "smoke: post-deploy health checks",
    "slow: takes more than 1 second",

filterwarnings = ["error::DeprecationWarning"]

[tool.coverage.run]
source = ["<pkg>"]
branch = true
omit = [
    "<pkg>/db/migrations/*",   # generated by alembic
    "<pkg>/main.py",           # app factory wiring; covered by e2e
    "*/__init__.py",
]

[tool.coverage.report]
fail_under = 80
show_missing = true
skip_covered = false
exclude_lines = [
    "pragma: no cover",
    "if TYPE_CHECKING:",
    "if __name__ == .__main__.:",
    "raise NotImplementedError",
]
```

## Folder → marker hook (root `tests/conftest.py`)

```python
import pytest

SUITE_MARKERS = {
    "unit", "integration", "contract", "e2e",
    "performance", "security", "property", "smoke",
}

def pytest_collection_modifyitems(config, items):
    for item in items:
        path = getattr(item, "path", None) or item.fspath  # pytest >= 7 uses .path
        parts = set(str(path).replace("\\", "/").split("/"))
        suites = SUITE_MARKERS & parts
        assert len(suites) == 1, f"{path} must live under exactly one suite folder, found {suites}"
        item.add_marker(getattr(pytest.mark, suites.pop()))
```

## Commands

```bash
pytest tests/unit -m unit --cov=<pkg> --cov-branch --cov-report=term-missing   # local / pre-commit
pytest tests/integration -m integration                                        # needs Docker
pytest -m "not e2e and not performance"                                        # PR pipeline
pytest tests/unit/services/test_order_service.py -v                            # single module
BASE_URL=[https://staging.example.com%20pytest%20tests/smoke%20-m%20smoke%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20#%20post-deploy](https://staging.example.com%20pytest%20tests/smoke%20-m%20smoke%20%20%20%20%20%20%20%20%20%20%20%20%20%20%20#%20post-deploy)
mutmut run --paths-to-mutate <pkg>/services/order_service.py --tests-dir tests/unit/services
```

CI stage order: unit (always, coverage gate) → integration (Docker runner) → contract →
e2e (main / nightly) → performance (nightly, opt-in). Smoke runs post-deploy, not in CI test stage.

## Anti-patterns — detect, report, never introduce

- Unit and integration tests in the same folder.
- Missing `__init__.py` → module name collisions (`unit/schemas/test_user.py` vs `integration/db/test_user.py`).
- Root `conftest.py` importing DB / LLM clients at module level.
- SQLite as a "unit" database.
- Inline sample payloads repeated across tests (belong in `fixtures/` + `factories/`).
- e2e / performance in the default `pytest` run.
- Mocks without `spec=`.
- `session`-scoped fixtures yielding mutable state without per-test reset.
- More than one pytest config file (only the first found is honoured).
- Assertions on `datetime.now()`, `uuid4()`, `random` without freezing / patching.
- `pytest.raises(Exception)` — always the exact exception type.
