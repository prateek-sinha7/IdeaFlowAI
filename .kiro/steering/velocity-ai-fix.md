# Legacy command redirect: `/velocity-ai-fix`

`/velocity-ai-fix` is retired. Use `/velocity fix <symptom>` instead.

The canonical `fix` workflow runs the full root-cause analysis first, identifies the relevant module and card constraints, computes blast radius, asks for approval before changing code, and records the resulting evidence through Velocity book-keeping.

For direct knowledge navigation, run `/velocity prime`, start at `.knowledge/CONTEXT.md` and `.knowledge/INDEX.md`, and follow only the required module/card links. The former cache-query interface and `.knowledge/surface/` artifacts are retired.
