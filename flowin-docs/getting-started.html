Getting Started

Get Flowin running on your machine from a clean checkout, then explore how it works through five zoomable, interactive architecture diagrams.

✓Prerequisites

Python 3.12+, Node.js 20+, and git. That's it.

1Set up

From the repo root — installs dependencies, creates your backend/.env & frontend/.env.local, runs migrations, and seeds login users:

./scripts/local-dev/install-prereqs.sh    # skip if you already have Python/Node/git
./scripts/local-dev/setup-backend.sh      # deps, backend/.env, migrations, seed users
./scripts/local-dev/setup-frontend.sh     # deps, frontend/.env.local

2Enable the LLM (backend/.env)

Setup pre-filled backend/.env, so almost everything just works. Before running, give it an LLM.

Quickest start: paste an Anthropic key into ANTHROPIC_API_KEY and you're done. Prefer AWS Bedrock? Fill the Bedrock rows instead.
ENV=development
SECRET_KEY=…auto-generated…
DATABASE_URL=sqlite:///./dev.db
CORS_ORIGINS=["http://localhost:3000"]
RUNS_ROOT=./runs

# Anthropic — easiest: paste a key here
ANTHROPIC_API_KEY=

# ...or use AWS Bedrock instead
AWS_REGION=eu-central-1
BEDROCK_MODEL_ID=anthropic.claude-haiku-4-5-20251001-v1:0
BEDROCK_INFERENCE_PROFILE_ID=eu.anthropic.claude-haiku-4-5-20251001-v1:0
AWS_BEARER_TOKEN_BEDROCK=
VariableSetupHow to get it
ENVautoKeep development.
SECRET_KEYautoGenerated for you.
DATABASE_URLautoLocal SQLite — nothing to do.
CORS_ORIGINSautoMatches the local frontend.
RUNS_ROOTautoLocal run folder.
ANTHROPIC_API_KEYset thisGet a key at console.anthropic.com. Easiest way to enable the LLM.
AWS_REGIONBedrockRegion where Bedrock is enabled.
BEDROCK_MODEL_IDBedrockFrom Bedrock → Model access.
BEDROCK_INFERENCE_PROFILE_IDBedrockFrom Bedrock → Inference profiles.
AWS_BEARER_TOKEN_BEDROCKBedrockBedrock API token — or leave empty to use your AWS credentials.

Bedrock also needs AWS credentials (aws configure or AWS_PROFILE) unless you set AWS_BEARER_TOKEN_BEDROCK.

No LLM set? You can still log in, but pipeline runs will fail. Set one of the two above.

The frontend's frontend/.env.local is written for you too — it just points at the backend, no account needed:

VariableSetupValue
NEXT_PUBLIC_API_URLautohttp://localhost:8000
NEXT_PUBLIC_WS_URLautows://localhost:8000/ws/chat

3Run

Start both dev servers (each in its own terminal):

./scripts/local-dev/run-backend.sh    # http://localhost:8000
./scripts/local-dev/run-frontend.sh   # http://localhost:3000

Shortcut: ./scripts/local-dev/install-and-run-all.sh does set up + run in one command. Handy once your LLM key is in backend/.env.

4Open & log in

Open http://localhost:3000. Sign-up is disabled — log in with one of the seeded accounts below. Their shared password is set by seed_test_users.py during setup.

EmailTier
qa-admin@flowinqa.comenterprise (admin)
qa-enterprise@flowinqa.comenterprise
qa-pro@flowinqa.compro
qa-basic@flowinqa.combasic

↳Good to know

  • backend/.env is the backend's env file — not a repo-root .env.
  • backend/dev.db is your local SQLite database.
  • Stuck at login? Use the seeded QA accounts above — sign-up is disabled.
