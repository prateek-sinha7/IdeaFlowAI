Frontend App

A Next.js 16 (App Router) single-page dashboard on React 19 + TypeScript 5 + Tailwind 4. It is a thin, event-driven view over the backend: it opens a WebSocket, sends run_pipeline, and reduces a stream of events into render state. Deliverables are dispatched by MIME type.

Next 16.2.4React 19.2.4Tailwind 4 motion · lucide-react · pptxgenjsVitest + Playwright
In plain terms. The frontend is a thin live window, not a brain. It sends one request to start a run, then simply renders whatever events stream back — agents thinking, tools firing, tasks completing — and finally shows the deliverable. Because runs can last hours, the window is built to survive dropped connections and pick up exactly where it left off.
What it is

A Next.js 16 / React 19 dashboard driven entirely by a WebSocket event stream.

Why it exists

Runs are long and streaming, so the UI must show live progress and reconnect gracefully rather than block on a request.

How it works

Two hooks — a socket (useWebSocket) and a state machine (useWorkflow) — reduce events into render state; deliverables render by MIME type.

The two hooks that run everything

useWebSocket.ts

Owns the socket lifecycle. Connects with subprotocols [bearer.<jwt>, flowin.v1] (JWT off the URL); server echoes flowin.v1. Exponential-backoff reconnect capped at 30s with no retry limit; 20s client ping; a 4001 close clears the token & redirects to login; filters heartbeats/pongs.

useWorkflow.ts

The central pipeline state machine. startPipeline() builds the run_pipeline payload (merging model_overrides, gate_agent_ids, template_id). handlePipelineMessage() is a big switch reducing every WS event into PipelineRunState. submitQuestionnaire() resumes a paused run.

Other hooks: useNotifications, useSpeechRecognition, useTextToSpeech. Context: SkillsHooksContext.

Deliverable rendering — dispatch on MIME type

Because a custom workflow can emit anything, PreviewPanel renders by the declared deliverable_mimetype, not by workflow name (SC-001 at the UI layer). On reopen it falls back to resolveReopenMimetype() heuristics.
