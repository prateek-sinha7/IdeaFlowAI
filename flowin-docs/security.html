Platform

Security Notes

The platform has strong security defaults in several places and a couple of items worth flagging. This reflects what is verifiable in the current code — it is a set of observations from reading the source, not a full audit.

The auth request path

Strong by default

✓

SECRET_KEY boot guard

config.py raises SecretKeyMisconfigured and refuses to boot if SECRET_KEY is empty, the shipped default, or <32 chars — unless ENV=development.

✓

JWT off the URL

The WebSocket carries the JWT in the bearer.<jwt> subprotocol, not the query string — out of nginx logs and Referer headers. Tokens are revocable (logout jti + password-change blanket revocation), re-checked per message.

✓

Least-privilege capabilities

Tool permissions default off (exec/network/secrets/spawn_subagents). exec requires the security+approval gates. User/db manifests can't reference non-user-allowed capabilities or raise budget ceilings.

✓

Safe by construction

Manifests parse with yaml.safe_load only (no RCE); capability resolution is a static dict lookup (no eval/dynamic import); client-facing agent_error is sanitized so provider ARNs/region/model-id never reach the browser.

✓

Ownership everywhere

Runs, artifacts, saved workflows, and review-gate responses are owner-scoped (ScopedStore + per-row owner_id/workspace_id); cross-run writes are IDOR-guarded (unknown/unowned → 404).

✓

Secrets never in code/CI

Terraform generates SECRET_KEY/db_password into SSM SecureStrings (project CMK). CI scans with gitleaks/checkov/trivy before merge. Default audit_logger + secret_scan hooks fire on every step.

Worth flagging

⚠

CORS is hardcoded

app/main.py sets allow_origins to localhost origins literally — it does not read the existing settings.CORS_ORIGINS. Fine for a same-origin nginx deployment; a cross-origin browser client would need this widened, and it should be driven by config rather than a literal.

⚠

Deprecated WS ?token=

The WebSocket still accepts a transitional ?token=<jwt> query param alongside the subprotocol path (it logs a deprecation warning on every use). Query-string tokens can land in logs — worth removing once no in-flight clients use it.

Scope

A full assessment would also cover dependency CVEs, rate limiting, the MCP credential flow end-to-end, and the gated-exec sandbox boundary in depth. WCAG compliance for the UI would require manual testing with assistive technologies.
