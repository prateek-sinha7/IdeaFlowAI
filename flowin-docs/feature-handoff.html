Product feature

Claude-Code Handoff

Bridges a local Claude Code (IDE) session into Flowin. A developer hands off their session transcript; Flowin runs a coding pipeline over it and can push results to GitHub/GitLab and file Jira issues via integrations.

Feature name: /flowin-handoffAuth: API key (flowin_ prefix, X-Flowin-API-Key)

The handoff flow

The pieces

PieceWhereRole
Receive endpointapp/api/handoff.pyAccepts the transcript (bounded to HANDOFF_MAX_TRANSCRIPT_BYTES = 1 MiB — a DoS guard), returns a handoff URL.
WS handoffapp/api/websocket_handoff.pyStreams the handoff coding run to the UI.
Pipelineapp/services/handoff_pipeline.pyThe coding pipeline (can use a Sonnet override via BEDROCK_CODING_MODEL_ID).
Git bridgeapp/services/handoff_github.pyPushes commits / opens PRs.
API-key authapp/api/api_key_auth.pyAuthenticates the CLI (flowin_ key prefix, X-Flowin-API-Key header).
UIcomponents/handoff/HandoffWorkflow, DiffView, ReportViews, IntegrationsCard, HandoffPreviewPanel.
🔑 Client installer

app/api/install.py serves a client CLI installer; the generated client uses FLOWIN_API_URL / FLOWIN_API_KEY env vars. This is one of the product surfaces that still carries the flowin brand (the infra was rebranded to velocityai; see the note on Home).
