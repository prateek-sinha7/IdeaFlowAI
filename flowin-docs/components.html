Component Tree

Components are grouped by feature area. DashboardLayout is the orchestrator; IdeaInputPage is the compose-and-launch surface; PreviewPanel + the results/ tabs render the live run and its deliverable. Expand a group to see its members.

In plain terms. The React components are organized by the job they do in a run's life: compose it, watch it happen, inspect the details, and view the finished result. Keeping those concerns in separate folders means one part can change without disturbing the others.
What it is

The component tree grouped by feature area (layout, workflow, preview, results, chat, catalog, handoff…).

Why it exists

Separation of compose / monitor / preview concerns keeps the UI maintainable and testable.

How it works

DashboardLayout orchestrates; IdeaInputPage composes; progress + results/ tabs monitor; PreviewPanel renders by mimetype.

How components connect to the run

Groups

🧭 layout/ — app shell

DashboardLayout.tsx — the top-level orchestrator (routes WS messages to useWorkflow, manages views, reconnect effect, pipeline chaining). AppHeader.tsx — the top bar.

🏭 workflow/ — compose & launch

IdeaInputPage.tsx (main input + composer), AgentLibrary, AgentsPopup, AgentModelPicker (per-agent model override), AgentNode, AgentProgressPanel, PipelineGraph, ReviewGatesSection (HITL toggles), SkillManager, TokenUsageSummary, WaveTreePanel, WorkflowControls, WorkflowView, CapabilityPaletteSection.

ppt/ → PPTTemplateGallery. prototype/ → DiscoveryForm, TemplateGallery/Card/DetailModal, DesignSystemPicker/DetailModal, CustomTemplateModal, CustomDesignSystemModal, DesignSpecView.

🖼️ preview/ — deliverable rendering

PreviewPanel.tsx (dispatches on mimetype), PrototypePreview, PPTPreview, AppBuilderPreview, MarkdownPreview, UserStoryPreview, QuestionnairePanel (clarify), ReviewGatePanel (HITL approve/edit), TweaksPanel.

📑 results/ — run introspection tabs

AgentThinkingTab (per-agent input/context/tool calls), AuditTab (hook_runs trail), FilesTab (sandbox files), PrototypePipelineView, ValidatorIssuePanel (issues by severity).

💬 chat/ — free-chat subsystem

ChatPanel, ChatInput, MessageBubble, ArtifactCard, ProcessSteps, TypingIndicator, ErrorMessage.

🗃️ catalog/ · history/ · savedworkflows/ · library/

WorkflowCatalog (data-driven from /api/workflows) + NameWorkflowModal; WorkflowHistory (reopen past runs); SavedWorkflowsPage (user-authored); LibraryPage (agents/skills/hooks browser).

🤝 handoff/ — Claude-Code bridge

HandoffWorkflow, HandoffAgentPanel, HandoffPreviewPanel, DiffView, ReportViews, IntegrationsCard (GitHub/GitLab/Jira/Slack), + useHandoffPipelineState.ts.

🧰 sidebar/ · settings/ · analytics/ · home/ · ui/

Sidebar + ChatSessionItem; AccountSettings; AnalyticsPage; CreationHub (home); ErrorBoundary, NotificationPanel, CompletionToast.

🧪 Testing

Unit tests are colocated (*.test.tsx via Vitest + Testing Library — e.g. IdeaInputPage.modelOverrides.test.tsx, PreviewPanel.degraded.test.tsx). End-to-end is Playwright with two projects: mocked (default) and live.
