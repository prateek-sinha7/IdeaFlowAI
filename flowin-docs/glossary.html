Glossary

The vocabulary that recurs across this atlas, in one place.

SC-001

The core success criterion: a new workflow can replicate prototype by manifest + AGENT.md only, zero engine edits. The kernel knows no workflow by name.

Manifest

A workflow.yaml describing a pipeline: steps, per-step strategy/gates/validators, deliverable, clarify config. Pure data, no control flow.

CompiledWorkflow

The typed, validated plan the kernel executes — output of the WorkflowCompiler. A topo-validated Step DAG plus workflow-level config.

Capability

A self-registering plug-in (@register(kind,name)) satisfying a Protocol port. Strategies, validators, deliverables, gates, hooks, tools, providers.

ExecutionContext

The per-run value object holding all run state (INV-2). One instance per execute(), threaded through the call tree; the engine singleton stays stateless.

AgentSpec / AGENT.md

An agent's identity + system prompt. YAML frontmatter (id, pipeline_type, order, tools, guardrails, gate) plus a Markdown prompt body.

DeepAgentRunner

The adapter that wraps a LangChain deepagents graph and maps its LangGraph event stream onto Flowin's WS event vocabulary (INV-13).

RunSandbox

A per-run, traversal-proof on-disk directory shared across a run's agents so files persist agent-to-agent.

HITL gate

Human-in-the-loop pause. A gate: human step (or clarify questionnaire) suspends the run, durable via the checkpointer, resumed by a client message.

Ports & Adapters

The hexagonal architecture: the kernel depends on abstract ports; concrete adapters plug in via the registry. Enforced by import-linter.

Fan-out / Wave

Parallel execution. fanout_batch spawns N isolated workers then merges; wave_scheduler topo-schedules tasks into parallel waves with durable resume.

Deliverable resolver

The capability that produces a run's final artifact from the sandbox: single_file, serialized_sandbox, streamed_text, ppt, repo_diff.

Checkpointer

The LangGraph state store (Postgres in prod, in-memory in dev) that makes HITL pauses and mid-run resume durable.

ScopedStore

The owner + workspace-scoped DB helper through which all per-run persistence flows, enforcing ownership on every row.

Constitution

A per-user set of governing principles (from workflow_memory) injected last into every agent prompt, just before the body.

deepagents

The LangChain library (pinned 0.6.7) every agent runs on. create_deep_agent is called only inside deep_agent_runner.py (INV-13).

The invariants, in one line each

INV-2No per-run state on the engine singleton; it lives on ExecutionContext.
INV-3Behavioral parity — deterministic deliverables stay byte-identical (5 golden tests).
INV-5Compiler is thin — manifests are pure data, no DSL.
INV-12Move, don't copy — deletion of superseded code is an exit gate.
