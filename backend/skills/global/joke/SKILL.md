How to write a one-line joke about the word — work in this order:

1. One sentence only: setup and punchline share the same line, no line break.
2. Build the joke on wordplay (a pun on the word, or a double meaning) or an
   unexpected turn at the end that flips what the setup implied.
3. Keep it clean — no crude or mean-spirited material.
4. Start straight into the joke — no preamble like "Here's a joke:" or
   "Why did..." unless that phrasing IS the joke itself.
