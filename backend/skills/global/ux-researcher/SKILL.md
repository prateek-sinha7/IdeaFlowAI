# UX Researcher & Designer

Comprehensive toolkit for user-centered research and experience design.

## Core Capabilities

- Data-driven persona generation
- Customer journey mapping
- Usability testing frameworks
- Research synthesis and insights
- Design validation methods

## Key Features

### Persona Generator
Creates research-backed personas from user data and interviews.

**Features:**
- Analyzes user behavior patterns
- Identifies persona archetypes
- Extracts psychographics
- Generates scenarios
- Provides design implications
- Confidence scoring based on sample size

### Journey Mapping
- Maps end-to-end user experiences
- Identifies pain points and opportunities
- Documents emotional journey
- Highlights moment-of-truth interactions
- Creates service blueprints

### Usability Testing
- Task-based test design
- Heuristic evaluation frameworks
- A/B testing methodology
- Think-aloud protocol guidance
- Metrics collection and analysis

### Research Synthesis
- Affinity diagramming support
- Theme extraction
- Insight prioritization
- Stakeholder presentation frameworks
- Actionable recommendation generation

## Research Methods

### Discovery Research
- User interviews (structured/semi-structured)
- Contextual inquiry
- Diary studies
- Survey design
- Card sorting
- Tree testing

### Evaluative Research
- Usability testing (moderated/unmoderated)
- A/B testing
- Preference testing
- First-click testing
- Accessibility audits

### Generative Research
- Co-design workshops
- Concept testing
- Prototype evaluation
- Desirability studies

## Frameworks

### JTBD (Jobs to Be Done)
- When [situation], I want to [motivation], so I can [expected outcome]
- Focus on user goals, not features
- Uncover emotional and social jobs

### Double Diamond
1. Discover: Research and understand
2. Define: Synthesize and frame
3. Develop: Ideate and prototype
4. Deliver: Test and implement

### UX Metrics
- Task success rate
- Time on task
- Error rate
- System Usability Scale (SUS)
- Net Promoter Score (NPS)
- Customer Satisfaction (CSAT)

## Best Practices

- Always start with user needs, not solutions
- Triangulate findings across multiple methods
- Include diverse participants in research
- Document assumptions and validate them
- Share insights across the organization
- Iterate based on evidence, not opinions
- Consider accessibility from the start
- Balance qualitative and quantitative data
