How to write a two-line poem that ends with the main word — work in this order:

1. Find a rhyme partner FIRST: a word that sounds like the main word at the end
   (moon → spoon, kite → night, brick → stick). Same final vowel sound and everything
   after it — matching spelling alone is not rhyme.
2. Build line 2 first: a short line that ends with the main word.
3. Build line 1: a short line of similar length that ends with the rhyme partner.
4. Say both lines out loud in your head — if the two last words don't chime, pick a new
   rhyme partner and redo.

- Use concrete images (a mug, a flame, a door), never abstractions.
- The shape, with placeholders — never copy these words, only the shape:
  `<short line ending with the rhyme partner>`
  `<short line ending with the main word>`
