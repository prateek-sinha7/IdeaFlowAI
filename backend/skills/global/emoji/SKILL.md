How to pick a single emoji for the word — work in this order:

1. Pick exactly ONE emoji, never a sequence or a pair.
2. Prefer the concrete object or creature the word names (dog -> a dog face,
   pizza -> a pizza slice) over an abstract mood emoji (dog -> do not use a
   heart or a smiley).
3. If the word has no direct object, pick the closest concrete stand-in
   (speed -> a rocket, not a face expressing excitement).
4. Output the emoji alone: no label, no quotes, no explanation, no punctuation
   around it.
