# Clarifications

## Round 1

### How should the main navigation be structured? Given 6 pages (Vehicles, Vehicle Detail, Work Orders, Inspections, Parts & Costs, Settings), should users navigate via a persistent left sidebar, top bar with dropdown menu, bottom tab bar, or card-based single-page layout? _(high impact)_
**Answer:** Persistent left sidebar (typical dashboard pattern)

### What visual design language should the prototype follow? Should it use a minimal SaaS aesthetic (light neutral, lots of whitespace), a dark admin dashboard (dark background, high contrast), a data-visualization style (charts/graphs emphasis), or match Northwind's existing brand? _(high impact)_
**Answer:** Minimal SaaS (light grays, clean typography, subtle accents)

### Which pages are essential for the minimum viable prototype? Should all 6 (Vehicles, Vehicle Detail, Work Orders, Inspections, Parts & Costs, Settings) be fully functional, or should some be placeholder/stub pages? _(high impact)_
**Answer:** Vehicles (list with filters/search) — fully functional
