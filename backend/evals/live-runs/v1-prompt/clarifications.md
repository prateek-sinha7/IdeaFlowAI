# Clarifications

## Round 1

### For the Work Orders page organized 'by shop', should the primary UI layout be Kanban-style columns (Pending → In Shop → Awaiting Parts → Road Test → Complete) with drag-to-advance vehicle cards, or a tabular list view with status-filter tabs and inline 'Advance Status' buttons? _(high impact)_
**Answer:** Kanban columns with drag-to-advance (visual queue management)

### Should the console use a persistent left sidebar for navigation (Vehicles → Vehicle Detail → Work Orders → Inspections → Parts & Costs → Settings) with the main content area showing the current page, or a flat single-page layout with tabs/breadcrumbs? _(high impact)_
**Answer:** Left sidebar navigation (persistent context, traditional dashboard)

### What is the intended visual style for the console — minimal/light-theme SaaS (neutral greys, blue accents), dark-mode admin dashboard (dark greys/blacks, bright alerts), or data-focused design (high contrast, colour-coded status)? _(medium impact)_
**Answer:** Minimal light SaaS (neutral greys, clean typography, blue action buttons)
