# LEDGER

The queue. One row per bug in `BUGS.md`, and **the `Status` column is the only place a bug's
state lives.**

The automated line reads this table to decide what to work on, then reads that bug's full
section in `BUGS.md`. Each stage rewrites the one row it is working on — nothing else.

Keep cells short. Detail belongs in `BUGS.md`; this table exists to be scanned and edited
safely.

The **`Cards`** column is where the line records what it worked out — `ISS-…` for the defect
and its root cause, `FIX-…` for the change, `ADR-…` for a decision, `BUG-…` for a knowledge
bug card. The prefix names the type. Bug **report** ids start with `QA-` precisely so they can
never be mistaken for a `BUG-` card.

**Every id here is a clickable link.** The `Bug` column links to that bug's section in
`BUGS.md`; the `Cards` column links to each card file:

```
[FIX-516](.knowledge/cards/20260915-1420-FIX-516.md)
```

Card filenames carry a datetime prefix, so the link has to name the real file — the agent that
mints the card knows it. Bug links use a fixed anchor (`BUGS.md#qa-ak-001`), which keeps
working even if the bug's title is edited.

See **`HOW_TO_LOG_BUGS.md`** before adding a row.

---

## Status values

| Status | Meaning | Who writes it |
|---|---|---|
| `Open` | logged, waiting to be picked up | **you** |
| `CONFIRMED` | reproduced 3× from cold | validator |
| `ANALYZED` | root cause and blast radius found | analyzer |
| `TESTED` | a failing test exists | test-writer |
| `FIXED` | fix applied, not yet verified | fixer |
| `CLOSED` | test green, bug gone, build healthy | verifier |
| `REOPENED` | verification failed, back to the fixer | verifier |
| `UNREPRODUCIBLE` | could not be reproduced from the steps given | validator |
| `DUPLICATE` | same root cause as another bug | validator / analyzer |
| `FLAKY` | reproduces only sometimes, trigger not yet pinned | validator |
| `ESCALATED` | needs a human decision — **stops here** | any stage |
| `PARKED` | deliberately not being worked — **stops here** | you |

`Open` is the only one you write by hand. After that the line owns the column.

`CLOSED`, `UNREPRODUCIBLE`, `DUPLICATE`, `ESCALATED` and `PARKED` are terminal — no stage
picks them up again.
